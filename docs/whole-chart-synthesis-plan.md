# 사주 전체 종합 풀이로 가는 실행 순서

2026-10-22. 사용자는 문장 조합을 넘어 사주 전체를 종합하는 방식과 지금 가능한 구현을 요청했다.

## 필요한 변화

문장을 만드는 방법보다 **어떤 해석을 선택할지 판단하는 단계**가 먼저다. 현재 v8은 확인된 십성 집합을 상황별 원고에 연결한다. 다음 구조는 계산 → 출처 있는 사실 → 복수 조건을 묶은 구조 분석 → 지지/방해 조건과 미확정 사유 → 검증된 해석 선택 → 쉬운 문장이다. LLM을 추가해도 가운데 판단 단계가 검증되지는 않는다.

## 순서와 완료 조건

| 단계 | 작업 | 이번 상태 / 통과 조건 |
| --- | --- | --- |
| 1. 구조 분석 통합 | 월지·뿌리 관찰·투출·자리·합의 거리/간섭·사령을 같은 검토에 모음 | 연구 구현 완료. 모든 연결의 근거 ID와 출처를 추적 |
| 2. 조건 충돌과 보류 | 출처별 합화 방해, 원전 사례, 시상 조건, 구응을 구분하고 후보/미상 전파 | 연구 구현 완료. 서로 범위가 다른 결과를 하나의 참/거짓으로 합치지 않음 |
| 3. 기존 사례 회귀 검증 | 원전 20명조, 시간 제거, 같은 십성/다른 자리, 출생 경계 | 7개 새 검사 및 전체 연구254개 통과. 일반 판정 정확도 검사는 아님 |
| 4. 일반 판정 규칙 정립 | 종합 강약·중화·합화의 충분조건/반례/우선순위 명시 | 미완료. 아래 감수표의 근거를 채운 뒤 구현 |
| 5. 해석 검증 | 구조가 특정 성격/관계 설명을 선택하는 이유와 반례 확인 | 미완료. 명리 분류와 실제 성격 타당성을 구분 |
| 6. 앱 적용 | 새 결과 버전으로 사실·판단·설명을 저장, 구버전 유지 | 기준 확인 후 적용. 현재 공개 체험은 v8 유지 |

## 이번에 구현한 범위

[종합 분석 모듈](../research/validation/whole-chart-synthesis.mjs)의 `synthesizeProfile`은 다음을 연결한다.

- 확정 사실과 후보에 따라 달라지는 사실을 분리한다. 확정 사실만 복수 조건 연결에 사용한다.
- 같은 십성이라도 어느 기둥의 겉/속에 있는지 보존한다. 같은 분류를 여러 번 세어 강도 점수로 쓰지 않는다.
- 월지 지장간의 천간 노출과 다른 기둥 지장간의 동일 글자를 결합한다. 이는 여러 조건의 사실 교집합이며, 통근 등급이나 격국 성립의 새 원전 규칙이 아니다.
- 원전 강약 사례, 일간 합화 방해, 시상/파상·자조, 일반 균형 검토, 구응/원전 합화 사례를 같은 결과 안에서 출처별로 보존한다.
- 강약·합화·성격 판단마다 필요한 정보와 보류 사유를 반환한다. 특정 판본의 정확한 네 기둥 사례 판어와 일반 판정은 별도 필드다.
- `synthesizeBirth`는 생일에서 계산한 실제 후보와 해당 사령 정책을 연결한다. 호출자가 넣은 임의의 사령/승인 필드를 신뢰하지 않는다.
- `synthesizePair`는 개인 두 명의 구조와 교차 기호를 구분한다. 두 사주를 하나의 여덟 기둥 명조로 합치지 않는다.

의도적으로 아직 하지 않은 것: 임의의 강약 수치, 부족한 오행을 무조건 보완한다는 설명, 합=좋음/충=나쁨, 두 사람 합화 확정, 실제 성격/관계 성공 확률.

## 다음 감수표

일반 사례 판정은 아래 항목이 갖춰진 규칙만 채택한다. 현재 판어가 있는 20명조는 극단 사례 모음이며 중화의 경계를 학습하거나 검증할 표본이 아니다.

| 항목 | 작성할 내용 | 채택 전에 확인할 것 |
| --- | --- | --- |
| 대상/학설 | 개인 일간·화신·격국 중 무엇을 판단하는지, 판본/쪽/전사 | 다른 대상과 규칙을 섞지 않았는가 |
| 입력 조건 | 월령/사령, 투출, 뿌리, 자리, 간섭, 시간 완전성 | 필요한 조건을 모두 관찰할 수 있는가 |
| 지지 조건 | 결론을 뒷받침하는 조건과 그 조합 | 개수나 임의 가중치가 아닌 근거가 있는가 |
| 방해/예외 | 성립을 막거나 보류하게 하는 반례 | 예외가 동시에 있을 때의 우선순위가 있는가 |
| 경계 사례 | 약/중화/강 및 경계 양쪽 사례 | 극단 사례만으로 일반화하지 않았는가 |
| 독립 검증 | 규칙 작성에 쓰지 않은 사례의 독립 판정 | 의견 차이를 숨기지 않고 미확정으로 기록하는가 |
| 해설 연결 | 구조 → 선택된 설명 → 예상 반례 | 전통 분류를 실제 성격의 증명이라고 말하지 않는가 |

기존 20사례를 사용한 일치 검사와 미래의 독립 검증셋을 분리해야 한다. 현재 전문 감수/실제 사용자 관찰을 수행했다고 표시하지 않는다. 사용자 테스트를 건너뛰라는 기존 지시는 유지한다.

20개 정확한 원전 사례 연결, 출생 입력 5종(일반/시간 알려짐/오월 자료 문제/절기 경계/역사 시계), 같은 십성·다른 자리 비교를 기록했다. 끊긴 근거 연결 0건, 후보 전용 사실을 확정 근거로 승격한 건수 0건, 미검증 최종 판정 0건이다. 앱에 새 종합 판정을 노출하지 않았으므로 공개 체험 재배포는 하지 않는다.
