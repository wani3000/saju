# 김춘배 훈장 개인정보 처리방침 초안

상태: **게시 전 검토용·시행일/책임자/문의 주소 미정**. 현재 구현 사실과 제안 정책을 구분한다. 체크박스나 새 동의 절차를 이 문서만으로 자동 추가하지 않는다.

## 현재 처리하는 정보

| 구분 | 정보와 목적 | 현재 보관/처리 사실 |
|---|---|---|
| 로그인 | Supabase 사용자 식별자와 앱 계정 연결, 선택 닉네임·프로필 사진 URL | 로그인·프로필 표시·내역 소유권 확인. 회원 기록의 정기 파기 기간은 아직 없음 |
| 사주 입력 | 부를 이름, 생년월일, 양력/음력·윤달, 시간 인지 여부와 입력 시각, 두 사람의 관계 | 입력 중 초안 저장, 계산·결과 생성/재열람. 회원 초안/결과의 만료 기간은 미확정 |
| 계산·결과 | 입력 스냅샷, 차트, 엔진/풀이 버전, 생성 상태 | 생성 당시 결과 보존. 사주 생일을 인증 공급자에 보내 계산시키지 않음 |
| 이용/결제 | 주문·거래 식별자, 금액·상태, 승인/취소 및 이용권 이력 | PG 대사·내역·중복 방지. 카드번호/카드 비밀번호를 앱 DB에 직접 보관하는 구조가 아님 |
| 공유 | 공개 별명·대화 카드, 링크 해시·만료·철회 상태 | 링크30일 만료, 철회 즉시 열람 차단. 만료/철회 행의 물리 정리는 maintenance 실행 시 처리 |
| 인증/보안 | 세션 해시, 임시 OAuth/이관·결제 반환 상태, 제한/운영 이벤트 | 세션30일, OAuth/이관10분, 결제 시도20분의 유효기간. 만료 거절과 물리 삭제 주기는 서로 다름 |

로그인 전에도 방문 세션이 만들어질 수 있으나, 실제 생일 입력은 카카오 로그인 후로 제한한다. 제공하지 않은 프로필을 임의로 만들어 저장하지 않는다. 서비스는 현재 생성형 AI 설명 API를 활성화하지 않았으며 생일/풀이를 외부 LLM으로 보내는 운영 기능은 없다.

## 보유·파기와 삭제의 실제 범위

앱 삭제는 생일/차트/결과/초안/공유·세션·복구 정보와 표시 프로필을 지우거나 비운다. 그러나 주문·거래/기존 동의·무료 이용·작업/이용권·내용을 비운 비교 기록과 계정 연결 식별 표지는 남는다. 익명화나 잔존 정보 최소화가 완료됐다는 뜻은 아니다. 이 정보의 처리 근거·최소 항목·분리 보관·보유 종료/파기 작업은 출시 전에 확정해야 한다. Supabase 인증 기록이나 카카오 연결 해제는 별도 범위다.

현행 정리 작업은 주문/인증 연결/활성 세션/최근 초안이 없는30일 경과 게스트만 대상으로 한다. 회원 전체가30일 뒤 자동 삭제된다고 안내하지 않는다. 운영 이벤트는30일 경과분을 maintenance에서 정리한다. 원격 정기 실행은 아직 등록하지 않았다.

법률 검토 시 목적 달성/기간 경과 정보의 파기와 법령상 보존 정보의 분리 보관을 확인한다([개인정보 보호법 제21조](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900078981), 시행2026-09-11). 거래기록의 법정 보존을 사주 원본 전체의 무기한 보관 근거로 사용하지 않는다. 백업의 보관/삭제 주기와 복원 뒤 삭제·철회 재반영도 별도로 정해야 한다.

## 외부 처리와 공개 범위

카카오·Supabase 인증, Supabase PostgreSQL, Vercel 호스팅, NICEPAY 테스트 PG를 사용한다. 각각의 계약상 위탁/제공 관계, 실제 전송 항목, 처리 국가·접근/로그·재위탁 범위는 확정 목록에 남긴다. DB가 서울이라는 이유만으로 모든 처리/접근이 국내에만 있다고 표시하지 않는다. 국외 이전의 처리 근거·고지 항목은 [개인정보 보호법 제28조의8](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1020398611)을 대조한다.

현재 공개 공유는 링크 보유자 열람이다. 개인정보를 포함한 URL·코드·토큰·생일을 운영 알림에 넣지 않으며, 플랫폼 자체 로그/백업의 설정과 보관 기간은 별도 확인 대상이다.

## 정보주체 요청과 출시 전 결정

열람·정정·삭제·처리정지의 공식 접수 창구, 책임자, 확인 절차·회신 기준을 실제 운영자 정보로 채운다. 회원 탈퇴/외부 인증 연결 해제·아동 정보·상대방 정보 처리·각 처리의 근거와 동의 시점을 확정한다. 최종 개인정보 처리방침의 공개 및 법률 검토 완료를 이 초안 작성으로 대신하지 않는다.
