# 김춘배 훈장 서비스 이용약관 초안

상태: **게시 전 검토용·시행일 미정**. 운영자/문의/판매 조건 확정과 실제 처리 방식 대조 전에는 앱의 최종 약관으로 게시하지 않는다. 이 문서는 사용자가 동의한 기록이 아니다.

## 서비스와 결과

김춘배 훈장은 이용자가 입력한 두 사람의 생일과 관계를 바탕으로, 전통 사주 글자의 뜻에 빗대어 개인 성향과 관계의 대화 주제를 제공한다. 성격 검사나 관계의 성공을 예측하는 서비스로 보증하지 않는다. 확인하지 못한 출생 시간이나 경계의 글자를 임의로 정하지 않는다.

서비스의 운영자는 플로렌스랩으로 등록한 상호를 기준으로 검토 중이다. 대표자·사업자/통신판매 신고 정보·주소·문의 창구는 [확정 목록](release-decisions.md)에 기재한 뒤 판매 화면에 연결한다. 등록 정보가 확인되기 전에는 판매자 표시가 완료됐다고 보지 않는다.

## 계정과 입력

서버 앱은 카카오 로그인 후 생일을 입력한다. 같은 계정으로 로그인하면 저장된 결과와 이용 내역을 다시 볼 수 있다. 닉네임·프로필 사진은 선택 정보이며 로그인 공급자의 이메일·전화번호·생일을 요청하는 방식은 사용하지 않는다. 사주용 생일은 입력 화면에서 별도로 받는다.

이용자는 자신이 입력할 수 있는 정보인지 확인한다. 상대방 정보는 당사자에게 알리고 필요한 허락/처리 근거가 있는 범위에서 입력한다. 단순히 버튼을 눌렀다는 기록을 상대방의 동의로 간주하지 않는다. 제3자 정보와 아동 정보의 이용 범위/확인 방식은 출시 전에 확정한다.

## 상품과 기록

현재 상품 기획은 첫 상대1명 무료, 추가 상대1명당2,900원이다. 공개된 서버는 연구용 스테이징이고 NICEPAY 테스트 결제를 사용한다. 운영 판매의 부가세 표시·공급 시점과 최종 상품 표시를 확정해야 한다. 보관 기본값은 아래와 같이 채택했다. 정기 구독이나 자동 반복 결제를 약속하지 않는다.

구매 대상은 생성 당시 입력과 계산·풀이 버전에 따른 결과다. 같은 저장 결과를 다시 읽는 데 새 주문을 만들지 않는다. 계산이나 원고가 바뀌어도 이전 결과를 자동으로 고쳐 쓰지 않는다. 저장 결과는 회원 유지 또는 이용자 삭제 시까지 보관·재열람하는 정책을 채택한다. 오입력은 결제 후7일 이내 환불 후 다시 입력하는 기준을 따른다. 개별 이야기는 프로필에서 삭제를 확인한 뒤 지울 수 있다. 삭제는 자동 환불이 아니며 사용한 무료 기회를 다시 제공하지 않는다.

## 공유와 삭제

공유는 별도로 정한 공개 별명과 대화 카드만 제공하며 생일·개인 차트·전체 성격 풀이를 공개 카드에 싣지 않는다. 링크를 아는 사람은 볼 수 있으므로 실명을 공개 별명으로 쓰지 않는 편이 좋다. 링크는30일 뒤 만료되며 이용자가 철회할 수 있다. 상대가 이미 저장한 화면까지 회수한다고 보장하지 않는다.

앱의 ‘내 정보 삭제’는 서비스의 생일/결과 등 삭제 기능이다. 카카오·Supabase 자체 계정 삭제나 외부 연결 해제와 같은 기능이라고 표시하지 않는다. 미확정 결제/취소는 먼저 상태를 확인하며, 삭제 자체가 결제 취소를 뜻하지 않는다. 남는 기록과 요청 창구는 [개인정보 초안](privacy-draft.md)에 따른다.

## 장애와 환불

결제 확인이 늦으면 중복 결제 대신 기존 주문을 조회한다. 생성 실패에는 기존 이용 권한을 보존한 재시도 경로를 사용한다. [취소·환불 초안](refund-draft.md)은 법정 권리를 제한하는 문구로 사용하지 않는다. 단순 변심도 열람 여부와 무관하게 결제 후7일 이내 전액 환불하는 기준을 채택했다. 문의는1영업일 이내 답변을 목표로 하고 법정 환급 기한을 우선한다. 수신처·담당자·중단/변경 고지와 구제는 최종 확정 전이다.

## 보관·운영 목표의 적용 상태

미완성 입력 내용은 마지막 수정 후30일, 공유 링크30일, 앱 운영 이벤트30일, 일반 백업7일 보관을 채택한다. 매시간 암호화 독립 백업과 월1회 복원, 손실 구간1시간·복구4시간은 구축/검증 목표다. 정기 백업·알림이 실제 가동 중이거나 이 목표를 보장한다는 뜻은 아니다. 구체적 미완료는 [정책 적용 현황](release-decisions.md)을 따른다.
