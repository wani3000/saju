# 운영자 확인이 필요한 정책 결정

2026-10-23. 초안3종은 [이용약관](service-terms-draft.md)·[개인정보](privacy-draft.md)·[환불](refund-draft.md)이다. 검토용 파일이며 미완성 문서를 앱에 게시하거나 과거 요청을 동의로 바꾸지 않는다.

| 우선순위 | 미확정 항목 | 지금 준비한 제안/근거 |
|---|---|---|
| 1 | 판매자 등록 정보·문의/개인정보 책임자 | 사용자 지정 상호 플로렌스랩 유지. 대표자·사업자/신고·주소·문의 이메일은 실제 값 확인 후 입력 |
| 2 | 출시 상품·공급/재열람·입력 정정 | 첫1명 무료/추가2,900원 계획. 추가 결제의 상품 범위·세금 표시·오입력 구제는 확정 전 |
| 3 | 회원 초안/결과 보관과 삭제 잔존 기록 | 회원 자동 파기 없음·식별 표지/무료/거래 기록 잔존을 실제 구현과 대조. 목적·종료 시점·분리 보관 필요 |
| 4 | 환불 판정/접수/처리 기한·청약철회 제한 | 자동 전액 테스트 취소와 법정 청약철회를 분리. 무조건 환불 불가 문구 사용 안 함 |
| 5 | 상대방·아동 정보와 처리 근거 | 체크박스를 복원하지 않고 합법적 입력 범위·고지/동의 시점·연령 범위를 먼저 검토 |
| 6 | 위탁·제공·국외 이전·로그 | 카카오/Supabase/Vercel/NICEPAY별 실제 전송·접근/계약과 고지 확인. 서울 DB만으로 국내 처리 완료 선언 안 함 |
| 7 | 백업/운영 예산·담당자·목표·알림 수신처 | [복구 준비](../operations-recovery-preparation.md)의 제안과 실제 가능한 복구 범위를 선택 |

승인 순서는 정보/상품 확정 → 실제 데이터/계약·법률 검토 → 앱의 고지/필요 동작 구현 → 내용/버전 기록과 회귀 확인 → 운영 공개 결정이다. 전문가 풀이 감수·실과금·사용자가 생략한 사용자 관찰의 상태를 이 문서로 바꾸지 않는다.
