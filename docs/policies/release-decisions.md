## 여전히 직접 정해야 하는 항목

1. **판매자·문의 창구:** 지정 상호 플로렌스랩 유지. 대표자·사업자/신고·주소·고객 문의 이메일·개인정보 책임자 실제 값이 필요하다. 개인 Gmail을 임의로 고객센터로 지정하지 않는다.
2. **상품 표시:** 첫 상대1명 무료/추가2,900원 계획은 유지한다. 부가세 표시·영수증·정확한 공급 범위를 확정한다. 새 원고가 과거 구매 결과를 바꾸지 않는다.
3. **법률/데이터 처리:** 타인/아동 정보의 허용 범위·연령·처리 근거/고지 시점, 잔존 식별자/무료 기록의 최소 항목·종료 시점, 법정 거래 기록의 분리 보관·파기, 위탁/제공·국외 이전을 대조한다. 체크박스를 자동 복원하지 않는다.
4. **실행 담당·비용:** 백업 저장소/암호화 키 보관 책임자, 운영자 이메일/보조 알림 채널과 수신자, 장애 대응 담당자를 정한다. 유료 출시 전 Supabase Pro 권장이나 로그인/유료 전환·구매는 나중에 진행한다.
5. **복구 후 재반영:** 별도 최신 환불/삭제/공유 철회 원장과 복원 뒤 재반영을 구축한다. 이 증거 없이 과거 백업을 운영에 덮어쓰거나 서비스 재개를 승인하지 않는다.
