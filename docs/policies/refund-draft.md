# 상품·취소·환불 정책 초안

상태: **운영 판매 전 검토용**. 현재는 NICEPAY 테스트 상점이다. 법정 권리·최종 거래 조건을 확정하거나 고객에게 게시한 문서가 아니다.

## 상품의 정의와 제안

첫 상대1명 무료, 이후 상대1명당2,900원이라는 기획을 유지한다. 유료 결과에 포함되는 개인 성향/두 사람의 도움·대화 주제, 공급 시점과 재열람 기간, 부가세/영수증 표시, 오입력 수정·재생성 기준을 운영자가 확정한다. 가격/무료 여부/성공 화면은 클라이언트 값이 아닌 서버 주문/이용권으로 판정한다.

## 현재 구현과 고객 대응안

| 상황 | 현재 처리 | 초안의 대응 방향 |
|---|---|---|
| 미결제 주문 | 결과 이용권 없음, 만료/취소 가능 | 결제 완료라고 안내하지 않음 |
| 승인/취소 확인 중 | 조회·대사 경로, 삭제 일시 제한 | 새 결제 권유 없이 기존 주문부터 확인 |
| 승인됐지만 생성 실패 | 기존 유료 권한을 둔 재시도 | 같은 이용권으로 복구. 복구 불가 시 환불 판단·고객 안내 |
| 같은 결과 재열람 | 당시 결과를 보존 | 다시 결제시키지 않음 |
| 전액 취소 완료 | paid→refunded, 해당 이용권/공유 열람 회수 | 무료/다른 구매 결과는 보존. 요청 중과 완료를 구분 |
| 계정 데이터 삭제 | 삭제와 환불은 별개 | 미확정 거래 해결 후 삭제. 거래 기록의 보관/열람 방법은 별도 확정 |

현재 UI의 전액 테스트 취소 기능은 운영에서도 모든 주문을 무조건 언제든 환불한다는 약속이 아니다. 반대로 ‘결과가 생성됐으므로 무조건 환불 불가’도 사용하지 않는다.

## 법정 청약철회 검토

[전자상거래법 제17조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0017&lsiSeq=282793&urlMode=lsScJoRltInfoR)(시행2026-07-21)는 일반 청약철회 기간과 디지털콘텐츠 제공 개시 관련 예외·사전 조치, 표시/계약과 다른 제공에 대한 권리를 구분한다. 생성 버튼 클릭·PG 약관 동의·결제 승인만으로 서비스의 철회 제한 요건이 모두 충족됐다고 간주하지 않는다. 제한을 채택할 경우 실제 고지·시험 이용 제공 등 필요한 조치와 증거를 검토한 뒤 흐름을 구현한다.

[시행령 제6조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0006&lsiSeq=288143&urlMode=lsScJoRltInfoR)는 표시광고6개월, 계약/철회·결제/공급5년, 불만/분쟁3년의 거래기록 보존을 정한다. 적용 대상 최소 기록과 분리 보관·파기 구현을 확인한다. 환불 접수·판정·처리/회신 기한은 관련 법률 검토 후 확정하며, 문의 주소나 기한을 임의로 약속하지 않는다.
