# 상품·취소·환불 정책 초안

상태: **권장 기본값 채택·운영 판매/게시 전 검토용**.2026-10-23 사용자 지시로 아래 정책을 반영했다. 현재는 NICEPAY 테스트 상점이며 이 문서는 최종 약관 게시나 실결제 출시 승인이 아니다.

## 상품과 재열람

첫 상대1명 무료, 추가 상대1명당2,900원 계획을 유지한다. 구매 대상은 입력한 두 사람의 개인 성향/관계 이야기와 생성 당시 계산·풀이 버전의 저장 결과다. 같은 저장 결과의 재열람은 추가 결제 없이 회원 유지/이용자 삭제 시까지 제공하는 정책을 채택한다. 환불/정보 삭제 시 해당 권한은 종료하며 서비스 종료/변경의 고지·구제 기준은 최종 판매 조건에 정한다. 부가세/영수증·공급 시점 표시는 운영 판매 전 확정한다.

## 채택한 환불·대응 기준

| 상황 | 정책/처리 |
|---|---|
| 단순 변심·기대와 다른 풀이 | 결제 후7일 이내 전액 환불. 결과 열람 여부와 무관하게 허용 |
| 중복 결제 | 기존 거래를 확인해 중복분 전액 환불. 같은 거래를 두 번 취소하지 않음 |
| 승인됐으나 결과 생성 실패 | 추가 결제 없이 같은 이용권 재시도. 고객이 환불을 원하면 전액 환불. 상태 불명은 기존 거래 대사 우선 |
| 생일 오입력 | 7일 이내 환불 후 올바른 정보로 새 요청. 별도 무료 수정 이용권/자동 결과 덮어쓰기는 도입하지 않음 |
| 접수·회신 | 즉시 접수 상태 표시,1영업일 이내 답변 목표. 문의 수신처/실제 담당은 준비 전 |
| 취소·환급 | 지체 없이 카드 취소 요청, 법정 기한 준수. 카드사 반영 일정과 서비스의 취소 요청 완료를 구분 |
| 7일 경과·시각 확인 불가·분쟁 | 자동 환불 불가로 확정하지 않고 법정 권리·중복/미공급/오류 여부를 수동 검토 |
| 환불 처리 중 | 해당 이용권·공유 중지, ‘취소 확인 중’과 ‘취소 완료’를 구분. 확인 없이 새 결제 유도나 권한 복원 금지 |
| 환불 완료 | 해당 구매의 결과 접근 종료. 무료 결과·다른 구매는 보존 |
| 계정/개별 이야기 삭제 | 삭제 자체가 환불은 아님. 진행 중인 승인/취소를 해결한 뒤 삭제하고 법정 최소 거래 기록은 별도 보관 |

7일은 서비스의 자율적 전액 환불 정책이며 법정 청약철회의 기간·요건·예외를 대체하지 않는다. 별점/성격 적중 여부 같은 증명을 고객에게 요구하지 않는다. 확인 가능한 중복/오류를 악용 의심만으로 일괄 거절하지 않는다.

## 현재 구현과 남은 연결

서버의 가격·주문·이용권·PG 확인을 신뢰한다. 승인/환불 **최초 요청 시각**을 결제 시도 원장에 기록하며 재시도로 시각을 갱신하지 않는다. 환불 요청을 저장하는 시점에 해당 이용권/공유를 회수하고 작업을 중지한다. PG CANCELED 확인 전에는 환불 완료라고 표시하지 않는다. 주문 생성일을 결제일이나 환불 요청일로 사용하지 않는다.

`goodwillRefundAssessment`는 검증된 결제시각을 받았을 때 정확히7일 경계까지 전액 환불 대상으로 판단하고, 시각 미확인/7일 경과는 수동 검토로 반환한다. 고객용 운영 접수/판정 경로에는 아직 연결하지 않았다. 현재 sandbox 전액 취소 API는 이 함수로 제한하지 않으며 실제 운영 PG는 차단 상태다. 기존 거래의 결제시각을 임의로 역산하지 않는다. 운영 전 검증된 승인 시각·정책 버전/상품 조건 증거·접수/기한 관리·문의 창구를 연결한다.

## 법정 권리와 기록

[전자상거래법 제17조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0017&lsiSeq=282793&urlMode=lsScJoRltInfoR)는 일반 철회와 디지털콘텐츠 관련 제한 조건, 표시/계약과 다른 제공에 대한 권리를 구분한다. ‘결과를 읽었으므로 무조건 환불 불가’ 문구를 사용하지 않는다. [제18조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0018&lsiSeq=282793&urlMode=lsScJoRltInfoR)에 따른 디지털콘텐츠 법정 청약철회 시 환급은 원칙적으로 철회한 날부터3영업일 이내이며 카드 청구 정지/취소 요청도 지체 없이 진행한다. 내부 답변 목표로 법정 기한을 연장하지 않는다.

[시행령 제6조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1018638379)의 표시광고6개월·계약/철회 및 결제/공급5년·불만/분쟁3년 기준에 맞춰 최소 거래 기록을 분리 보관하고 파기하도록 구현해야 한다. 최종 법률/판매 조건 검토와 실제 고객 운영은 별도다.

개별 이야기 삭제 후에도 결제 내역에서 기존 주문의 테스트 취소를 요청할 수 있다. 삭제 자체가 환불 접수나 취소 완료로 기록되지는 않는다. 취소 확인 중에는 해당 결과를 열 수 없으며 상태 확인/재시도를 안내한다.
