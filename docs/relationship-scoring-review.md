# 관계 점수·지도 기준 감수 · 2026-10-19

## 현재 판정

원전의 합충 짝, 십성, 월령·뿌리·합의 조건 관찰까지 구현했지만, 이 자료만으로 두 사람의 좋은 관계를 나타내는 수치나 지도 거리를 도출할 수는 없다. **현재 점수·정규화 궁합값·지도 반경은 null**이다. 합 개수에 가산점, 충 개수에 감점을 부여하는 임의 산식을 추가하지 않았다.

이는 실행 실패나 0점이 아니라 `unavailable-pending-rule-and-scale-review` 상태다. [관계 감수 생성기](../research/validation/context-drafts.mjs)가 명시적으로 반환하며, 관계 종류·자기 비교·사용자가 전달한 임의 score 필드로 이 상태를 바꿀 수 없다. 웹은 기존 예시 결과와 지도 동작을 유지한다.

## 산식 채택 전에 필요한 계약

아래는 다음 산식의 **채택 조건**이며 구현 완료나 운영 승인 체크리스트가 아니다.

1. 각 점수 항목은 버전·규칙 ID·입력 위치·기여값을 남겨야 한다. 같은 기호가 여러 위치에서 반복될 때 독립 증거인지 중복인지 정해야 한다.
2. 가중치의 선정 이유, 합산 상한, 음수·동점·모순 근거의 처리를 문서화해야 한다. 모든 항목이 null이면 숫자 0으로 채우지 않는다.
3. A/B 순서를 바꿔도 최종 척도는 같아야 한다. 방향이 다른 십성을 무조건 같은 항목으로 취급해서 대칭성을 만드는 것도 허용하지 않는다.
4. 시간 미상·절기 경계·역사 시각 검토가 결과에 미치는 범위를 먼저 정한다. 확인되지 않은 시주를 보충해서 수치를 만든 뒤 확정된 결과처럼 제시하지 않는다.
5. 지도는 승인된 동일 척도 버전의 `q`에 대해서만 기존 반경 산식을 쓴다. 서로 다른 척도 버전을 한 순위로 비교하거나 새 사람이 추가됐다는 이유로 기존 거리를 정규화하지 않는다.
6. 원전 해석 검토, 문장 감수와 실제 사용자 이해도 검토를 구분한다. ‘점수=성공 확률’, ‘안쪽=실제 친밀도’로 읽히는 표현을 사용하지 않는다.

현재 자동 검사는 관계 유형 변경 시 근거·지표 상태 유지, A/B 기호 비교, 자기 비교에도 점수 null, 임의 수치 주입 무시와 미승인 배포 차단을 확인한다. 가중치 타당성·실제 사용자 이해도·승인 척도의 지도 배치를 검증한 것은 아니다.
