# 쉬운 훈장 말투와 관계별 풀이 v5

2026-10-21 사용자가 사주표 설명·성향 안내부터 전체 풀이를 훈장 말투로 통일하고, 어려운 말을 쉽게 풀며 선택한 관계의 주제에 맞추도록 요청했다. 신규 풀이 버전은 `chunbae-easy-relationship-copy-v5`다. 계산 엔진 v5와 명리 분류는 바꾸지 않는다.

## 표시와 원고

- 표의 연주/월주/일주/시주를 태어난 해/달/날/시간으로 안내한다. 한자·독음은 그대로 유지하고, 음양·오행의 전문 설명 대신 나무/불/흙/쇠/물과 생활 속 비유로 말한다.
- 본문에서 십성·지장간·월령·통근·합화를 나열하지 않고, 솔직하게 말하기/차근차근 챙기기/혼자 생각할 시간 등 일상의 표현으로 쓴다. 직접 설명은 온화한 하게체로, 대화 예시의 따옴표 속 말은 실제 두 사람이 쓸 법한 말투로 둔다.
- 각 개인의 알려진 해·달·날·시간에서 분류를 읽는다. 본문은 각 자리의 보이는 천간, 없으면 확인된 안쪽 글자의 첫 항목을 설명 예로 사용한다. 모든 분류와 출처는 자세한 풀이/근거에 그대로 남긴다. 순서가 세력·중요도·확률을 뜻하지 않는다.
- 두 사람의 공통 행동 예는 두 대표 항목의 공통 묶음부터 고른다. 대표 항목은 기존 v4의 편집 순서이며 새로운 가중치/점수 판정이 아니다. 같은 자리의 구성이 다르면 확인된 서로 다른 분류의 쉬운 설명을 골라 비교한다.

## 관계별 범위

| 선택 | 본문·개인 배려·마무리에서 다루는 주제 |
|---|---|
| 친구 | 연락 간격, 약속/여행과 취향, 고민을 들어 주는 방법 |
| 연인 | 애정 표현, 사랑받는 배려, 데이트/각자의 시간, 서운할 때 대화 |
| 가족 | 집안일/돌봄 분담, 부탁, 휴식, 각자의 선택 존중 |
| 동료 | 역할, 결정권, 마감/완료 기준, 피드백과 질문할 시간 |

관계에 맞춘 조언은 원전에서 검증된 관계 예측이 아닌 편집 원고다. 같은 생일이어도 선택 관계에 따라 개인 배려 문장, 궁합 본문과 마지막 대화가 달라진다. 같은 관계에서도 확인한 십성의 분류가 달라지면 바라는 배려와 설명 예가 달라진다. 연인 외 관계에 데이트·애정 문구를 넣지 않는다.

## 보존과 경계

기존 `buildWholeChartReading`으로 엄격하게 검증한 v4 결과를 독립 복사한 뒤 v5 원고를 작성한다. v4/v3/v2 조회 경로와 원고는 유지한다. 저장된 구매/공유/기존 체험 결과를 새 원고로 덮어쓰지 않는다. 업데이트를 확인할 때는 새 비교를 만든다.

개인/교차 관계의 전체 사실 ID·기둥 위치·출처·알려진 시간·후보 공통성은 보존한다. 시간 모름은 채우지 않고, 계절 후보는 하나로 고르지 않는다. 합/충을 지우거나 이별/결혼/성격 타당성·궁합 점수를 도출하지 않는다. 공개 카드에는 개인별 바람이나 사주 근거를 싣지 않고, 선택 관계의 공통 조언만 둔다. 외부 연동과 전문가 승인 대기는 그대로다.
