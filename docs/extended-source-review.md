# 오월 일수·중화·다섯 합화 쌍 후속 감수 · 2026-10-19

## 결과와 구현 범위

새 연구 버전은 `cross-source-strength-transformation-review-v1`이다. [구현](../research/validation/extended-source-review.mjs), [읽기용 보고서](../research/validation/reports/extended-source-drafts.md), [전체 판정](../research/validation/reports/extended-source-audit.json), [테스트](../research/validation/extended-source-review.test.mjs)를 함께 보관한다. 이전 사령·갑기 v1과 그 보고서는 그대로 재현된다. 실제 입력을 받는 `reviewExtendedSources`에서 사령·강약 요소·다섯 합 조건과 이전 갑기 관습을 함께 확인할 수 있다.

이번 확인으로 오월의 29일은 코드 합산이나 우리 전사에서 생긴 오류가 아님을 확인했다. 합화는 다섯 쌍의 기본월·예외월 및 출처별 중복 조건까지 확대했다. 강약은 과다/부족 안에서도 태왕·왕극·태쇠·쇠극이 구분됨을 확인하고 네 원문 명조를 대조 사례로 등록했다. 모든 명조를 분류하는 수치 기준과 합화 충분조건은 확보되지 않았다. 이 구분은 앱 출시 승인이나 예측 타당성 검증을 뜻하지 않는다.

## 대조 자료

[쪽 이미지·PDF·전사 해시](../research/validation/fixtures/reading-sources/extended-sources.json)와 [선택 전사](../research/validation/fixtures/reading-sources/extended-transcription.json)에 출처를 고정했다. 전체 PDF는 무시된 `.reference-cache`에 두고, 대조한 14쪽의 전체 페이지 PNG를 저장했다. 판독은 Codex의 이미지 대조이며 외부 전문가의 승인이 아니다. 전사는 필요한 구절만 발췌하고 구두점·생략 표시를 추가했다.

- [『增補淵海子平音義評註』](https://commons.wikimedia.org/wiki/File:NLC416-12jh002712-40330_增補淵海子平音義評註.pdf): 趙燕生 편집, 章福記書局, 康德七年[1940]이라는 소장 메타데이터. PDF 18·32·33쪽, 인쇄 15·29·30쪽.
- [『命理集成』](https://commons.wikimedia.org/wiki/File:NLC416-13jh001663-59235_命理集成.pdf): 汪琴南 편, 출판사 [文明書局]·연도 [1932]는 목록의 대괄호를 보존. PDF 28~30쪽, 卷一 7~9쪽. 이 책이 인용한 『三命通會』 문장을 확인했으며 『三命通會』의 초기 판본 자체를 직접 대조했다고 주장하지 않는다.
- [『滴天髓闡微』](https://commons.wikimedia.org/wiki/File:SSID-11335994_滴天髓闡微.pdf): 上海大東書局, 1947이라는 목록 정보. PDF 175~180·188~189쪽, 卷二 33~38·46~47쪽. 原注와 任氏注의 층위를 구분한다. 웹 전사에는 오탈자·누락이 있어 아래 판정은 스캔을 기준으로 한다.

## 오월 29일의 원인과 처리

1940년 판본의 **月律分野之圖**(PDF 18)는 오월에 丙十日·己九日·丁十日을 배치하고, **又論節氣歌**(PDF 33)는 `午宮陽火屬上旬，丁火十日九日己`라고 적는다. 시구는 기존 1926년 판본과 같은 10+10+9다. 도표의 배치를 시간 순서로 확정하거나 분수 표기를 강약 가중치로 바꾸지 않는다.

따라서 **29라는 합계는 원문에 있는 문제**다. 다만 두 판본의 일치가 독립적인 전승, 원저자 의도, 누락된 하루의 위치를 입증하지는 않는다. 九를 十으로 바꾸거나 丁을 11일로 늘리는 수정은 이번 근거로 승인할 수 없다. 원문 오식인지 다른 배분 관습인지의 발생 원인은 여전히 미해결이다. 코드의 기존 오월 전체 `source-duration-conflict`를 유지하고, 신규 통합 결과에 판본 대조 결과와 출처를 추가했다. 다른 30일 표로 조용히 갈아 끼우지 않는다.

## 다섯 합의 월령 대조

『命理集成』 PDF 28의 인용문을 아래와 같이 정규화했다. 숫자 월은 월건에 따라 지지로 옮기며 양력 1·4·5·7·10월을 직접 적용하지 않는다.

| 쌍 | 명명된 변화 오행 | 기본월 | 추가로 적힌 월 |
|---|---|---|---|
| 갑기 | 토 | 진·술·축·미 | 오(五月) |
| 을경 | 금 | 사·유·축 | 신(七月) |
| 병신 | 수 | 신·자·진 | 해(十月) |
| 정임 | 목 | 해·묘·미 | 인(正月) |
| 무계 | 화 | 인·오·술 | 사(四月) |

`primary-month`·`additional-month`·`unlisted-month`를 반환한다. 해당 단락은 **월중 왕기를 얻지 못해도 시상 왕기를 얻으면 쓸 수 있다**고 덧붙인다. 따라서 목록 밖 월을 합화 불가의 최종 판정으로 사용하지 않는다. 시상 왕기의 완전한 검사법은 미검토여서 `hourSupportRoute=not-adjudicated`로 남는다. PDF 30도 진중유가·가중유진과 파상·자조를 논하므로, 월 목록 일치만으로 진화·가화를 확정하지 않는다.

한 음·한 양이라는 설명, 하나의 기에 두 갑/하나의 갑에 두 기가 붙는 예와 `餘倣此`에 따라 **이 출처의 연구 검사**에서는 다섯 쌍 모두 각 천간이 하나씩 드러나는지 확인한다. 이것은 해당 인용문의 유추를 채택한 명시적 정규화다. 『子平真詮』의 위치에 따른 쟁합 예외까지 폐기하는 통일 규칙이 아니다. 같은 쌍의 반복이 있으면 `source-cardinality-conflict`로 보고하고, 시간 모름에는 부재·유일성을 확정하지 않는다. 이미 관찰된 중복은 시주 미상으로 지우지 않는다.

일간이 참여하는 쌍만 평가한다. 월주의 천간·지지를 결합한 채 후보를 전개하고, 기둥 사이 일부 후보의 조합을 실제 가능한 공동 명조라고 단정하지 않는다. 후보 순서와 무관하게 결과가 같다. `transformationEstablished=null`이며 천간 오행을 바꾸지 않는다.

기존 갑기 v1은 진·술·축·미 및 별도 방해 조건을 검사한다. 새 출처에서는 오월도 목록에 들어가므로 두 결과를 합쳐 단일 참/거짓으로 만들지 않는다. `priorJiaJiConvention`으로 이전 출처 관습을 병기한다. 새 월령 목록을 통과해도 기존 중간 경/을 방해까지 통과했다는 뜻은 아니다.

## 중화·과다·부족 기준

직접 확인한 원문으로 다음을 구분한다.

1. **득시/실령과 종합 강약**: 『滴天髓闡微』 PDF 175~177은 월령만의 고정 판단을 경계하고 뿌리·주변 생극을 함께 논한다. 천간 개수가 뿌리의 힘을 대신하지 않는다.
2. **과다/부족 안의 차이**: PDF 188의 任氏注는 旺中有衰·衰中有旺을 太旺·太衰, 극왕·극쇠를 별도로 설명한다. 따라서 ‘강하면 억제, 약하면 보강’을 모든 극단 사례에 자동 적용할 수 없다.
3. **중화의 비교 대상**: PDF 189는 재경겁중·관쇠상왕·살강제약·제강살약처럼 관계 양쪽의 불균형을 든다. 일간 강약 하나나 오행 개수의 균등성으로 중화를 정의하지 않는다.
4. **수치·충분조건**: 확인 구절은 임계 점수·백분율·모든 명조의 분류 절차를 제공하지 않는다. 太旺/旺極의 구분을 임의의 숫자로 만들지 않는다. 일간 강약 사례를 『淵海子平』 합화의 `中和之氣`를 충족했다는 증거로 전용하지 않는다.

다음은 완전한 네 기둥이 원문 사례와 일치하는지만 판별한다. 원문에 기록된 판어와 범위를 반환하며 사용자에 대한 일반 강약 분류·성격·운세를 산출하지 않는다.

| 원문 명조(년·월·일·시) | 판어 | PDF |
|---|---|---|
| 갑진·정묘·갑자·무진 | 木太旺 | 178 |
| 계묘·을묘·갑인·을해 | 木旺極 | 179 |
| 을축·갑신·갑신·신미 | 木太衰 | 179 |
| 기사·기사·을유·병술 | 木衰極 | 180 |

두 번째 사례의 스캔에는 **七木兩水**가 인쇄되어 있다. 흔한 웹 전사의 六木兩水로 교정하지 않으며 개수 임계값의 근거로도 쓰지 않는다. 세 번째 사례의 `木無盤根之處`는 다른 판본의 미중 을 관찰을 삭제하는 보편 규칙이 아니다. 명조 전체에 붙은 원문 판어로만 취급한다. 시간 모름·후보 일부 일치는 부분 대조로 표시하며, 유사 명조·미수록 명조를 자동 중화 또는 무근으로 분류하지 않는다.

## 검증과 남은 범위

신규 17개 검사에 다섯 쌍×두 일간 방향×12월(120조합), 양쪽 중복, 시주 미상, 미수록월의 시상 경로 보존, 이전 갑기 관습과 차이, 후보 상관관계와 16개 고정 조합 대조를 포함했다. 네 원문 사례·부분 일치·같은 천간 개수지만 다른 지지 사례, 출처 해시, 개인정보 제외, 음양력 대응과 실행 시간대 불변성을 확인한다. 새 보고서는 월령 15사례·원문 강약 4사례·실제 입력 경로 2사례다.

```sh
node research/validation/audit-extended-sources.mjs --check
pnpm --dir research/validation test
# 운영 미승인: 종료 코드 2
node research/validation/audit-extended-sources.mjs --release-check
```

남은 것은 오월의 수정값을 뒷받침할 명확한 다른 배분 원전, 일반 명조의 강약·중화 판정 절차, 시상 왕기·파상·자조 및 출처 충돌의 우선순위다. 현재 근거로 이를 완료했다고 표시하지 않는다. 외부 인증·결제는 준비 후 진행한다.

검증 완료: 전체 연구 테스트 143개(신규 17개), 엔진 빌드, 문서 검사, 신규·기존 보고서 재현 검사 통과. 신규 `--release-check`는 의도대로 종료 코드 2로 운영 미승인을 유지한다.
