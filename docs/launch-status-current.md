# 현재 출시 준비 현황 · 2026-10-23

최신 구현: 프로필의 개별 이야기 삭제·확인/완료·취소 대기 안내를 추가했다. 선택한 생일/차트/결과/공유/같은 입력 초안은 제거하고 주문/소비한 무료 이력은 보존한다. 미확정 거래를 먼저 해결하고 늦은 승인/작업 완료로 삭제 결과가 되살아나지 않게 한다. [검증/배포 후속](release-preparation-3-4-5.md)을 따른다.

최신 정책 후속: 사용자가 권장 기본값 반영을 지시하여 [보관/환불/백업/알림 정책](policies/release-decisions.md)을 채택했다. 초안30일 만료·정리 전용 명령·승인/환불 요청시각·파일 백업 암호화·오프라인 알림 판정을 소스에 구현했다. 외부 정기 작업/알림·자동 백업/파기·실결제 환불 접수·법정 기록 분리 파기는 미연결이다. 최종 약관 게시·유료 전환·원격 정리는 실행하지 않았다.

앞선 소스 후속은 [풀이→정책→운영3→4→5](release-preparation-3-4-5.md)다. 신규v9는 같은 대화 반복만 수정했고968결과에서 기존 사실/개인 설명을 보존했다. 정책 초안3종·복구 호환 검사/격리 복원 훈련을 보완했다. 아래의 전문/정책/지속 운영·외부 실제 검증을 자동 통과시키지 않는다.

현재 앱은 김춘배 훈장 연구용 스테이징이다. 실제 카카오 로그인과 NICEPAY sandbox 승인/취소는 확인했으며 정식 공개 출시·실청구 승인은 별도다. 2026-10-20의 [출시 감수 묶음](launch-preparation.json)은 풀이v2 당시의 보존 자료다. 거기에 적힌 ‘외부 설정 없음/모의 결제만 확인’은 현재 연동 상태가 아니며 아래 증거를 따른다. 기존 감수 승인·미관찰 기록은 임의 통과시키지 않았다.

최신 화면은 [서당 초대장 랜딩](landing-invitation-2026-10-23.md)이다. 기존 콘셉트·하단 고정 두 버튼을 유지하고 v8 예시·관계별 소개·FAQ를 추가해 같은 테스트 서버에 재배포했다. 로그인 전후 버튼/저장 입력·프로필 연결을 확인했으며 아래 출시 미완료 항목을 통과시킨 작업은 아니다.

사용자가 생략한 사용자 이해도 관찰은 다시 요청하지 않는다. 현재 관찰0명은 유지한다. 사용자 요청으로 테스트 랜딩은 누구나 접근할 수 있으므로 초대자 제한을 임의로 추가하지 않는다. 개인 데이터는 카카오 세션/소유권, 공유는 철회 가능한 링크 보유자 열람이라는 실제 동작을 기준으로 검토한다.

## 앞선 운영 CLI 감수의 범위(랜딩·v9 후속 이전)

로그인/새 카드 인증·실청구·회원 삭제·원격 maintenance/worker·스케줄러·알림 등록·운영 키·DB 마이그레이션·운영 공개 승인은 실행하지 않았다. 최신 상태 조회는 집계와 등록 GET만 사용했다. 실행 명령 수정은 로컬/운영 CLI 경로이며 앱 화면이나 계산·풀이·서버 웹훅 처리 규칙은 바꾸지 않았다.
