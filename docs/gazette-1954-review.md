# 1954년 관보 원문 대조 · 2026-10-19

## 원문에서 확인한 사실

국가기록원 **BA0185690**, 기록물 건 **0027975450**, 관보 **제1074호**, **1954-03-17** 발행본의 1쪽을 직접 확인했다. 해당 쪽의 대통령령 **제876호 「標準子午線變更에關한件」** 본문은 한 쪽 안에서 끝난다. 2쪽도 확인했으며 본건의 추가 시계 조정 지시가 아니라 다른 통첩·고시다. 같은 호 전체 8쪽의 모든 항목을 감수한 것은 아니다.

- [보관한 원본 1쪽](../research/validation/fixtures/time-standards/gazette-1954-1074-page-1.jpg)

원문 핵심 조항의 수기 전사(띄어쓰기만 보충):

> 檀紀四二八七年三月二十一日午前零時三十分부터 東經百二十七度三十分을 標準子午線으로 한다

현대 표기로 읽으면 **1954년 3월 21일 오전 0시 30분부터 동경 127도 30분을 표준 자오선으로 한다**는 내용이다. 단기 4287년을 서기 1954년으로 환산했다. 공포일 3월 17일과 시행일 3월 21일은 별개다. [국가법령정보센터 연혁](https://law.go.kr/LSW/lsInfoP.do?lsiSeq=31221&viewCls=lsRvsDocInfoR)에서도 제정·시행 날짜를 교차 확인했다. 법령 페이지의 동적 본문을 관보를 대신하는 전사 근거로 사용하지 않았다.

이제 **‘0시 30분’은 국가기록원 요약의 단순 오타라는 가설을 배제할 수 있다.** 다만 본문에는 ‘종전 시계 00:30을 새 시계 00:00으로 돌린다’는 조작 지시나 전환 전/후 시계라는 수식이 없다. 실제 당시 시보·방송·교통 운용까지 확정한 것으로 표시하지 않는다.

마지막 [금주의 기록](https://theme.archives.go.kr/next/weekly/viewMain.do?selectMonth=201503&selectWeek=3)의 연결 원본 **BG0000054 / 0052184524**도 열어 보았다. [원본 이미지](../research/validation/fixtures/time-standards/archives-1954-meridians.jpg)는 127도 30분과 135도 자오선을 표시한 지도이며, 전환 시계 조작 문구가 보이지 않는다. 따라서 그 페이지의 ‘0시’를 별도의 1954년 원문 시행 지시로 취급하지 않는다.

IANA 원본 주석은 대통령령 876호를 출처 목록에 들고 있지만, 해당 주석 자체에 00:30을 00:00으로 해석한 근거가 적혀 있지 않다. 2025b 재현 성공과 역사적 사실의 최종 판정을 구분한다.

## 두 가정을 비교한 결과와 현재 처리

[비교 도구](../research/validation/compare-1954-clocks.mjs)는 아래 두 모델을 이름과 가정으로 구분한다. **관보를 종전 시계로 읽는 두 번째 모델은 가설**이다. 다른 모든 가능한 역사 해석을 망라했다고 주장하지 않는다.

| 항목 | IANA 2025b | 관보 00:30을 종전 시계로 읽는 가설 |
|---|---|---|
| 전환 직전 시계 → 직후 시계 | 3/21 00:00 → 3/20 23:30 | 3/21 00:30 → 3/21 00:00 |
| 역산 UTC 좌표 | 3/20 15:00Z | 3/20 15:30Z |
| 중복 구간(끝 제외) | 3/20 23:30~3/21 00:00 | 3/21 00:00~00:30 |
| 3/21 00:15의 후보 | 3/20 15:45Z 하나 | 3/20 15:15Z와 15:45Z 둘 |

여기서 `Z`는 현대 UTC가 당시 실현됐다는 뜻이 아니라 이전 검증과 같은 역산 좌표다. `prolepticUtc`라는 필드로 이를 드러낸다.

3월 20·21일 **2,880개 입력 분**을 모두 비교했다. **60분은 후보가 다르고, 2,820분은 일치**한다. 현재 v5는 앞의 30분을 `AMBIGUOUS_BIRTH_TIME`, 뒤의 30분을 `HISTORICAL_CLOCK_SOURCE_DISPUTE`로 거절해 두 가정의 중복 구간 전체를 보호한다. 초 단위의 시작 포함·끝 제외도 검사했다. 알려진 시각을 시간 모름으로 바꿔 우회하도록 권하지 않는다.

이번 원문 확인만으로 앱의 시간표를 교체하거나 과거 저장 결과를 재계산할 이유는 확보되지 않았다. v5를 유지한다. 시간 모름의 `clockReview`를 새 풀이 연구에서도 전달하고, 그 후보의 일치가 실제 시각 확정이라는 뜻으로 바뀌지 않게 했다.

## 남은 확인
