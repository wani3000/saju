# 김춘배 훈장 · 입력부터 결과까지

2026-10-20 사용자가 선택한 조선 2안의 분위기와 자연스러운 말투를 전체 여정에 적용하도록 요청했다. [인물 설정](../design/characters/joseon/chunbae-v1/README.md)을 유지하며 새 콘셉트/캐릭터/계산 규칙을 도입하지 않는다.

## 말투 기준

훈장이 직접 말하는 부분은 화면마다 이름을 밝힌 ‘김춘배 훈장의 한마디’다. 짧고 온화한 하게체(‘적어 보세’, ‘괜찮네’, ‘살펴보세’)를 사용한다. 사용자를 ‘자네/그대’라고 부르거나 사투리·옛말을 과장하지 않는다. 확실하지 않은 사주 판단을 인물의 권위로 보증하지 않는다.

입력칸·버튼은 ‘부를 이름’, ‘저장하고 다음’, ‘수정’처럼 행동을 명확히 적는다. 저장·오류·개인정보·결제·연구 한계는 해요체로 설명한다. 훈장 대사와 서비스 설명은 표기와 서체로 구분하며 생일/금전/삭제의 의미를 옛말로 흐리지 않는다.

| 화면 | 훈장 대사/표현 | 디자인과 동작 |
|---|---|---|
| 나의 생일 | 이름과 생일부터 천천히 적어 보세. 태어난 시각을 몰라도 괜찮네. | 내 생일→상대 생일→내용 확인→이야기 단계 표시, 현재 단계 aria-current, 한지 기록장 입력 |
| 상대 생일 | 함께 살펴볼 이의 생일을 적어 보세. | 같은 필드·서체·저장 안내, 관계 입력 유지 |
| 확인 | 잘못 적은 곳은 여기서 고치면 되네. | 두 사람 기록을 나란히 확인, 수정·명시적 동의·가격/모의 결제 고지 유지 |
| 준비/실패 | 아래에서 준비 상태를 살펴보세. | 실제 queued/processing/failed 상태에 맞는 안내, 기존 재시도/상태 확인 동작 유지 |
| 결과 | 기호만으로 사람 사이를 단정할 수는 없지. | 첫째·둘째·셋째 해설 기록지, 사진 소형 표지와 춘배 인장, 근거/계산은 별도 펼침 |
| 공유 | 함께 나눌 말을 먼저 읽어 보세. | 공개 별명 입력·내용 미리보기, 생일/근거 비공개·30일/철회 안내 유지 |
| 지도/보관함 | 다시 읽고 싶은 이름을 골라 보세. | ‘함께한 이야기’, ‘이야기 보관함’, 같은 종이/먹갈색/명조 제목으로 정리 |

훈장의 대사는 [journey-copy.json](../web/content/journey-copy.json)의 `chunbae-journey-v1`으로 관리한다. 현재 화면 안내이며 저장 결과에 주입하지 않는다. 엔진 v5·풀이 `source-observations-copy-v2`·점수 null·기존 주문/공유/구매 스냅샷은 바꾸지 않는다. 결과 본문의 기호 정의·주의·대화 제안은 저장된 해요체를 그대로 보여 준다. 기존 `tigers-v1` 공유 그림과 이전 버전 풀이도 그대로 해석한다.

검수 중 추가 이용 화면에서 NICEPAY 테스트 주문도 Toss라고 표시하던 기존 안내를 발견해 공급자별 이름으로 바로잡았다. 결제 처리·가격·외부 설정은 변경하지 않았고 실제 PG 연동 검증을 주장하지 않는다.

## 검증

웹 88개·HTTP·320/390px 모바일 18사례·빌드/타입 검사 통과. 기존 자동 여정의 변경된 제목 선택자만 갱신했고, 단순 문구를 복제하는 새 테스트는 추가하지 않았다. 자동 여정은 입력 오류·저장 실패 재시도·동의 초기화·새로고침 복원·이전 결과 불변·공개 비식별/철회/삭제를 계속 확인한다.

Chrome/CUA에서 가상 정보만으로 입력→확인→결과→공유 미리보기→지도→보관함을 확인했다. 320px 입력/결과/공유의 scrollWidth와 innerWidth가 같고 앱 출처 오류/경고는 없었다. [시각 QA](../design-qa.md)의 단계/안내 간격과 한국어 단어 줄바꿈 문제를 수정한 뒤 재캡처했다. 실제 사용자·전문가·외부 인증/PG·공개 출시는 별도이며 8개 출시 조건 미완료를 유지한다.
