# 2026-10-19 풀이 내용·버전 감수

## 실제 검토 대상과 판정

현재 서버에는 생일로 성격·관계를 추론하는 명리 규칙, 합충 가중치, 실제 궁합 점수가 구현돼 있지 않다. 기존 결과의 문구 5개(label/title/strength/difference/advice)는 모든 입력에 같은 일반 대화 예시였다. 이번 검토는 실제 존재하는 문구의 명료성·근거 표시와 저장 경로를 감수한 것이다. 명리 전문가 검토나 실제 궁합 타당성 검증을 완료한 것으로 표시하지 않는다.

[풀이 카탈로그](../web/content/readings.json)에 검토자 Codex, 검토일, 검토 범위와 `domainReview.status=pending`, `productionApproved=false`, `birthDerived=false`를 기록했다. 두 버전 모두 `generic-conversation-example`이다. 숫자 점수, 출생 기반 판단, 승인 완료로 바뀐 자료는 현재 로더가 거절한다. 이 구조는 향후 실제 규칙을 승인하는 경로가 아니다.

| 항목 | 검토·수정 | 판정 |
|---|---|---|
| 결과 라벨 | 새 버전은 ‘생일과 무관한 대화 예시’로 명시 | 출생 정보에서 도출한 내용이라는 오해 축소 |
| 제목 | ‘서로의 하루를 나눠 보세요’라는 제안으로 정리 | 타인의 성격·미래 단정 없음 |
| 함께 할 점 | 함께 좋아하는 활동과 시간을 찾아보자는 기존 제안 유지 | 누구에게나 가능한 일반 제안 |
| 차이를 다루는 문장 | ‘느끼는 속도’라는 모호한 표현을, 같은 일을 어떻게 느꼈는지 묻고 들어보는 행동으로 수정 | 성향의 원인을 사주로 단정하지 않음 |
| 작은 제안 | 고마웠던 일을 서로 말해보자는 기존 문장 유지 | 결혼·이별·재물·건강을 예측하거나 강요하지 않음 |
| 숫자·지도 | score null, 기존 예시 배치 유지 | 실제 관계 확률·순위 근거로 쓰지 않음 |

검토한 금지·보류 예시는 ‘충이 있으니 반드시 다툰다’, ‘합이면 결혼이 성공한다’, ‘87% 확률로 잘 맞는다’, ‘시간 모름은 정오로 계산한다’다. 이런 내용을 새 문구로 추가하지 않는다. 건강·수명·재산·출산·이별에 대한 단정이나 공포·차별을 유발하는 문구도 근거 없는 관계 해석으로 사용하지 않는다. 자동 키워드 검사만으로 감수 완료를 판정하지 않는다.

## 발견한 두 저장 경로 문제와 수정

1. 대기 작업은 `comparisons.rule_version`을 저장했지만 완료 시점의 최신 `sampleReading`을 사용했다. 이제 저장된 버전으로 조회한다. `example-copy-v1` 원문을 카탈로그에 그대로 보존하고 새 작업만 v2로 만든다. 찾을 수 없는 버전은 최신 문구로 대체하지 않고 기존 실패/재시도·무료권 반환 절차로 종료한다.
2. 공유 생성은 결과 소유권을 확인한 다음 최신 예시 문구로 카드를 새로 만들었다. 이제 저장된 결과의 reading에서 공개 허용 필드만 복사한다. 별명 외 원본 생일·계산표·숨은 추가 필드는 포함하지 않는다. 기존 공유·구매 스냅샷은 갱신하지 않는다.

같은 입력의 기존 결과를 여는 동작은 문구·계산 버전 업데이트만으로 새 결과를 만들거나 재과금하지 않는다. 엔진은 v5, 새 예시 문구는 v2로 구분해 저장한다. 이전 v3/v4 계산과 v1 풀이가 섞인 대기 작업도 저장된 각 버전 그대로 처리한다. 구현: [readings.ts](../web/src/server/readings.ts), [service.ts](../web/src/server/service.ts).

## 실제 명리 풀이를 위해 남은 항목

| 항목 | 지금 확인한 것 | 남은 판정 |
|---|---|---|
| 연·월 경계 | 독립 천문 자료와 불확실성 후보 보존 | 계산 모델·시간척도 운영 채택 |
| 일·시주 | 현지 시계와 자정 정책의 구현 일관성 | 23시/0시·DST 제거·경도/균시차 적용 관습 |
| 오행·합·충 | 현재 사용자 풀이에 연결되지 않음 | 용어·조건·상충 규칙·명리 근거 |
| 시간 모름·경계 후보 | 값을 임의 확정하지 않음 | 모든 후보에 공통인 해석만 표시하는 조건 |
| 궁합 점수·지도 거리 | 점수 null, 가상 배치 | 가중치·근거·대칭성·동점 처리; 관계 성공률로 표현 금지 |
| 관계별 제안 | 일반 예시만 제공 | 가족/연인/친구/동료별 실제 결과 조합 검토 |
| 감수자·승인 | Codex의 편집·기술 검토 기록 | 명리 검토 담당자의 실명/버전별 승인, 사용자 이해도 확인 |

외부 인증·결제 설정은 이번 검토의 선행 조건이 아니다. 준비될 때 실제 왕복 검증을 진행한다.
