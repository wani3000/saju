# 관계별 상호작용 이야기 v7

2026-10-21 사용자가 예시의 총평·서로에게 주는 선물·닮은 부분·갈등 대화 형식을 참고해 모든 관계에 적용하도록 요청했다. 연인은 사랑과 서운함, 친구는 성격과 서로에게 어떤 도움이 되는지를 중심으로 다룬다.

신규 버전 `chunbae-relationship-story-v7`은 v6를 독립 복사한다. 개인 장단점은 유지하고 궁합을 총평 → 내가 주는 도움 → 상대가 주는 도움 → 닮은 부분 → 부담/서운함 → 실제 대화 예시 → 함께할 일 → 오래 지내는 방법으로 구성한다.

| 관계 | 주요 주제 |
|---|---|
| 연인 | 애정 표현, 데이트, 배려, 서운함, 화해, 함께 살 때의 생활 대화 |
| 친구 | 성격 차이, 고민/실행/꾸준함에 주는 도움, 취미·여행·공부, 부탁과 거절 |
| 가족 | 돌봄, 집안일, 개인 선택, 휴식, 부탁과 책임 분담 |
| 동료 | 아이디어·실행·검토, 담당/마감/완료 기준, 결정권, 피드백 |

도움은 방향을 구분해 설명한다. 제공자에게 확인된 대표 분류와 별도의 공통 확인 분류를 설명 예로 사용하고, 받는 사람의 대표 분류에 해당하는 배려와 연결한다. 대표 분류는 기존 편집 순서다. 실제 도움의 크기·가치·우세·상호 보완 성공을 측정하지 않는다. 공통 분류는 양쪽에 확인된 사실만 사용한다. 예시 대사는 실제 사건이나 앞으로 반드시 할 행동으로 표시하지 않는다.

새 본문 각 절의 근거는 사용한 개인별 사실에 직접 연결한다. 전체 사실·후보·시각 미상·계절·합충 관찰과 출처를 보존한다. 합충 관찰은 기록 펼침에서 확인하며 점수나 결혼 성공으로 바꾸지 않는다. 개인 장단점과 구버전 원고/스냅샷을 유지하고 신규 결과만 v7이다. 공개 카드에는 사적인 도움 방향·대화·사주 근거가 추가되지 않는다.

검증: 네 관계, 도움 방향을 뒤집었을 때의 일관성, 실제 생일 변경 민감도, 이전 원고 불변, 공개 비식별, 경계 후보·시간 미상 검사를 수행한다. 결과는 배포 기록에 남긴다.

원고는 전통 분류에 기대어 만든 편집 해설이다. 공통 분류의 첫 항목과 개인 대표 항목을 설명 순서로 택하는 것은 강약 순위가 아니다. 모든 관계를 무조건 ‘보완 관계’로 부르지 않으며, 실제 필요한 도움을 확인하는 대화와 도움을 거절할 여지를 함께 둔다.
