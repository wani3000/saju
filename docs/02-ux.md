# 화면과 사용자 흐름

## 기본 화면 구조

기본 내비게이션은 ‘궁합 보기’와 ‘내 지도’ 정도로 제한한다. 계정·결제 내역·도움말은 보조 메뉴에 둔다. 2026-10-14 호랑이 시안 2번을 선택해 로컬 클릭 시안으로 구현했다. 아래는 화면 동작과 문구 초안이다.

| 화면 | 내용 | 주 버튼 | 뒤로 가기와 오류 |
|---|---|---|---|
| 시작 | 나와 이 사람, 얼마나 잘 맞을까요 / 첫 한 명 무료 | 무료로 시작하기 | 재방문이면 내 지도 노출 |
| 내 정보 | 별명, 생년월일, 달력 구분, 시간 선택 | 다음 | 입력 보존, 틀린 필드 바로 아래 설명 |
| 상대 정보 | 상대 별명, 생년월일, 관계 | 무료 궁합 보기 또는 2,900원에 보기 | 내 정보 요약과 수정 링크 |
| 입력 확인 | 두 사람 정보, 시간 모름, 가격 | 결과 보기 또는 결제하기 | 편집 후 돌아와도 값 유지 |
| 저장/인증 | 구매 복원 목적의 짧은 설명 | 간편 로그인 | 입력과 주문 초안 보존 |
| 결제 | 대상 상대, 금액, 상품 내용 | 2,900원 결제 | 취소는 상대 입력으로, 재결제 전 상태 확인 |
| 처리 중 | 두 사람의 궁합을 보고 있어요 | 상태에 따라 다시 확인 | 중복 생성 금지, 새로고침 복원 |
| 결과 | 요약 → 설명 → 공유 → 지도 → 추가 | 한 명 더 추가하기 | 같은 사람 결과는 즉시 재열람 |
| 공유 미리보기 | 공개할 별명과 내용 | 링크 만들기 | 취소 시 공개 링크를 만들지 않음 |
| 내 지도 | 지도/목록, 기존 사람 선택 | 한 명 더 추가하기 | 빈 지도는 첫 상대 추가 안내 |

## 입력 상세

- 날짜는 4자리 연도·월·일을 각각 입력한다. 키보드로 입력 가능하고 모바일 숫자 키패드를 사용한다.
- 레이블은 입력 후에도 항상 보인다. placeholder만으로 필드 이름을 전달하지 않는다.
- 날짜 선택을 위해 달력을 수십 년 넘기게 하지 않는다.
- 양력/음력은 큰 선택 버튼, 음력 선택 시에만 윤달 옵션을 보여준다.
- 출생 시간은 ‘알아요 / 몰라요’. 모름은 실제 null로 저장한다.
- 정확한 시간 입력은 시·분을 사용한다. 대략적인 시각은 MVP에서 정밀 결과로 오인시키지 않는다.
- 지원 연도·국내 출생 범위를 필드 근처에서 안내한다. 현재 연도 이후 날짜, 존재하지 않는 날짜, 없는 음력 윤달을 차단한다.
- 관계 정보는 사주 계산 입력이 아니라 설명 선택 입력이다.
- 성별은 MVP의 고정 관계 비교에 필요하지 않으면 수집하지 않는다. 라이브러리 기본 성별이 계산에 유입되지 않게 한다.
- 상대방 정보를 넣는다는 점과 별명 사용을 짧게 안내한다. 원문 생일을 공유하지 않는다.

## 결과 정보 우선순위

1. ‘나와 민수님의 궁합’과 한 줄 관계 요약.
2. 잘 맞는 점 최대 2개.
3. 서로 다른 점 최대 2개.
4. 잘 지내는 방법 최대 2개.
5. 이 궁합 공유하기.
6. 가까운 사람 지도, 지도/목록 전환.
7. 한 명 더 추가하기 · 2,900원.

각 설명은 1~3문장을 기본으로 한다. 명리학 전문 용어와 상세 근거는 접힌 상세 영역에 둔다. 순위·숫자만으로 상대를 평가하게 만들지 않는다.

## 글씨와 접근성

본문 18~20px, 주요 제목 28~32px, 버튼 글씨 18px 이상, 버튼 높이 56px 이상을 디자인 기준으로 한다. 충분한 행간과 진한 글씨를 사용한다. 실제 명암비·포커스·확대·보조기기 지원은 테스트로 확인한다.

- 320~430px 모바일 폭에서 가로 스크롤 없이 입력 가능.
- 글자 200% 확대 시 문구·버튼 잘림 없음.
- 현재 단계와 입력 오류는 색만으로 표현하지 않음.
- 버튼 누른 뒤 처리 상태와 결과 이동을 보조기기에 알림.
- 지도는 보조 표현이다. 같은 정보와 행동을 목록에서도 제공.
- 모달이 필요하면 포커스 이동·가두기·닫은 후 복귀 구현. 불필요한 설명 모달은 사용하지 않음.

## 필수 예외

- 새로고침: 서버에 저장한 draft ID를 이용해 같은 진행 단계 복원.
- 연결 끊김: 입력 유지, 다시 시도. 중복 무료권/주문 생성 방지.
- 이미 추가한 상대: 새 결제 대신 기존 결과 안내.
- 로그인 실패: 초안 유지. 첫 무료 결과를 이미 봤다면 돌아갈 수 있음.
- 같은 생일의 다른 사람: 자동 합치지 않는다. 별도 사람임을 확인한다. 계산 내용이 같을 수 있음을 설명.
- 익명 세션 유실: 복원 불가능할 수 있음을 저장 전에 설명. 이를 막으려 과도한 가입 벽을 첫 화면에 두지 않음.
- 추가 사람 생성 실패: 기존 지도와 기존 결과는 계속 사용 가능.

## 사용성 검증

P02에는 합성 데이터로 전체 흐름을 수행하는 클릭 시안을 만든다. P08에는 작은 글씨를 어려워하는 성인/고령 사용자 5명 정도를 모집하는 소규모 관찰을 제안한다. 첫 결과, 결과 공유, 두 번째 추가, 기존 결과 재열람을 진행자가 대신 누르지 않고 수행하는지 기록한다. 이는 통계적 대표성 주장 없이 발견용 테스트로 사용한다.

## 캐릭터 적용

[캐릭터 적용 설계](13-character-plan.md)에 따라 입력에는 작은 안내 캐릭터, 결과에는 두 캐릭터와 이름, 지도에는 이름을 병기한 노드를 사용한다. 입력에 캐릭터 선택 단계를 추가하거나 글씨를 줄이지 않는다. 새 시작 화면 3안은 생성·선택 대기 상태이며 선택한 방향을 결과·지도 화면으로 확장한다. 사주햄찌의 확인 범위는 [공개 흐름 분석](sajuham-audit.md)을 따른다.

현재 구현과 운영 설계의 차이는 [시안 실행 안내](../prototype/README.md)에 기록했다.
