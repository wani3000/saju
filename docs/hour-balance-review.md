# 시상 왕기·파상·자조와 일반 강약·중화 후속 감수

2026-10-19. `hour-damage-relational-balance-review-v1`은 원문 조건을 조사하는 연구 버전이다. 일반 강약·중화 분류기와 합화 충분조건은 아직 완성되지 않았다. 원전의 기술을 확인한 것이며 현대적 예측 타당성이나 전문가 감수 승인을 뜻하지 않는다.

## 직접 확인한 근거

[『三命通會』 1926년 판본](https://commons.wikimedia.org/wiki/File:NLC416-13jh000156-94145_三命通會.pdf)의 PDF 128~129쪽(卷二 50~51쪽)을 직접 읽었다. 앞선 『命理集成』의 간접 인용에 더해 본서의 시상 왕기 구절과 다섯 선호 시주를 확인했다. 전체 PDF 해시와 쪽 이미지, 선택 전사는 [새 출처 명세](../research/validation/fixtures/reading-sources/hour-balance-sources.json)에 고정했다. 455쪽 파일은 소장본 두 책의 스캔이며 목차에 실린 전체 권차의 수록을 보증하지 않는다.

『命理集成』 PDF 30쪽의 토 합화 파상·자조 예시, 『滴天髓闡微』 PDF 176·189쪽의 일반 강약·중화 설명도 이미 보존한 원본 이미지로 재대조했다. [선택 전사](../research/validation/fixtures/reading-sources/hour-balance-transcription.json)는 구두점·생략 부호를 추가한 발췌이며 원문 전체가 아니다.

## 시상 왕기

『三命通會』는 월중 왕기가 없어도 시상 왕기가 있으면 사용할 수 있다고 서술한다. 월중 왕기가 있어도 시상 왕기를 얻지 못한 경우는 별도로 다룬다. 그러나 이 단락에는 모든 시주에 적용할 수 있는 왕기 정의가 없다.

| 합 | 喜로 제시한 시주 | 함께 제시한 월지 |
|---|---|---|
| 갑기 | 무진 | 진·술·축·미 |
| 을경 | 경진 | 신·유 |
| 병신 | 임진 | 해·자 |
| 정임 | 갑진 | 인·묘 |
| 무계 | 병진 | 사·오 |

사계월을 진술축미로, 각 쌍의 양쪽 일간에 같은 예시를 적용하는 것은 명시적 연구 정규화다. 위 월지는 앞선 기본월·예외월 목록과 다른 문맥의 예시이므로 이전 목록을 교체하지 않는다.

코드는 일간의 합 상대 존재, 선호 시주 전체 일치, 동반 월지 일치, 쌍의 중복을 같은 후보 조합에서 기록한다. 원문의 생왕·유기, 인접 기피 조건, 중화와 파상 조건은 별도로 남긴다. 따라서 `preference-example-matched`는 표의 부분 조건 일치일 뿐이다. `wangQiEstablished`와 `transformationEstablished`는 null이다. 미수록 시주·월을 불성립으로 변환하지 않는다.

## 파상·자조

『命理集成』은 **이미 토로 화하는 격**에서 추가 천간이 **暗地化**한다는 전제로 다음 예시를 든다.

| 추가 쌍 | 가정한 변화 | 토에 대한 원문 관계 |
|---|---|---|
| 을경 | 금 | 도설토기(盜洩土氣), 파상 |
| 정임 | 목 | 손상토질(損傷土質), 파상 |
| 무계 | 화 | 토의 인(土之印), 자조 |
| 병신 | 수 | 토의 재(土之財), 자조 |

코드는 같은 후보 조합에서 두 글자의 존재를 확인하고 조건부 예시를 표시한다. 기본 토 합화, 추가 합의 변화, 유효한 파상·자조의 세 전제는 각각 null로 유지한다. 갑기 상대가 보이지 않는 경우도 별도로 표시한다. 다른 대상 오행으로 확장하지 않는다.

『三命通會』 갑기 선호 시주 단락의 화 기피와 『命理集成』의 화토 자조는 전제·문맥을 더 대조해야 한다. 화가 있다는 이유로 일괄 도움 또는 방해라고 정하지 않는다. 이 출처 차이는 새로운 우선순위나 가중치로 해소하지 않았다.

## 일반 강약·중화

『滴天髓闡微』는 월령을 중시하면서 연·일·시의 손익도 함께 보며, 봄 목이라도 금이 지나치게 무겁거나 가을 목이라도 뿌리가 깊은 반례를 설명한다. 천간 수보다 뿌리의 힘을 중시한다는 설명도 있다. 이들은 득령 하나 또는 개수 합계로 강약을 고정할 수 없다는 근거다. `太重`, `根深`을 자동 판정할 수치 문턱은 확인하지 못했다.

중화 항목의 재경겁중·관쇠상왕·살강제약·제강살약을 다음 일반 검토 항목으로 연결했다.

- 재성/겁재: 편재·정재와 겁재의 존재 근거.
- 정관/상관: 두 분류의 존재 근거.
- 칠살/제어 후보: 편관과 식상의 생극 관계 근거. 원문 `制`를 식상에만 한정하지 않으며 제살 성립은 미판정.

각 항목은 천간과 지장간의 위치·일주 후보·관찰 근거를 제공한다. 양쪽 존재, 경중·왕쇠, 유효한 제어는 서로 다른 판단이다. 양쪽이 관찰되어도 원문의 불균형이 성립했다고 선언하지 않는다. 한쪽이 관찰되지 않아도 중화로 처리하지 않는다. 일간 자신을 비견 하나로 중복 계수하지 않는다.

전체 입력 경로는 이전 사령·투출·통근·강약 요소, 네 원문 강약 사례 및 출처별 합화 조건을 `previousReview`에 보존하고 이번 관찰을 추가한다. 이전 모듈·보고서·웹·구매 결과는 수정하지 않았다.

## 후보·경계·검증

월주와 시주는 천간·지지를 통째로 유지한다. 특히 무자와 무진을 같은 시주로 취급하지 않는다. 월의 서로 배타적인 후보에서 합 상대와 추가 쌍을 각각 가져와 성립시키지 않는다. 불확실한 기둥 사이의 일부 교차 조합은 실제 동시 성립이 증명되지 않은 검토 가능성이다.

일반 중화의 양쪽 존재 검사는 각 기둥 후보 안의 모든 관찰을 두 비트로 축약한 뒤 조합한다(1=왼쪽, 2=오른쪽, 3=양쪽). 같은 일주 후보의 일간·지장간을 유지한다. 이 비트는 강도나 점수가 아니다. 시각 미상은 관찰에서 제외하고 미관찰을 부재로 단정하지 않는다. 달력·역사 시계 검토 플래그를 전달하고 개인정보 필드를 복사하지 않는다.

[19사례 보고서](../research/validation/reports/hour-balance-drafts.md): 다섯 쌍 양방향 10개, 토 파상·자조 4개, 일반 중화 3개, 실제 입력 경로 2개. 합성 기둥 예시는 실제 생년월일 명조가 아니다.

```sh
node research/validation/build.mjs
pnpm --dir research/validation test
node research/validation/audit-hour-balance.mjs --check
node research/validation/audit-hour-balance.mjs --release-check
python3 tools/check_docs.py
```

신규 테스트는 원전 파일 해시, 다섯 쌍 양방향, 시주 전체 일치, 미수록월·시간 모름·중복, 네 조건부 파상/자조, 후보 상관관계, 동적 관찰과 16개 고정 명조 전수 비교, 개인정보·경계, 이전 및 신규 보고서 재현을 검사한다. `--release-check`의 종료 코드 2는 미승인 상태를 뜻한다.

남은 범위: 시상 왕기의 완전한 정의, 합화 인접 기피 조건과 출처별 충돌, 실제 파상·자조 성립 및 구응, 일반 강약의 태왕/왕극·태쇠/쇠극 경계와 중화 기준. 오월 사령표의 누락 위치와 보정값도 미확정이다. 외부 인증·결제 연동은 준비 후 진행한다.
