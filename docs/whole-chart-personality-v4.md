# 전체 사주 성격·궁합 풀이 v4

2026-10-21 사용자가 일간 외에 사주 전체를 반영해 성격과 궁합을 구체화하고 검증 뒤 체험판·GitHub를 갱신하도록 요청했다. 신규 결과는 whole-chart-personality-copy-v4를 사용한다. 계산 엔진은 v5 그대로이며 기존 v1/v2/v3 결과·구매/공유 스냅샷은 변경하지 않는다.

## 실제 반영 범위

| 개인 성격 | 두 사람 궁합 |
|---|---|
| 알려진 연·월·일·시 각각의 천간과 지장간 | 각자의 알려진 모든 기둥 간 천간 합·지지 육합·육충 |
| 일간 기준 십성 10분류, 겉 천간과 지장간의 위치 구분 | 두 사주의 공통/다른 십성 묶음 및 같은 기둥 자리의 세부 십성 비교 |
| 월지의 계절 배경, 후보는 함께 보존 | 두 월지의 계절 배경과 생활 리듬에 대한 질문 |
| 같은 오행의 지장간 연결, 개인 차트 내부 합충 | 일지의 지장간과 확인된 쪽의 시주가 더하는 관계 해설 |
| 근거가 붙은 장점·주의·친밀감 표현·업무 방식 | 구체적인 대화의 바람·실행 제안·기둥별 근거 펼침 |

일간의 열 가지 기본형은 출발점으로 남기되, 본문과 제목에 다른 기둥의 결을 함께 반영한다. 같은 일주여도 월주나 출생 시간이 달라지면 성격·궁합 해설이 달라진다. 시주를 모르면 해당 천간/지장간/합충을 제외한 세 기둥으로 읽고, 한 사람만 시간을 알면 그쪽 시주만 비교한다.

## 정의와 해석

정의는 기존 [십성·지장간 원전 대조](natal-rules-review.md)와 [합충 표](reading-rules-review.md)의 고정 연구 분석기를 사용한다. [도서관 원목록](https://taiwanebook.ncl.edu.tw/zh-tw/book/NTL-9900014379)에서 확인한 1926년 『淵海子平子平真詮 v.1』 판본의 기존 전사·쪽별 근거를 재사용하며, 원전이나 기존 감수 보고서를 이번 개발 때문에 수정하지 않았다. 지장간 목록은 본기/중기/여기 가중치 순서로 바꾸지 않는다. 한국어 십성 용어의 기존 연구 정책과 감수 대기도 유지한다.

성격 문장과 ‘자기 기준/표현/실행/책임/이해’의 다섯 묶음, 계절을 생활 장면에 빗댄 문장은 별도의 편집 해설이다. 정의가 원문에 있다는 사실을 성격 예측의 타당성이나 전문가 승인으로 확대하지 않는다. 월간→시간→연간→일지 순서는 대표 대화의 예를 고르는 표시 순서이며 강약·중요도 순서가 아니다. 모든 공통 십성은 근거 펼침에 남긴다.

월령은 월지의 계절 맥락을 반영한다. 사령 일수 배분·가중치를 적용한 종합 신강/신약, 용신, 합화 최종 판정은 추가하지 않았다. 합과 충이 함께 있으면 둘 다 남기며 상쇄하거나 점수화하지 않는다. 지장간 반복을 전체 오행 비율로 표시하지 않고, 확인되지 않은 십성을 없는 성격/부족함으로 표현하지 않는다. 가족·배우자·직업·재물·건강·미래의 결과를 판정하지 않는다.

## 후보와 보존

- 기존 엄격한 v5 차트 검증 후 analyzeNatal/compareProfiles를 실행한다. 원시 분석기와 출처는 변경하지 않고 웹 번들에는 필요한 정의 JSON을 내장한다. 키·DB·서버 파일은 정적 배포에 포함하지 않는다.
- 십성/합충은 supplied candidates 전체에 공통인 항목만 확정 문장으로 연결한다. 일부 후보의 사실·가상 공동 사주·후보 비율은 출력하지 않는다. 후보 월지에서 계절 하나를 임의로 고르지 않는다.
- 전체 해설은 생성 시 결과 JSON에 저장한다. 과거 결과를 현재 카탈로그로 다시 쓰거나 새 규칙을 묵시 적용하지 않는다. v3의 일간 풀이도 해당 버전으로 계속 조회할 수 있다.
- 공개 카드는 기존처럼 별명과 일반 대화만 남기고 wholeChart/interpretation/출생/한자/십성/근거를 제거한다. 프리뷰의 로그인·실결제·공개 링크 미연동과 탭 저장/전송 차단은 유지한다.
