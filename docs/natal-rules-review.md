# 지장간·십성·월령의 후속 감수 · 2026-10-19

추가 후속: [월령·합화 조건과 관계별 풀이 감수](month-combination-review.md)에서 월지 투출·뿌리 연결·합의 위치 맥락을 구현했다. 아래 초기 버전과 초안은 보존한다.

## 구현한 범위

『評註淵海子平』 1926년 판본의 정의 구절을 추가 대조해 **12지지의 지장간 28항목, 일간 기준 100개 천간 조합의 십성 분류, 월지 후보 보존과 감수용 한국어 문장**을 연구 모듈로 구현했다. 원문 대조는 Codex의 수기 판독이며 전문가 감수나 운영 승인이 아니다. 십성 명칭에는 아래에 공개한 별도의 용어 정책이 들어간다.

기존 `symbol-relations-research-v1`과 그 보고서는 유지한다. 새 규칙은 `natal-definitions-research-v1`, 문장 초안은 `natal-review-copy-v1`이다. 웹의 `example-copy-v2`에는 연결하지 않았다.

## 확인한 원전

[도서관 목록](https://taiwanebook.ncl.edu.tw/zh-tw/book/NTL-9900014379)의 동일 판본에서 전체 페이지 이미지를 추가 추출했다. [출처와 이미지 해시](../research/validation/fixtures/reading-sources/natal-source.json), [선택 구절·목록 전사](../research/validation/fixtures/reading-sources/natal-transcription.json)를 보존했다. 인쇄 쪽수는 권별로 직접 확인했으며 PDF 쪽수에서 일정 수를 빼서 추정하지 않았다.

지장간 원문 순서는 축=계·신·기, 진=을·무·계, 사=경·병·무 등이다. 이를 **본기·중기·여기 순서로 간주하지 않는다**. 원문 중 숫자 표현이나 53쪽의 사령 일수를 그대로 백분율로 바꾸지 않는다. 현재 구현에 지장간 가중치·오행 비율은 없다.

## 용어 정책과 미승인 부분

| 일간 기준 방향 | 같은 음양 | 다른 음양 |
|---|---|---|
| 같은 오행 | 비견 | 겁재 |
| 일간이 대상을 생함 | 식신 | 상관 |
| 일간이 대상을 극함 | 편재 | 정재 |
| 대상이 일간을 극함 | 편관 | 정관 |
| 대상이 일간을 생함 | 편인 | 정인 |

이 표의 한국어 명칭은 `korean-ten-gods-research-v1` 연구 정책이다. 원전 한 페이지에 이 표가 그대로 있다고 주장하지 않는다. 특히 112쪽은 갑→을을 敗財, 을→갑을 劫財로 구별한다. 두 방향 모두를 ‘겁재’로 부르는 선택과 같은 음양의 ‘비견’ 명명은 **용어 감수 대기**로 기록했다. 印綬를 정인, 七殺을 편관으로 설명하는 명명도 같은 검토 범위다. 羊刃은 별개의 조건이므로 겁재의 동의어로 처리하지 않는다.

십성은 방향이 있다. 갑에서 병을 보면 식신, 병에서 갑을 보면 편인이다. 합충 쌍의 A/B 대칭성 검사를 십성에 적용하지 않는다. 일간 자체를 비견 항목 하나로 추가하지 않지만, 일지의 실제 지장간에 일간과 같은 천간이 있으면 그 항목은 비견으로 분류한다.

## 불확실성 처리와 문장

- 시간 모름은 시주의 천간·지장간을 모두 제외한다. 누락을 0점이나 불리함으로 바꾸지 않는다.
- 일주가 여러 후보이면 각 일간은 **그 일주 후보의 지장간**과만 연결한다. 갑자/을축 후보에서 갑 일간과 축의 기를 섞어 정재라고 출력하지 않는다.
- 다른 기둥끼리의 후보는 현재 엔진이 완전한 공동 사주를 제공하지 않으므로, 일부 교차 조합만의 분류를 `not-established-from-marginal-candidates`로 남긴다.
- 후보 전체에서 같은 대상 천간·십성 분류가 유지되는 항목만 확정형 감수 문장에 넣는다. 공통 지장간은 보존하고, 일부 후보 전용 문장과 후보 비율은 만들지 않는다.
- `all-candidates`는 공급된 연구 후보 내부의 공통성이다. 역사 시각·천문 정확도 승인이라는 뜻이 아니다. 절기 경계·역사 시계 검토 표시를 초안에도 전달한다.
- 생년월일·별명·UTC 시각은 새 보고서에 복사하지 않는다. 보고서는 합성 자료로만 생성한다.

[읽을 수 있는 초안 6사례](../research/validation/reports/natal-reading-drafts.md)와 [전체 분석 JSON](../research/validation/reports/natal-rule-audit.json)을 함께 생성한다. 문장은 원전의 분류를 설명하는 감수 자료다. 사람의 성격이나 두 사람의 관계를 예측하는 실제 상품 풀이로 완료 처리하지 않는다.

## 남은 순서와 적용 조건

1. **월령·강약:** 절기 내 시점, 사령 학설, 통근·투간, 지장간 가중치와 충돌 기준을 대조해야 한다. 현재 `monthContext`는 월지 후보만 보존하고 `seasonalStrength`는 null이다.
2. **합화·합충 우선순위:** 위치·거리, 같은 천간의 중복, 다른 합충과의 공존, 월령 조건을 검토할 사례를 정해야 한다. 이 목록은 후속 감수 항목이며 원전에서 승인된 실행 조건표가 아니다. 짝 분류를 곧바로 합화 성립으로 바꾸지 않는다.
3. **관계별 실제 풀이:** 규칙·용어·해석 감수 후 근거와 문장을 연결한다. 현재 초안의 분류 사실에서 성격·배우자·재물·건강 결과를 추론하지 않는다.
4. **점수·지도:** 개별 사주의 십성이나 오행 목록만으로 대칭 궁합 점수·거리를 정당화할 수 없다. 쌍 비교의 의미, 중복 집계, 시간 모름의 공통 범위, 가중치와 상한을 먼저 정하고 승인된 새 버전으로 도입해야 한다. 현재 점수는 null이다.
5. **운영 적용:** 달력·역사 시각 정책 및 콘텐츠 승인이 끝나면 웹에 별도 버전으로 연결하고 기존 구매 결과를 보존한다. 외부 로그인·결제는 사용자 요청대로 준비 후 검증한다.
