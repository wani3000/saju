# 출시 후보 계산 정책과 예외 처리

2026-10-20. **현재 로컬 설명판에서 사용할 권장 정책**이다. 구현된 v5와 같은 기준으로 안내를 고정하며, 계산 전문가의 운영 채택 승인을 대신하지 않는다. 점수 없는 첫 베타와 기존 유료 궁합 계획은 [현재 범위](beta-scope-and-quality.md)를 따른다.

## 권장안

| 항목 | 현재 적용·권장 기준 | 다른 관습과의 구분 |
|---|---|---|
| 출생지·연도 | 국내 출생, 입력 연도와 양력 환산 연도 모두 1908~2026, 미래 생일 거절 | 해외·지원 연도 확대는 별도 검증 후 진행 |
| 연주·월주 | 당시 시간대에서 환산한 시각과 입춘·절입 기준 | 음력 연·월의 간지를 사주 연·월로 전용하지 않음 |
| 일주·시주 | 현지 시계, 자정 일 경계, 태양시 보정 없음 | 23시 일 경계나 진태양시를 선택 가능한 검증 완료 옵션처럼 제공하지 않음 |
| 시간 모름 | 시주 없음, 날짜 구간에서 가능한 연·월주 후보 보존 | 정오·임의 시각을 대입하거나 후보를 확률순으로 정렬하지 않음 |
| 절입 경계 | 입력 분·날짜가 절입 ±120초의 임시 검토 폭과 겹치면 후보 유지 | 임시 폭은 천문 오차의 보증 구간이 아님 |
| 1954년 | 기존 중복 시각 거절 + 3월 21일 00:00~00:29 거절, 시간 모름의 검토 표시 | 관보와 고정 시간대 자료의 차이를 임의 수정하지 않음 |
| 과거 시계 변경 | 사라진 시각과 중복 시각은 서로 다른 사유로 거절 | 시각 자동 보정이나 먼저/나중 시각 자동 선택 없음 |
| 풀이 비교 | 연·월·일의 전체 후보에 공통인 기호만 사용 | 강약·합화 최종 판정·궁합 점수는 제공하지 않음 |
| 결과 보존 | 생성 당시 입력·계산·풀이 버전 유지 | 정책 수정으로 과거 구매/저장/공유를 자동 재계산하지 않음 |

기계 검사용 안내 원본은 [research-policy.json](../web/content/research-policy.json)이다. 이 파일은 계산 엔진을 덮어쓰는 설정이 아니다. 웹의 입력 전 안내에 사용하고, 테스트가 실제 엔진 정책·경계 폭·베타 범위와 대조한다. 저장 결과 상세는 계속 저장 당시 정책을 읽는다.

## 남긴 제한과 확인할 결정

- 1908년 4월 이전 서울 지역 평균시가 모든 출생지 기록의 시계 관행을 증명하지 않는다.
- 1972년 이전 연구용 시각 좌표를 당시 현대 UTC 실현의 확정으로 표현하지 않는다.
- 1954년 시행 시계의 해석과 독립 절기 모형의 분 경계 차이는 최종 미해결이다. 기존 보호를 유지한다.
- 양력 1908년 1월은 지원하지만 그 날짜의 음력 1907년 입력은 현재 지원하지 않는다. 음력 2026년 말이 양력 2027년으로 넘어가는 경우도 거절한다.
- 특정 날짜를 제외하면 모든 다른 날짜가 검증됐다는 뜻은 아니다. [달력 근거와 검증 한계](calendar-reading-release-review.md)를 함께 전달한다.

계산 검토자는 위 항목별로 `채택 / 수정 필요 / 범위 제외 / 보류`와 이유를 남긴다. 승인 시 엔진·안내·지원 범위의 버전, 예외 사례, 회귀 검사와 남긴 제한을 함께 고정한다. 현재는 서명·운영 승인이 없는 권장안이다.

## 이번 보완의 실제 동작

입력 전 안내에서 자동 저장·계산 범위·시간 관습·기호의 의미·공유·삭제를 확인할 수 있다. 과거 시계의 중복·소실·범위 밖 환산은 일반 날짜 오류 대신 구분된 안내를 보낸다. 입력·무료권·결제·저장 결과를 자동 보정하지 않는다.
