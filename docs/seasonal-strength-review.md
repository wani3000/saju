# 사령·종합 강약 요소·합화 필요조건 감수 · 2026-10-19

## 구현한 범위

사령을 실제 출생 입력의 절입 후 경과 구간에 연결하고, 사령·월지 투출·통근·생극 관계를 한 결과에서 대조한다. 합화는 일간이 갑 또는 기인 경우의 **확인한 필요조건**을 평가한다. 종합 강약의 신강/신약 분류와 합화의 충분조건을 모두 확정한 것은 아니다.

사령 버전은 `yuanhai-command-nominal-days-v1`, 통합 감수 버전은 `seasonal-strength-transformation-review-v1`이다. [읽기용 12사례](../research/validation/reports/seasonal-review-drafts.md), [기계 판정](../research/validation/reports/seasonal-review-audit.json), [계산 코드](../research/validation/seasonal-command.mjs), [통합 감수 코드](../research/validation/strength-transformation-review.mjs)를 함께 보관한다. 웹·구매 결과·기존 연구 버전은 변경하지 않았다.

## 원문과 사령 배분

1926년 『評註淵海子平』의 PDF 53~54쪽(卷一 인쇄 三五~三六) **又論節氣歌**, PDF 167쪽(卷三 二二) **論運化氣**, PDF 171쪽(卷三 二六) **神趣八法의 化象**을 직접 대조했다. [원본 PDF 출처](https://upload.wikimedia.org/wikipedia/commons/f/fa/NTL-9900014379_%E6%B7%B5%E6%B5%B7%E5%AD%90%E5%B9%B3%E5%AD%90%E5%B9%B3%E7%9C%9F%E8%A9%AE_v.1.pdf), [선택 전사](../research/validation/fixtures/reading-sources/seasonal-transcription.json), [쪽 이미지·전사 해시](../research/validation/fixtures/reading-sources/seasonal-source.json). 원본은 207쪽이며 파일 이름의 v.1과 달리 이 스캔 안에 卷三까지 들어 있다.

旬은 10일, 중·하순은 20일로 풀었다. ‘나머지’로 적힌 기·임 등은 명목 30일을 기준으로 계산했다. 이는 **선택한 연구 정규화**이며 실제 절기월이 모두 30일이라는 뜻이 아니다. 사월의 순서나 신월의 기·무를 익숙한 다른 표로 교체하지 않았다. 본문 바로 앞의 별도 節氣歌와도 무조건 같은 표라고 취급하지 않는다.

오월의 `丁火十日九日己`는 스캔에서 九를 확인했다. 九를 十으로 고치거나, 누락된 하루가 마지막에 있다고 추정하지 않는다. 일수 충돌의 위치가 확인되지 않았으므로 **첫날부터 해당 표에 따른 확정 사령을 내지 않는다**. 자월의 임, 신월의 기는 정적인 지장간 목록과 다르며, 이를 이유로 기존 지장간 정의를 고치지 않는다.

## 실제 입력에 연결한 시간 정책

- 어댑터 v5에서 음력을 양력으로 정규화하고 역사적 시간대를 적용한다. 알려진 시간은 입력한 1분 구간, 시간 모름은 실제로 존재한 날짜 전체 구간을 사용한다.
- 직전 절입에서 **86,400초가 지난 것을 1일**로 세는 연구 관습을 선택했다. 현지 날짜의 자정 횟수를 세거나 실월 길이에 비례해 30등분하지 않는다. 원문에 분·초 경계가 명시됐다고 주장하지 않는다.
- 절입의 기존 임시 검토 폭 ±120초를 내부 사령 변경 경계에도 전파한다. 경계 양쪽과 겹치면 두 천간을 남긴다. 이 폭은 검증된 오차 한도가 아니다.
- 명목 30일을 넘어가는 실제 절기월 구간은 마지막 천간으로 연장하지 않는다. `outside-source-scheme`으로 남긴다. 2024-05-05 00:00의 진월 입력이 실제 회귀 사례다.
- 절입 당일의 복수 월주·역사 시계 검토는 사령을 확정하지 않는다. 이전 월의 경과일을 다음 월 후보에 붙이지 않는다.
- 반환값에는 생일이나 UTC 시각을 넣지 않고, 적용 버전·월지·사령 후보·미확정 이유만 남긴다.

## 종합 강약의 검토 기준

다음 항목을 한 객체의 독립적인 근거로 모은다. 아래 구조의 구현과 최종 강약 판정을 구분한다.

1. **사령**: 확정 가능한 천간과 일간 사이의 십성·생극 방향. 사령이 불확실하면 해당 관계를 임의로 채우지 않는다.
2. **월지와 투출**: 월지의 정적 지장간이 어느 천간에 드러났는지. 사령과 투출은 다른 항목이다.
3. **통근**: 같은 천간/오행의 지장간 관찰과 [원전 11사례의 등급](source-judgments-review.md)을 분리한다. 을·오, 정·유의 판본별 차이도 보존한다.
4. **주변 생극**: 일간과 같은 오행·일간을 생하는 관계, 일간이 생하거나 극하는 관계·일간을 극하는 관계를 위치·천간/지장간별로 기록한다. 일간 자체를 추가 비견으로 세지 않는다.
5. **상충·범위**: 생조와 다른 관계가 함께 있는지, 후보 일부에만 있는지, 시주가 빠졌는지, 사령이나 역사 시계가 미확정인지 기록한다.

이 목록의 개수·다수결, 지장간 나열 순서나 ‘무거움/가벼움’에 임의 가중치를 부여하지 않는다. 『子平真詮』의 월령만으로 강약을 정하지 말라는 설명은 통합 검토의 근거지만, 완전한 점수식이나 모든 차트의 이진 판정표는 아니다. 그래서 `strength.classification=null`과 구체적인 검토 사유를 반환한다. 사령을 연결했다는 이유만으로 신강·신약 엔진 완성이라고 표시하지 않는다.

## 갑기 합화의 필요조건 검토

PDF 167의 갑일·기일 대칭 설명과 171의 월령·경쟁 상대 설명을 적용했다. 171쪽에는 실제로 `甲乙日生人`이 인쇄돼 있다. 이를 전사에서 `甲己`로 조용히 고치지 않고, 분명한 갑기 합 설명과 167쪽의 대칭에 근거해 **갑일·기일의 갑기 합만** 구현 대상으로 삼았다. 기일에도 같은 월령 조건을 적용한 것은 이 연구의 명시적 대칭 정책이다.

| 검사 | 확인한 조건 | 불확실성 처리 |
|---|---|---|
| 월령 | 진·술·축·미 | 월주 후보의 천간·지지를 함께 보존 |
| 상대 | 일간과 합하는 다른 천간이 한 개 | 시주가 없으면 유일성 확정 불가 |
| 쟁합 | 추가 갑이 드러나는 예 | 원문의 갑기 범위에 한정; 모든 합에 일반화하지 않음 |
| 투합 | 을이 드러나는 예 | 숨은 을을 자동으로 드러난 을과 동일시하지 않음 |
| 중간 방해 | 갑·기 사이 경 또는 을 | 앞서 검토한 『子平真詮』 조건과 별도 출처로 결합 |
| 반복 기 | 기일에 기가 추가되는 경우 | 같은 쟁합 규칙으로 확대하지 않고 적용 범위 미검토 |

충족·미충족·자료 부족·후보 의존을 구분한다. 모든 후보에서 어떤 필요조건이 실패하더라도 **같은 실패 이유가 공통이라는 뜻은 아니다**. 결과에는 공통 실패 항목과 후보별 대안을 나눠 남긴다. 음양력 후보의 주변 조합은 실제로 가능한 공동 차트라고 단정하지 않으며 비율을 확률로 제시하지 않는다.

여기서 `reviewed-necessary-conditions-met`는 **검토한 필요조건의 충족**이다. 원문이 함께 요구하는 중화, 과다·부족과 다른 관계의 우선순위까지 확정한 충분조건이 아니다. 합화가 성립했다고 선언하거나 갑·기의 오행을 토로 바꾸지 않는다. 을경·병신·정임·무계의 전체 성립 조건도 구현 완료가 아니다. 이 합성 연구 정책은 두 원전의 모든 학설을 통일했다는 주장이 아니다.

## 검증과 다음 작업

전체 연구 126개, 엔진 빌드, 문서 연결 및 신규/이전 보고서 재현 검사를 통과했다. `--release-check`는 미승인 종료 코드 2다.

신규 22개 검사를 추가했다. 원전 해시·12월 표·각 배분 경계·오월 충돌·30일 초과·실제 절입과 내부 사령 경계·시간 모름·역사 시계·음양력 대응·실행 시간대 불변성을 검증한다. 갑기 양방향×12월, 쟁합·투합·중간 방해·후보 상관관계와 16개 고정 차트 전개를 대조했다. 통합 결과의 개인정보 제외와 기존 보고서 재현도 확인한다.

```sh
node research/validation/audit-seasonal-review.mjs --check
pnpm --dir research/validation test
# 운영 미승인: 종료 코드 2
node research/validation/audit-seasonal-review.mjs --release-check
```

다음은 오월 일수와 다른 사령 배분법을 다른 판본과 대조하고, 일수 경계 관습을 비교하는 일이다. 강약의 최종 분류와 합화 충분조건을 채택하려면 중화·과다·부족의 판단과 상충 사례를 추가로 정해야 한다. 관계별 해석·점수·지도·웹 연결은 그 뒤다. 외부 인증·결제 연동은 기존 요청대로 준비 후 진행한다.
