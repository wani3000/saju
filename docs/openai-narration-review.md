# OpenAI API로 사주 설명을 다듬는 방안

2026-10-22 공식 OpenAI Docs 조회 기준. 도입 검토 문서이며 API 연결·키 생성·유료 호출·한국어 품질 실험은 하지 않았다.

## 권장 역할

현재 엔진이 달력/사주 기호/확정 사실/보류 사항을 계산한다. 서버가 검토된 설명 범위를 선택한 뒤, 모델은 그 범위 안에서 김춘배 훈장의 쉬운 문장과 연인·친구·가족·동료의 구체적 대화 예시를 작성한다. 모든 계산과 미확정 판단을 모델에 맡기는 것은 권하지 않는다.

기대 효과는 반복 감소, 단락 연결, 친절한 설명, 관계에 맞춘 생활 예시다. 비용/지연/출력 변동과 근거 없는 판단 생성 가능성이 생긴다. 실제 개선 여부는 아래 평가 전에는 확정할 수 없다. 비싼 모델로 바꾸는 것만으로 강약·합화 규칙의 부족함이 해결되지 않는다.

## 가격 비교

[공식 가격](https://developers.openai.com/api/docs/pricing)의 Standard, 짧은 문맥, 캐시 없는 텍스트 요금. 단위는 USD/100만 토큰. 1회 입력4,000 + **총 과금 출력2,000**토큰을 가정했다. 한국어 글자 수와 토큰 수는 다르며 이번 값은 실측이 아니다.

| 모델 | 입력 | 출력 | 1회 | 1,000회 | 10,000회 | 검토 용도 |
| --- | --- | --- | --- | --- | --- | --- |
| GPT-5 nano | $0.05 | $0.40 | $0.0010 | $1.00 | $10.00 | 최저 단가 비교군 |
| GPT-4.1 nano | $0.10 | $0.40 | $0.0012 | $1.20 | $12.00 | 비추론 저가 비교군 |
| GPT-6 Luna | $0.10 | $0.50 | $0.0014 | $1.40 | $14.00 | 첫 도입 평가 후보 |
| GPT-6.1 Sol | $2.00 | $10.00 | $0.0280 | $28.00 | $280.00 | 품질 비교군, 기본 호출은 보류 |

공식 모델 목록은 비용 민감/대량 작업에 [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)를 제시한다. 이 작업에서는 **GPT-6 Luna를 먼저 평가**하고 GPT-5 nano와 비교하는 것이 합리적이다. 위 가정에서 1만 회 차이는 $4다. 한국어 설명 품질 우위가 실측된 것은 아니다. [GPT-5 nano](https://developers.openai.com/api/docs/models/gpt-5-nano)는 요약/분류 용도로 소개된 이전 모델이며 가장 낮은 명목 단가가 실제 최저 총비용을 보장하지 않는다.

[추론 토큰도 출력 요금으로 과금](https://developers.openai.com/api/docs/guides/reasoning#how-reasoning-works)된다. 가정한2,000토큰을 넘는 추론/장문, 재시도, 도구, 지역 처리, 서버 비용과 세금은 위 표에 포함하지 않았다. 캐시 할인도 가정하지 않았다. Luna는 공식적으로 reasoning.effort none을 지원하므로 제한된 문장 작성의 첫 비교 설정으로 검토할 수 있다. 모델별 지원 설정을 동일하다고 가정하지 않는다. 계정 사용 가능 여부와 한도는 미확인이다.

## 연결 구조

1. 기존 서버에서 계산하고 개인 식별값을 최소화한다. 이름은 A/B로 바꾸고 원 생년월일 대신 필요한 계산 사실·허용된 설명·관계 종류를 전달한다. 사주 정보도 외부 처리 대상이므로 단순히 완전 익명이라고 주장하지 않는다.
2. 원전 원문·전체 분석 JSON을 매번 던지지 않는다. 중복 출처를 제거한 필요한 근거 묶음과 금지/보류 결론만 전달한다.
3. Responses API와 [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)로 개인 설명/양방향 도움/대화/근거 ID/불확실성 항목을 받는 방식을 검토한다. JSON 형식 준수는 의미적 정확성 보장이 아니다.
4. 서버가 근거 ID, A/B 방향, 누락된 필수 조건, 확정 금지 항목, 길이를 검사한다. 의미상 새로운 결론을 만들었는지는 별도 표본 감수가 필요하다. 정규식이나 ID 검사만으로 환각을 전부 잡는다고 주장하지 않는다.
5. 시간 초과·거절·형식 오류·검증 실패 시 현재 v8 설명으로 돌아간다. 재시도 상한과 서버 측 사용자별 호출 한도/비용 상한을 둔다.
6. 결과는 모델/프롬프트/규칙 버전과 함께 저장한다. 새로고침마다 재생성하지 않고 사용자별 저장 결과를 재사용한다. 같은 요청의 동시 중복 호출도 제한한다.

현재 공개 preview는 브라우저 단독 정적 배포이며 외부 연결을 막는 구성이므로 키를 넣을 수 없다. 실제 적용에는 기존 Next.js 서버 측 생성 경로와 비밀 환경 변수, 체험판의 서버 호출 경로가 필요하다. API 키를 브라우저에 넣지 않는다.

[공식 데이터 정책](https://developers.openai.com/api/docs/guides/your-data): API 데이터는 기본적으로 모델 학습에 사용하지 않지만, 기본 오남용 모니터링 로그에 내용이 포함될 수 있으며 최대30일 보관될 수 있다. `store:false`만으로 모든 보관이 없어지는 것은 아니다. 실제 연결 전 외부 처리 안내·데이터 최소화·보관 정책을 정한다.

## 도입 판단용 평가 계획 — 아직 미실행

- 합성 입력40쌍 × 네 관계 =160결과를 두 후보 모델과 현재 v8으로 비교. 비용 표의 길이라면 두 API 후보 320호출의 기본 토큰 비용 합계 약$0.384. 실제 추론/길이/재시도에 따라 달라진다.
- 포함: 시간 모름/절기 경계/같은 십성 다른 자리/동시 선호·기피/중화 원전 사례/관계별 어휘.
- 우선 검사: 사주 사실 변경0, 보류 판단 확정0, 상대 뒤바뀜0, 관계 범주 혼입0. 실패 사례를 숨기지 않는다.
- 별도 감수: 쉬운 말, 훈장 말투, 상황의 구체성, 중복, 개인 설명과 궁합의 일관성. 미리 정한 루브릭으로 평가하며 생성한 모델의 자기평가만으로 통과시키지 않는다.
- 사용량 usage와 p50/p95 지연, 실패/재시도율을 기록해 실제 비용을 비교한다. 샘플 통과는 무오류 보장이 아니다.

API를 붙이는 결정과 실행 승인은 이번 문서의 검토 범위를 넘어선다. 모델 선택·설계 검토에는 키가 필요하지 않아 사용자에게 키를 요청하지 않았다.

## 후속 요청

이 문서 작성 뒤 사용자가 실제 두 모델 비교·우수 모델 적용·새 키 생성과 데스크탑 저장을 허용했다. OpenAI Platform 재인증이 해결되지 않아 키/실제 호출은 미완료이며, 사용자의 후속 지시에 따라 [오프라인 평가 준비와 서버 후보 모듈](narration-comparison-preparation.md)을 구현했다. 이전의 ‘검토만 수행’은 최초 문서 작성 시점의 상태다. 모델 선택과 공개 앱 적용은 아직이다.
