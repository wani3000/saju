# 강약·합화 최종 판정과 궁합 점수 기준 후속 감수

2026-10-19. `source-case-veto-and-score-review-v1`을 추가했다. 원문에 명시된 **20명조의 강약 판어**, 다섯 합의 **출처별 방해 조건**, 점수안의 **근거 범위·공학 조건**을 검토한다. 일반 명조 전부의 강약·중화·합화를 판정하는 엔진과 궁합 점수 산식은 아직 채택하지 않았다. 새로 채택한 연구 판단과 보류 사유를 각각 코드로 검사한다.

## 원전 대조와 근거 보존

[『滴天髓闡微』 1947년 판본](https://commons.wikimedia.org/wiki/File:SSID-11335994_滴天髓闡微.pdf)의 PDF 178~188쪽을 직접 읽어, 이전 목 4명조에 화·토·금·수 16명조를 추가했다. 181~187쪽 이미지 7개를 새로 보존하고 나머지는 이미 고정한 이미지를 재사용한다. 사주 네 기둥은 오른쪽부터 연·월·일·시로 읽고 대운 열은 제외했다.

[『三命通會』 1926년 판본](https://commons.wikimedia.org/wiki/File:NLC416-13jh000156-94145_三命通會.pdf)의 PDF 128~129쪽을 다시 읽어 다섯 합의 방해 문구를 대조했다. 원문 해시·쪽 이미지·선택 전사·20명조 판어는 [출처 명세](../research/validation/fixtures/reading-sources/adjudication-sources.json)와 [전사](../research/validation/fixtures/reading-sources/adjudication-transcription.json)에 고정했다. 선택 전사는 구두점·생략 부호를 추가한 발췌다. 수명·재산·건강·관직·가족의 길흉 서사는 수록하지 않는다.

## 강약: 판어가 있는 사례와 일반 기준의 경계

20명조는 오행별로 태왕·왕극·태쇠·쇠극 각 1개씩이다. 네 기둥이 원문과 정확히 일치할 때 **이 판본의 해당 사례 판어**를 반환한다. 시간 모름·일부 후보·비슷한 명조에는 판어를 확장하지 않는다. 일반 강약·중화와 궁합 점수는 null이다.

원문 PDF 188쪽은 이 20명조를 중화의 기운을 얻지 못한 사례로 총괄한다. **중화 사례가 없는 극단 사례 모음으로 중화의 일반 경계값을 정할 수는 없다.** 원문 판어를 옮기는 작업과 일반 분류기를 검증하는 작업은 다르다.

실행 가능한 반례 검사로 다음 가설을 배제했다.

> 일간을 제외한 다른 천간 3개 중 생조 관계가 2개 이상이면 강, 미만이면 약으로 정한다.

이는 채택 후보를 입증하기 위한 근거가 아니라 개수 위주의 지름길을 반증하기 위한 진단 가설이다. 목 태왕·목 태쇠·금 태쇠 **3명조에서 원문 방향과 어긋난다.** 목 태왕을 약으로, 목 태쇠를 강으로 분류하는 반대 방향 오류도 있다. 이 20명조의 일치 비율을 일반 명조 정확도나 실제 예측 타당성으로 표시하지 않는다.

따라서 천간 단순 과반수 기준은 채택하지 않는다. 사령·뿌리·투출·합화에 따른 유효 작용과 태왕/왕극·태쇠/쇠극의 경계는 별도 정성 기준이 필요하다. 현재 연구 코드의 각 근거를 점수로 조용히 합산하지 않는다.

## 합화: 방해 조건을 다섯 쌍으로 확대

| 합 | 원문 방해 천간 | 문구 | 연구 적용 범위 |
|---|---|---|---|
| 갑기 | 무 | 有戊字間之則不化 | 두 합 위치 사이 |
| 을경 | 갑 | 有甲字間之則不化 | 두 합 위치 사이 |
| 병신 | 정 | 柱有丁字不化 | 관찰된 천간 전체 |
| 정임 | 병 | 柱有丙字不化 | 관찰된 천간 전체 |
| 무계 | 기 | 柱有己字不化 | 관찰된 천간 전체 |

`間之`가 반드시 두 위치 사이만을 뜻하는지의 해석은 추가 검토 범위다. 구현은 **사이에 있는 경우만 보수적으로 적용하는 연구 정규화**이며, 사이 밖에 없다는 이유로 방해 부재를 확정하는 일반 규칙이 아니다. `柱有`의 존재 조건과 위치 조건을 하나로 합치지 않는다.

판정은 관찰된 일간 합 상대마다 따로 한다. 한 상대가 방해받아도 다른 인접 상대가 남으면 전체를 불성립으로 선언하지 않는다. 출생 시간을 모르면 시주의 추가 상대·방해를 배제하지 않는다. 전체 후보에서 해당 출처 조건으로 모든 관찰 상대가 막히고 시주도 관찰된 경우에는 `dayPairSourceClausePassed=false`를 반환한다. 구응·상충 우선순위가 미검토이므로 이것을 합화 전체 불성립으로 승격하지 않는다. `dayPairTransformationEstablished=false`는 관찰이 완전하고 보이는 일간 합 상대 자체가 없는 경우에만 사용하며, 이 역시 **일간·보이는 천간 범위**다.

방해가 없거나 상대가 남는 경우는 `remaining-conditions-unresolved`다. 선호 시주·월 조건을 통과했다고 true로 바꾸지 않는다. 원문별 간섭 천간의 차이(『子平真詮』 갑기의 경/을, 『三命通會』 갑기의 무)는 별도로 보존하며 어느 출처의 조건 부재를 다른 출처의 성립으로 취급하지 않는다. 구응·파상·자조·왕기의 충분조건과 상충 우선순위는 미완료다.

## 원문이 합화를 직접 말한 사례의 적용 범위

『滴天髓闡微』 PDF 188쪽의 **계묘·무오·임인·병오** 명조에는 `戊癸從化`라는 문구가 있다. 무·계는 **연·월 천간**이고 일간은 임이다. 네 기둥이 정확히 일치할 때 이 원문 사례의 화 종화 언급을 출처와 함께 기록한다.

이를 계기로 일간 중심 합화 검사가 사주 안의 모든 합을 다루는 것처럼 읽히지 않도록 범위를 명시했다. 이 사례의 연·월 무계 언급과 일간 임의 합 상대 부재는 다른 검토 대상이다. 일반 합화 성립이나 두 사람 사이의 합화에 이식하지 않는다. 다른 명조·시간 모름에는 이 긍정 판어를 부여하지 않는다.

## 궁합 점수안: 무엇이 부족한가

새 [점수안 감사 함수](../research/validation/adjudication-review.mjs)는 제안된 규칙 ID·수치 가중치·방향 집계·시각 미상·후보·정규화·중복 처리 정책을 받는다. 출처의 효력은 요청자가 제공하는 승인 플래그가 아니라 저장소의 검토된 근거 목록으로 확인한다. 표현식을 실행하지 않는다.

| 제안 근거 | 확인된 범위 | 점수 채택 판정 |
|---|---|---|
| 합충 정의 | 어떤 두 기호가 짝인지 | 두 사람 관계의 좋고 나쁨과 수치 가중치의 근거가 아님 |
| 개인 강약 사례 | 한 판본의 특정 명조 판어 | 두 사람 점수의 기여값으로 전용할 수 없음 |
| 개인 합화 방해 | 선택한 출처의 개인 차트 조건 | 두 사람 궁합 감점 근거로 전용할 수 없음 |
| 임의 규칙·승인 주장 | 검토된 근거 없음 | 미검토로 거절 |

기호 개수 가감, 개인 강약 가산, 합화 방해 감점의 **세 제안 유형**을 검사했다. 보고서의 ±10·±5 등의 수치는 결함 검사용 임의값이며 추천·채택된 가중치가 아니다. 제안이 구조적으로 잘 작성되어도 현재 검토 목록에는 관계 효과와 수치 가중치 근거가 없으므로 점수·정규화 궁합값·지도 반경은 null이다. `approved=true` 같은 요청 필드로 이를 바꿀 수 없다.

다음 공학적 반례도 고정했다.

- **집단별 최솟값/최댓값 정규화:** 합성 값 60이 `[40,60,80]`에서는 0.5지만 다른 값 0을 추가하면 0.75가 된다. 다른 사람을 추가해 기존 지도가 바뀌는 정책을 배제한다.
- **동일 항목 중복:** 같은 기여 10을 두 번 세면 20이 된다. 중복 근거를 독립 증거로 취급하지 않는다.
- **방향성:** 갑→병의 식신과 병→갑의 편인은 서로 다른 분류다. 검토된 대칭 집계 정책 없이 최종 대칭 궁합 점수에 넣지 않는다.
- **시간·후보:** 시각 미상에 정오를 채우거나 일부 후보 수를 확률로 사용하는 정책을 거절한다.

이 공학 조건을 통과해도 해석·가중치가 검증된 것은 아니다. 반대로 원전이 있다는 이유만으로 중복·비대칭·버전 혼합·거리 이동 문제가 해결되는 것도 아니다.

## 적용·검증·남은 일

기존 앱 풀이 `source-observations-copy-v1`, 숫자 없는 지도 보관함, 과거 구매·공유 결과는 보존했다. 이번 연구 판단을 기존 결과에 주입하거나 운영 점수로 노출하지 않았다.

[보고서](../research/validation/reports/adjudication-drafts.md)는 강약 20사례·합화 방해 양방향 10사례·점수안 3종·정규화/중복/방향 반례를 담는다. 구조·수치 검사는 합성 자료다. 신규 테스트 17개는 원문 해시, 20사례 판어·오행/등급 분포, 이전 네 사례 재현, 부분 후보·시간 모름, 원문 연월 종화 범위, 방해 위치 차이·다른 합 상대·후보 전수 대조, 세 점수안 거절·승인 위조 차단·비유한값 차단, 개인정보·검토 플래그와 이전 보고서 재현을 검증한다.

```sh
node research/validation/build.mjs
pnpm --dir research/validation test
node research/validation/audit-adjudication.mjs --check
node research/validation/audit-adjudication.mjs --release-check
python3 tools/check_docs.py
```

운영 승인 검사는 종료 코드 2를 유지한다. 남은 핵심은 일반 강약·중화 경계와 대표 사례 보강, 합화 구응·왕기·출처 충돌의 채택 정책, 두 사람 관계 효과 및 수치화 근거·가중치·척도 검토다. 현재 출처 검토만으로 그 값이 정해진 것처럼 만들지 않는다. 외부 인증·결제는 준비 후 진행한다.

실행 결과: 전체 연구 테스트 186개(신규 17개), 엔진 빌드·문서 연결·신규 및 이전 보고서 재현 통과. 운영 승인 검사는 예상 종료 코드 2다.
