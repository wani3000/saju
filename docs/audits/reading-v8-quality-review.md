# v8 결과 품질 재검사 — 2026-10-22

[v7 평가](reading-v7-quality-review.md)의 동일 가상 120쌍 × 네 관계 = 480결과, 10날짜 × 12시각 = 120결과를 재생성했다. 실제 사용자 관찰이나 적중률 검사가 아니다.

| 항목 (각 관계 120쌍) | v7 | v8 |
| --- | --- | --- |
| 공통점 설명 종류 | 3 | 108 |
| 공통점 최대 동일 그룹 | 108 | 3 |
| 양방향 도움 종류 | 각 25 | 각 119 |
| 대화 절 종류 | 25 | 114 |
| 함께할 일 종류 | 25 | 119 |
| 마지막 조언 완전 중복 | 120 | 0 |
| 개인 도움과 궁합 도움 완전 중복 | 120 | 0 |

전체 본문은 각 관계 120종이다. 모든 근거가 개인 성향 모델에 연결됐고 장점·주의점·배려 문구의 내부 불일치 0건, 사실 변경/모르는 시주 생성/관계 카테고리 혼입/공개 카드 차이/생성 실패 0건이다. 이는 코드 기준의 검사이며 심리적 타당성 검증은 아니다.

시각을 바꾼 10날짜 모두 궁합 본문이 변했다. 각 날짜의 서로 다른 본문 수는 5, 7, 8, 8, 7, 10, 10, 8, 6, 8종이다. v7에서는 8날짜가 12시각 내내 동일했다. 같은 십성 집합은 문장을 공유할 수 있다.

월간 anchor와 첫 공통 대분류는 이전 버전 구조에 보존된 값이며 v8 해설 선택에 사용하지 않는다. 순서를 뒤집고 anchor를 지워도 문장 결과가 동일한지 별도 회귀 검사한다.

식신의 작은 행동/꾸준한 관심이 궁합에서 말 중심 성격으로 바뀌던 경로를 제거했다. 장단점과 궁합 모두 열 가지 분류의 같은 행동·필요 배려를 사용한다. 근거 펼침의 이전 표현도 정리했다. 양방향 도움을 뒤집으면 대응하는 설명이 유지된다.

## 정성적 판정과 남은 범위

일관성과 확인된 기둥의 반영 범위는 개선됐다. 다만 문장의 다양성 자체가 좋은 해설을 증명하지는 않는다. 상세 분량은 v7보다 늘었고 비슷한 배려 표현은 남는다. 각각 어떤 상황인지 나눠 읽을 수 있게 했으며, 실제 사용자에게 충분히 쉬운지 관찰한 것은 아니다. 가족 세부 관계/직무와 실제 가치관은 입력에 없으므로 확정하지 않는다. 일반 강약/합화/점수, 전문가 승인 및 외부 연동은 그대로 별도 과제다.
