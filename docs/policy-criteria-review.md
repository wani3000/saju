# 계산 정책과 강약·합화·궁합 기준 후속 감수

2026-10-20. 연구 버전 `scoped-source-criteria-v1`을 추가했다. 외부 연동은 준비 후 진행한다. 계산 엔진 v5·앱 풀이 v2·기존 구매/공유 스냅샷은 유지한다. 이번 변경은 출처의 조건 범위, 후보 상관관계, 계산 정책의 구현 경계를 확인하는 연구 모듈이다.

## 계산 정책: 채택한 관습과 검증된 사실 구분

[종합 자료](../research/validation/reports/policy-criteria-audit.json)의 `calendar.choices`에 현재 선택과 남은 승인 상태를 구분했다.

| 항목 | 현재 연구판 기준 | 감수의 한계 |
|---|---|---|
| 날짜 범위 | 입력 연도와 환산 양력 모두 1908~2026 | 범위 밖을 정확하다고 추정하지 않음 |
| 연·월 | 역사 시계의 UTC 좌표와 절입 사용 | 음력 연·월 간지와 같다고 보지 않음 |
| 일·시 | 민간시계·자정 기준, 태양시/DST 제거 없음 | 다른 학파의 자시·태양시 관습을 틀렸다고 판정하지 않음 |
| 분 입력 | 분 시작 포함·다음 분 시작 제외 | 실제 출생 초를 안다고 가정하지 않음 |
| 절입 검토 폭 | 임시 ±120초와 분 입력 구간의 교집합 | 천문 오차 상한이나 바깥의 정확도를 보증하지 않음 |
| 시간 모름 | 민간 날짜 전체에서 연·월 후보 유지, 시주 없음 | 정오·임의 확률 보충 없음 |
| 역사 시계 | IANA gap/fold 거절, 1954 출처 차이·LMT/1972년 전 한계 유지 | 기록 시계의 보편성을 승인하지 않음 |

2000~2026의 **엔진 절입 324개 × 경계 시각 4개 = 1,296건**을 확인했다. 검토 폭 하한에서 끝나는 분은 제외하고 하한에서 시작하는 분은 포함한다. 상한에서 시작하는 분은 포함하며 그 다음 분은 제외한다. 검토 구간 여부가 일주·시주를 이동시키지 않고, 구간 안의 월주 후보 2개와 미검증 오차 상한 표시가 유지된다. 이는 **정책 구현 검사**이며 독립 천문 관측 1,296개가 아니다. 새 계산 불일치는 없어 엔진을 수정하지 않았다.

## 합화: 선호 시주와 일·시 기피 조건을 함께 관찰

1926년 『三命通會』 PDF 128~129쪽(인쇄 50~51쪽)의 전체 페이지와 앞뒤 문맥을 재대조했다. [기존 원본·쪽 이미지·해시](../research/validation/fixtures/reading-sources/hour-balance-sources.json)는 보존하고, [이번 발췌·조건 명세](../research/validation/fixtures/reading-sources/scoped-criteria-source.json)를 별도로 추가했다.

| 합 | 이번에 한정한 월 문맥 | 원문의 직접 기피 표현 | 코드가 관찰하는 위치 |
|---|---|---|---|
| 갑기 | 진·술·축·미 | 怕丙丁時 | 시주의 천간 병·정 |
| 을경 | 신·유 | 怕子寅時 | 시주의 지지 자·인 |
| 병신 | 해·자 | 怕卯巳時 | 시주의 지지 묘·사 |
| 정임 | 인·묘 | 怕午申時 | 시주의 지지 오·신 |
| 무계 | 사·오 | 怕卯酉日時 | **일주 또는 시주의 지지 묘·유** |

`此月`과 인접 문맥을 위 월 범위에 한정하는 것은 보수적인 연구 정규화다. 다른 월에서 조건이 없다고 결론 내리지 않는다. `怕`가 관찰됐다는 상태, 같은 개인 명조에 합 상대가 있는지, 선호 시주 일치, 합화 성립은 각각 별도 필드다. 기피가 관찰되지 않아도 충분조건 통과로 바꾸지 않는다.

**무진·정사·계유·병진** 합성 구조는 연월/일시 천간 전개와 합법 간지 짝을 지키면서, 기존 선호 예시인 사월·병진시와 새로 확인한 일지 유의 기피 조건을 함께 갖는다. 실제 생년월일에서 확보한 명조가 아니라 조건 분리용 예시다. 기존 선호 예시가 불완전하다는 뜻이며 기존 모듈도 합화 성립을 선언하지 않았으므로 과거 결과를 바꾸지 않는다.

- 천간·지지를 통째로 보존한다. 특히 무진/계유 후보에서 무유라는 불가능한 일주를 합성하지 않는다.
- 월주 후보의 합 상대 천간과 다른 월주 후보의 해당 월지를 모아 조건을 충족시키지 않는다.
- 시간이 없어도 확인된 일지 기피는 유지하되 미관찰 시주를 보충하지 않는다. 보이지 않는 기피·합 상대를 부재로 단정하지 않는다.
- 두 사람을 비교할 때 개인별로 관찰한다. 다른 사람의 천간을 가져와 개인 합화의 상대나 방해자로 사용하지 않는다.

### 아직 자동 판정하지 않는 구절

갑기 문맥의 `不可見火`·`見木氣`는 기세 판단을 요구하므로 눈에 보이는 화·목 천간의 개수로 대체하지 않는다. 1926년 스캔의 `除月喜丙`·`見木氣則愈衰`와 [온라인 전사 고정판](https://zh.wikisource.org/w/index.php?oldid=2292392&title=%E4%B8%89%E5%91%BD%E9%80%9A%E6%9C%83/%E5%8D%B7%E4%BA%8C)의 `余月喜丙`·`見木氣則克壞`를 구분해 기록했다. 온라인 전사는 별도 실물 판본을 확인한 증거로 세지 않으며 스캔을 자동 교정하지 않는다.

무계의 `若犯戊己`를 모든 위치의 무·기에 적용하면 합 상대 자체까지 무조건 방해로 취급할 수 있다. 이 문구의 위치·전제를 확정하지 않았으므로 해당 자동 부정 판단은 넣지 않는다. 왕기·생왕유기·중복 상대·구응·출처 충돌의 우선순위도 미확정이다. 새 모듈의 `transformationEstablished`·`sourceClauseFinalVerdict`는 **null**이다.

## 강약·중화: 오행 구비만으로 판정하는 가설 배제

기존에 원문과 대조한 『滴天髓闡微』 **극단 20명조**에, 별도로 고정한 지장간 목록을 사용해 천간·지장간 오행의 존재 여부만 조사했다. 가중치·기세·사령은 계산하지 않는다. 그 결과 **8명조에서 오행이 모두 관찰되지만 원문의 태왕·왕극·태쇠·쇠극 판어가 있다.** 예를 들어 화 태왕 사례 `을축·임오·병술·갑오`도 다섯 오행이 모두 관찰된다.

따라서 “오행이 모두 있으면 중화”는 이 관찰 방식에서 충분조건이 아니다. 반대로 한 오행이 없으면 무조건 불균형이라는 규칙도 도출하지 않는다. 표본은 의도적으로 고른 극단 사례이므로 일반 판정 정확도·경계·확률을 추정할 수 없다. 기존 중화 원문 사례와 월령 반례도 보존하며 일반 강약/중화 분류는 null로 둔다.

## 궁합: 개인 조건을 관계 점수로 전용하지 않음

새 합화 기피는 특정 출처의 **한 사람 명조 문맥**이다. 관계가 나빠진다는 효과나 숫자 감점 근거는 제공하지 않는다. [두 사람 검토 함수](../research/validation/scoped-criteria.mjs)는 개인별 원문 강약 사례와 기피 관찰을 분리하고 점수·정규화 궁합값·지도 반경을 null로 유지한다. 앞서 배제한 후보 비율 확률화·집단 정규화·중복 계수·방향성 무시도 그대로 거절한다.

## 재현·검증·다음 순서

```sh
node research/validation/build.mjs
pnpm --dir research/validation test
node research/validation/audit-policy-criteria.mjs --check
node research/validation/audit-release-readiness.mjs --check
python3 tools/check_docs.py
```

신규 검사 14개, 전체 연구 **227개** 통과. 다섯 쌍 양방향 10개와 선호/일지 기피 공존·시간 모름의 합성 2개, 실제 달력 입력 경로 4개, 후보·소유 차트 범위·개인정보 전달 차단과 이전 보고서 재현을 확인한다. 달력 4개는 공개 날짜의 계산 경로 검사이며 실제 사람의 사례나 출생 결과 관찰이 아니다. [읽기용 결과](../research/validation/reports/policy-criteria-drafts.md)·[구조화 결과](../research/validation/reports/policy-criteria-audit.json).

`--release-check`는 미승인 종료 코드 **2**다. 이후 순서는 모호 구절의 스캔 판본 대조, 왕기/구응·출처 충돌의 정성 기준, 일반 강약·중화의 독립 대조군, 관계 효과와 수치화 근거 검토다. 계산 운영 채택·전문가/실사용자 감수와 외부/운영 검증을 자동 테스트로 승인하지 않는다.
