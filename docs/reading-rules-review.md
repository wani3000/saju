## 이번에 완료한 범위

일반 대화 예시 문구 감수에서 나아가, **천간 오행 배속 10자와 합·충 17쌍의 정의를 원전 스캔과 대조하고 연구용 분석기로 구현**했다. Codex의 원문 대조·소프트웨어 검토이며 명리 전문가 승인, 관계 예측의 타당성 검증, 운영 출시 승인은 아니다. 웹 결과는 여전히 별도의 `example-copy-v2` 일반 예시다.

## 감수 중 구분한 규칙과 표현

1. **합 짝과 합화는 별개다.** 원전의 일부 육합 항목에는 오행도 붙어 있지만 이 규칙표는 짝만 추출한다. 특히 확인한 판본의 午未 항목은 다른 다섯 항목처럼 ‘合土’라고 적혀 있지 않고 太陽/太陰에 관한 작은 설명이 이어진다. 모든 육합에 결과 오행을 일률 배정하거나, 합 짝이 보이면 오행이 바뀐다고 처리하지 않는다. 합화 조건·판본 차이·학파 차이는 후속 감수 대상이다.
2. **천간 오행 배속과 사주 전체의 오행 강약은 별개다.** 지장간·월령·통근·가중치를 계산하지 않았으므로 ‘목이 몇 %’, ‘금이 부족’, ‘성격이 이렇다’는 출력을 만들지 않는다. 후보가 갑/을이면 공통 배속 목을 보존하지만 갑/병이면 확정 배속은 null이다.
3. **한 사람 안의 분류와 두 사람 사이의 궁합은 별개다.** `analyzeProfile`은 한 명의 서로 다른 기둥 쌍, `compareProfiles`는 두 명의 기둥 간 모든 쌍을 조사한다. 위치 선택·우선순위를 승인받은 궁합 산식이라고 부르지 않는다. 인접 여부·월령 등 적용 조건을 검토하기 위한 전체 목록이다.
4. **합과 충이 동시에 보이면 둘 다 남긴다.** 상쇄, 합 우선, 충 우선 같은 정책은 아직 확정하지 않았다. 점수·좋음/나쁨·관계 성공률을 만들지 않는다. 자기 비교도 100점으로 처리하지 않는다.
5. **후보에서만 보이는 근거를 확정 문장에 넣지 않는다.** `all-candidates`는 공급된 후보 범위 전체에 공통인 짝이다. `candidate-dependent`는 일부 후보의 짝이며 보고서의 확정형 초안에서 제외한다. 후보 개수를 확률로 환산하지 않는다.
6. **같은 사람의 연·월 후보는 상관관계가 있다.** 현재 계산기는 각 기둥 후보만 전달하고 결합 가능한 전체 사주를 전달하지 않는다. 교차 조합 일부에서만 보인 짝은 `jointFeasibility=not-established-from-marginal-candidates`로 표시한다. 가능한 실제 사주가 확인됐다고 표현하지 않는다. 모든 교차 조합에 공통인 결과만 확정 후보 범위의 공통 사실로 남긴다.
7. **시간 모름과 역사적 시계 검토를 전달한다.** 시간 모름은 시주를 분석하지 않으며 누락을 0점이나 불리한 점수로 바꾸지 않는다. 1954년 시계 검토·절기 경계 표시도 분석 범위에 남긴다. 후보 전체가 같아도 미승인 계산 엔진의 실제 정확도까지 확정한 것은 아니다.

## 구현과 재현 가능한 감수 결과

- [규칙 카탈로그](../research/validation/reading-rules.mjs): 버전 `symbol-relations-research-v1`, 규칙 ID·기호·원전 PDF 해시·쪽·절·검토 상태. 정의 대조 상태와 해석 승인 상태를 분리한다.
- [분석기](../research/validation/reading-analysis.mjs): v5 연구 프로필만 수용하고 60갑자 밖의 기둥, 누락·모순 후보, 시간 모름의 시주를 거절한다. 생일·UTC·별명 등 원본 개인정보를 결과에 복사하지 않는다.
- [감수 보고서](../research/validation/reports/reading-rule-audit.json): 합성 사례 6개와 초안 문장, 출처, 미완료 판정. 개발용으로 기둥을 조합한 사례는 실제 출생 차트가 아니라 규칙 단위 시험이라고 표시했다.
- [자동 검사](../research/validation/reading-analysis.test.mjs): 100개 천간 짝·144개 지지 짝의 양성/음성, 60×60 일주 조합의 A/B 대칭, 자기 비교, 실제 입춘 후보·시간 모름, 대응 음양력, 동시 합충, 미확정 문장 제외, 출처 해시와 출시 차단을 검사한다.

초안은 예를 들어 ‘a의 연주와 b의 연주에서 갑·기(甲己)가 확인되어, 선택한 규칙표의 천간 합에 해당합니다’처럼 **관측한 기호와 분류만** 설명한다. 위치·근거를 빼고 ‘서로 잘 맞는 사람’으로 바꾸지 않는다. 표시용 a/b 별칭, 관계별 쉬운 표현, 전체 결과에서의 중복·분량·이해도는 후속 사용자 문구 감수 대상이다. 초안은 앱 화면·구매·공유에 연결되지 않는다.

```sh
node research/validation/audit-reading-rules.mjs --check
pnpm --dir research/validation test
# 미승인이므로 종료 코드 2가 정상이다.
node research/validation/audit-reading-rules.mjs --release-check
```

보고서 갱신은 변경을 검토할 때만 `--check` 없이 실행한다. 원문 판독을 변경할 때는 이미지 재확인 후 전사·해시·규칙 버전·기대 결과를 함께 검토한다. 단순 해시 일치는 원문 해석의 정확도 증명이 아니다.

## 다음 감수 순서

1. 지장간·십성·월령과 합화 성립 조건을 같은 방식으로 판본·적용 조건·반례와 함께 검토한다.
2. 일 경계·진태양시 정책과 결합 후보 보존을 확정하고, 어떤 위치의 근거를 두 사람 관계에 사용할지 담당 감수자의 판단을 기록한다.
3. 관계별 문장 조합·충돌 처리·사용자 이해도를 확인한다. 숫자 가중치나 지도 거리의 운영 근거는 그 뒤의 별도 승인 대상이다.

외부 인증·결제는 준비 이후에 진행한다. 이번 연구 결과로 해당 왕복 검증이나 출시 조건을 통과 처리하지 않는다.
