## 이번 코드 변경

- research/validation/resolve-wall-time.mjs: 고정한 Asia/Seoul 전환 자료에서 UTC 후보를 역산한다. 결과는 unique / nonexistent / ambiguous로 구분한다.
- collect-transitions.py: 호스트 TZif에서 28개 offset 전환을 추출하고 SHA-256을 저장한다. Python zoneinfo 왕복 변환으로 월별 및 전환 경계 1,918개 기대 사례를 만든다.
- adapter.mjs: 누락·중복 출생 시각은 차트 반환 전에 오류를 낸다. 유일한 시각은 civilTime 근거를 제공한다. 기존 사주 기둥 계산에는 아직 과거 UTC 보정을 연결하지 않았다.
- 공유 정책 객체를 동결해 호출자가 productionApproved 값을 바꿔 이후 결과를 오염시키는 것을 차단한다. 연구 정책 버전은 research-midnight-v2다.
- node --test research/validation/*.test.mjs: 22개 테스트 통과. 하나의 테스트가 1,918개 사례를 전체 대조한다.

시간대 fixture와 기대값은 동일한 IANA 원천을 공유한다. 후보 사주 엔진 출력으로 기대값을 만들지는 않았지만 역사적 사실을 두 독립 자료로 교차 확인한 것은 아니다. 원본 manseryeok의 99건 불일치 보고서는 보존한다. 새 변환기의 통과를 원본 엔진 수정이나 운영 채택 완료로 표시하지 않는다.

## 시안 선택과 후속 구현

[캐릭터 시안](../design/characters/README.md) 3개는 대화에 표시된 순서로 1~3번이다. ‘가까운 사이’는 작업용 이름이며 서비스명 확정이 아니다. 선택 뒤에는 이미지의 문구·가독성·크기를 실제 CSS로 검증하고 입력·결과·지도 화면으로 확장한다. 일러스트는 자산으로 분리 생성하며 입력과 버튼은 실제 HTML로 구현한다.

저장소 AGENTS.md와 Product Design ideate 절차에 따라 시각안 선택 전 앱 UI를 임의로 고정하지 않는다. 합성 데이터 앱은 사주 엔진의 운영 승인을 의미하지 않으며 실제 유료 결과 연결은 P01/P05 조건을 충족한 뒤 진행한다.

[캐릭터 적용 설계](13-character-plan.md)를 UX·DB·지도/공유 계획에 연결했다. P02는 기존 시작 시안 선택 후 결과·지도·사람 구분용 변형으로 확장한다. P04는 승인된 표시 키·변형·카탈로그 버전을 저장하고, P06은 공유 당시 표시 스냅샷 보존과 접근성·이미지 실패를 검증한다. 사주 계산·과금과 외형은 독립이다. [통합 기록](handoff-integration-2026-10-14.md)에 원본과 현재 작업의 차이를 기록했다.
