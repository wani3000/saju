# 가까운 사람 지도와 결과 공유

## 지도 원칙

나를 가운데 두고 궁합상 가까운 사람을 안쪽, 차이가 큰 사람을 바깥쪽에 둔다. 이 거리는 실제 친밀도나 사람의 좋고 나쁨을 뜻하지 않는다. 모든 사람의 설명과 결과 열기는 목록에서도 가능하게 한다.

MVP는 나와 각 상대의 관계만 표시한다. 상대끼리의 궁합을 계산하거나 선을 연결하지 않는다. 이미 구매한 두 사람의 점수를 친구가 한 명 늘었다는 이유로 다시 계산하지 않는다.

## 거리 산식 계획

궁합 규칙에서 공통 척도로 정규화한 값 q를 0~1로 받은 뒤 `radius = minRadius + (1 - q) * (maxRadius - minRadius)`로 표시한다. 이것은 화면 배치 산식일 뿐, q를 정하는 궁합 가중치는 별도 감수 사항이다.

- 나와 노드가 겹치지 않도록 minRadius를 확보한다.
- 각도는 상대 생성 때 정하고 저장한다. 화면 크기가 바뀌어도 순서를 유지한다.
- 충돌은 우선 각도와 라벨 배치로 해결한다. 점수 순서가 바뀌도록 거리를 임의로 크게 이동하지 않는다.
- 정확히 같은 점수는 같은 거리로 두어도 된다. 억지 순위를 만들지 않는다.
- 표시 밴드 이름은 ‘잘 맞아요 / 서로 보완해요 / 이해가 필요해요’ 같은 초안이며 최종 규칙과 일치하도록 확정한다.
- ‘지도 거리 = 감정적 친밀도’로 오해하지 않도록 한 줄 안내를 둔다.

## 인원이 많을 때

처음에는 1~8명까지 이름이 읽히는지 검증한다. 작은 화면에서 전체 노드를 억지로 축소하지 않는다. 겹침이 많아지면 목록을 먼저 제공하고 지도에서는 페이지/필터로 일부 사람을 보여준다. 전체 인원과 현재 표시 인원을 알려 숨겨진 사람이 삭제된 것처럼 보이지 않게 한다.

목록 순서는 기본 추가 순, 선택적으로 궁합 순을 제공한다. 검색·필터는 실제 인원이 늘어나는 사용 패턴 확인 후 확장한다.

## 결과 선택

각 상대의 지도 노드는 현재 내 출생 버전에 대한 최신 접근 가능한 결과를 가리킨다. 내 생일 변경 뒤에는 이전 지도를 ‘이전 내 정보 기준’으로 보관하며 새 결과와 섞지 않는다. 규칙 버전이 달라도 기존 결과를 몰래 갱신하지 않는다. 척도가 달라진 버전의 결과를 한 지도에서 비교해야 한다면 별도 마이그레이션 정책이 필요하다.

## 공유 공개 범위

기본 공개: 두 사람의 공개용 별명, 관계 한 줄, 잘 맞는 점, 차이, 조언. 기본 비공개: 생년월일시, 사주 원본, 계정 ID, 결제 내역, 다른 사람 목록, 전체 지도.

별명이 민감할 수도 있으므로 공유 미리보기에서 ‘나 / 상대방’으로 바꿀 수 있게 한다. 전체 지도를 공개하는 기능은 MVP에 없다.

## 링크 처리

1. 사용자가 결과의 공유 버튼을 누름.
2. 공개될 정보의 미리보기와 링크를 받은 사람이 볼 수 있다는 안내.
3. 확인 후 충분히 긴 암호학적 난수 token 생성. DB에는 hash와 공개 스냅샷 저장.
4. Web Share API 지원 시 OS 공유 창, 미지원 시 링크 복사. 사용자가 직접 수신자를 선택.
5. 링크 방문은 원본 result가 아닌 whitelist로 만든 public_snapshot 반환.
6. 만료/철회/원본 삭제/환불로 권한 철회 시 공개 중단.

초기 만료 제안은 30일이며 다시 만들 수 있다. noindex, Referrer-Policy, 개인 결과 공개 캐시 금지, 토큰 로그 마스킹을 적용한다. 검색 비노출은 접근 통제가 아니며 링크를 아는 사람은 볼 수 있음을 안내한다.

SNS 미리보기는 서비스 공통 이미지·제목을 기본으로 하여 공유 내용이 외부 미리보기 캐시에 남는 것을 최소화한다. 철회는 이후 웹 열람을 막는 기능이며 수신자가 이미 복사한 내용까지 지울 수는 없다.

## 검증

- 점수 q가 높을수록 radius가 작거나 같음.
- 다른 상대 추가 전후 기존 사람의 점수·거리 불변.
- 모바일에서 이름 겹침·화면 잘림 확인, 목록으로 동일 결과 접근.
- 키보드로 사람 선택, 포커스 상태 확인.
- 추측 가능한 ID나 다른 계정 결과로 공유 링크 발급 불가.
- 만료·철회·삭제 후 링크 접근 차단.
- 공개 응답/HTML/메타태그/미리보기에 생일과 비공개 지도 없음.
