# 제품 기획

## 목표와 대상

작은 글씨와 복잡한 운세 메뉴를 어려워하는 사용자도 설명 없이 두 사람의 궁합을 보고 사람을 더 추가할 수 있게 한다. 실제 관계를 단정하기보다 서로 이해할 점을 쉽게 전달한다.

성공 경험은 “내 정보 한 번 입력 → 첫 상대 무료 결과 → 공유 또는 지도 확인 → 다음 상대 추가”다. 이름은 가칭이며 브랜딩은 후속 결정이다.

## 사용자 요청과 현재 기준

| 구분 | 기준 |
|---|---|
| 핵심 입력 | 내 생년월일과 다른 사람의 생년월일 |
| 결과 | 별도 결과 페이지, 큰 글씨와 짧은 설명 |
| 공유 | 현재 두 사람의 결과 공유 |
| 지도 | 결과 아래, 나와 잘 맞는 사람은 가깝게 표시 |
| 반복 | 한 명 추가 → 상대 입력 → 결과 → 지도 갱신 |
| 가격 | 첫 상대 무료, 두 번째부터 상대 1명당 2,900원 |
| 저장 | 내 정보·상대 정보·계산·결과를 내부 DB에서 관리 |
| 해석 | 자체 규칙과 편집한 문장 DB, 초기 AI 호출 없음 |

가격의 ‘1명당’ 해석은 앞선 기획의 기준이다. 두 번째부터 전체 무제한 2,900원이라는 뜻으로 변경되면 이용권 모델과 수익 계산을 함께 바꾼다.

## MVP 포함

- 내 프로필 하나와 여러 상대. 내 프로필은 소유자당 하나를 기본으로 한다.
- 이름/별명, 생년월일, 양력/음력, 윤달, 선택적인 출생 시간.
- 국내 출생 우선. 해외 출생은 지원 범위를 확정하기 전 계산하지 않고 안내한다.
- 상대 관계: 가족·연인·친구·직장·기타. 관계는 설명의 맥락에 사용한다.
- 관계별 문구는 달라도 MVP 지도 점수 기준은 동일하다. 표시 거리를 비교할 수 있게 한다.
- 요약, 잘 맞는 점, 다른 점, 관계를 위한 조언, 상세 풀이 접기.
- 결과 재열람, 단일 결과 공유/철회, 나를 중심으로 한 지도와 목록.
- 익명 첫 체험, 저장/구매 시 계정 연결, 구매 내역과 실패 복구.

## 제외

종합 운세 쇼핑몰, 오늘 운세, 신년 운세, 택일, 채팅 상담, 코인·질문권, 구독, 광고 보상, 친구끼리 자동 궁합, 연락처 가져오기, 전체 지도 공개, 네이티브 앱, AI 자유 생성.

## 결과 작성 원칙

단정적인 “악연”, “반드시 헤어짐”, 질병·죽음 예측을 사용하지 않는다. 관계의 차이와 실천 가능한 대화 방법을 설명한다. 지도는 실제 친밀도·인격·미래의 객관적 측정이 아니라 선택한 사주 해석 규칙의 결과임을 짧게 알린다.

## 측정 계획

| 지표 | 정의 | 목적 |
|---|---|---|
| 첫 결과 도달률 | 첫 결과 표시 / 내 정보 입력 시작 | 입력 마찰 확인 |
| 상대 추가 전환 | 추가 입력 시작 / 첫 결과 표시 | 지도와 추가 행동 이해도 |
| 유료 전환 | 유효 결제 완료 / 유료 주문 생성 | 결제 마찰 확인 |
| 재방문 | 결과/지도 재열람 계정 수 | 저장 가치 확인 |
| 공유 사용 | 공유 링크 발급·방문 수 | 공유 흐름 확인 |
| 오류율 | 단계별 오류 / 해당 요청 | 안정성 확인 |

이벤트에 이름, 생일, 사주 원문, 공유 토큰을 넣지 않는다. 목표 전환율은 실제 기준값을 모은 뒤 정하며 현재 성과를 임의로 만들지 않는다.

## 상품 단위

‘특정 내 생년월일 스냅샷 + 특정 상대 생년월일 스냅샷’ 한 쌍의 결과를 판매한다. 별명 수정·재열람에는 재결제하지 않는다. 출생 정보 변경은 별도 계산으로 취급하되, 결제 후 오입력 구제 정책은 출시 전에 확정한다. 결제 직전 입력 확인 화면을 제공한다.
