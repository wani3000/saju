## 3. 풀이 감수와 수정

[v9 감수](reading-dialogue-review-v9.md): 같은 사주 조합에서 같은 질문/응답이 역할만 바뀌어 반복되는 문제를 재현했다. 신규 v9는 마지막 중복 두 줄만 제거한다. 합성968결과에서68→0, 나머지 개인·근거·관계 본문과 공개 카드 내용은 보존했다. 계산5/풀이8 이하 저장 결과와 v8 생성 함수를 유지하고 신규 결과/랜딩 예시의 버전만 갱신했다.

일반 강약/중화 경계·합화 충분조건·궁합 점수는 새로 확정하지 않았다. 기존 자료만으로 단정하지 않고 [현재 기준](calculation-policy-candidate.md)의 미해결을 유지한다. 기존 AI 오프라인160사례 비교는 v8 계약에 고정해 앱 버전 변경으로 자동 승격되지 않게 했다. API 호출·키 작업·모델 선택은 없고 AI 활성화도 하지 않았다.

## 4. 정책 초안

[이용약관](policies/service-terms-draft.md)·[개인정보](policies/privacy-draft.md)·[상품/환불](policies/refund-draft.md)과 [운영자 결정7항목](policies/release-decisions.md)을 작성했다. 국가법령정보센터의2026년 시행 조문과 실제 DB/삭제/결제/공유 코드를 대조했다. 세션의 유효기간과 물리 정리, 회원 보관과 비활성 게스트30일 정리, 삭제와 계정 연결 해제·환불을 구분했다.

회원 초안/결과의 자동 파기 기간은 아직 없고 삭제 뒤에도 일부 식별/거래/작업 기록이 남는다. 최종 보관/분리/파기·국외 이전·제3자/아동 정보·문의 창구·상품/환불 조건을 확정하기 전 게시하지 않는다. 삭제했던 동의 칸을 복원하거나 버튼 요청을 적법한 동의로 바꾸지 않았다.

## 5. 운영·복구 준비

[복구 실행안](operations-recovery-preparation.md)과 [현재 런타임 호환 명세](audits/runtime-recovery-manifest.json)를 만들었다. 마이그레이션 해시·저장 엔진/풀이·미처리 풀이 버전을 대조하는 오프라인 CLI는 불일치면 종료2, 잘못된 입력/추가 필드/옵션·과대 파일이면 종료1이다. 네트워크/DB에 연결하거나 복원을 실행하지 않고 원문/경로/비밀을 출력하지 않는다.

합성 PostgreSQL의 실제 백업→다른 로컬 DB 복원에서21테이블 데이터·스키마/권한·세션/프로필·저장 결과·환불 권한 회수·공유 철회/만료·소유권·작업1회 재개를 통과했다. 복원 DB의 실제 버전 집계가 현재 앱과 호환되고, v9 대기 작업을 모르는 이전 worker 복귀는 차단되는 것도 확인했다. 임시 클러스터 정지/제거 완료.

정기 백업·외부 저장소/암호화 키·알림 수신처·RPO/RTO·백업 이후 삭제/환불 이력 대사·재개 책임자는 아직 결정 전이다. 원격 복원/역마이그레이션·스케줄러/알림·유료 플랜·실청구는 실행하지 않았다.
