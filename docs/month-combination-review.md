# 월령·합화 조건과 관계별 풀이 감수 · 2026-10-19

## 이번 반영

월령에서 곧바로 강약을 정하거나 합의 짝만으로 합화를 선언하지 않도록, **월지 지장간의 투출·일간과 지장간의 연결·합의 위치와 중간 천간·추가 합 상대**를 추적하는 연구 모듈을 구현했다. 조건의 관찰 사실과 최종 해석을 구분한다. 새 버전은 `month-combination-context-research-v1`; 앞선 합충·십성 연구 버전과 웹 결과는 유지한다.

새로 확보한 자료는 중국국가도서관 소장으로 기록된 『子平真詮』 文明書局 1926년 판본, **NLC416-13jh002326-46443 第2卷**이다. [Commons 출처·판본 정보](https://commons.wikimedia.org/wiki/File:NLC416-13jh002326-46443_淵海子平_子平真詮_第2卷.pdf)의 원본 PDF 75쪽을 보존하고 필요한 7쪽을 직접 읽었다. [전체 PDF](../research/validation/fixtures/reading-sources/ziping-1926-vol2.pdf), [파일 해시·쪽 위치](../research/validation/fixtures/reading-sources/context-source.json), [선택 구절 전사](../research/validation/fixtures/reading-sources/context-transcription.json). 현대 해설은 실행 규칙의 근거로 삼지 않았다.

여기서 ‘같은 오행의 지장간’은 통근 감수를 위한 기초 관찰이다. 고전의 장생·녹·왕·묘고·여기와 뿌리 등급을 전부 구현했다고 표현하지 않는다. 음양이 같은 천간인지 다른 음양인지도 구분한다. 투출 관찰에서 일간은 기준으로 남기고, 격국용 천간 하나로 중복 집계하지 않는다. 이 제외는 연구 구현 범위이며 모든 투간 용어 사용의 보편 정의라고 주장하지 않는다.

## 판본 간 차이를 보존한 부분

이번 『子平真詮』 PDF 26쪽은 논의 중 子午卯酉를 함께 묶는다. 앞서 확인한 『淵海子平』 PDF 54쪽의 정적 지장간 구절은 午에 丁·己를 명시한다. 두 구절의 목적과 분류 단위가 같다고 단정해 기존 午 목록에서 己를 삭제하지 않았다. 지장간 정의는 기존 카탈로그로 고정하고, 새 원전은 맥락 감수 근거로 구분했다.

합화 오행의 전통 명명과 실제 성립 조건도 분리한다. 갑기라는 이름을 찾았다는 이유로 두 천간의 오행을 토로 교체하지 않는다. 위치·월령·통근·투출·다른 관계를 통합하는 충분조건은 아직 확정하지 않았으므로 `transformation.status=not-adjudicated`, 결과 오행은 null이다.

## 후보 처리에서 보강한 부분

1. **같은 기둥의 천간·지지를 분리하지 않는다.** 병인/정묘 월주 후보에서 정과 인의 지장간을 임의로 묶어 투출을 만들지 않는다. 일주 후보의 일간·뿌리도 같은 후보 안에서 묶는다.
2. **합이 나타난 조합 안에서만 그 맥락을 본다.** 월간이 기/경 후보인 경우 갑기 합의 맥락에 다른 후보의 경을 끼워 넣지 않는다.
3. **합의 공통성과 방해 조건의 공통성을 별도로 확인한다.** 갑기 짝은 공통이지만 중간 경이 일부 후보에만 있다면, 그 방해 조건을 확정 문장에 넣지 않는다.
4. **한 사람의 후보는 완전한 공동 사주 목록이 아니다.** 서로 다른 기둥의 일부 조합은 실제 성립 여부 미확정이다. 원시 맥락에는 후보 대안을 남기고, 모든 주변 조합에 공통인 내용만 문장에 사용한다. 분모나 후보 비율을 확률로 제시하지 않는다.
5. **시간 모름은 미관찰이다.** 알려진 기둥에서 추가 합 상대가 없다고 해서 전체 사주에도 없다고 말하지 않는다. 시주 제외와 절기·역사 시각 검토를 JSON·읽기용 초안 모두에 표시한다.

천간 맥락 열거는 기둥별로 중복 천간을 합쳐 최대 10⁴개 주변 조합으로 제한한다. 전체 60⁴ 사주를 사실상 가능한 차트처럼 생성하지 않는다. 지장간 관찰은 해당 두 기둥에 필요한 후보만 비교한다.

## 관계별 풀이 감수

[감수용 문장 모음](../research/validation/reports/context-reading-drafts.md)은 조건 사례 8개와 친구·가족·연인 및 불확실한 친구 사례 총 4개의 관계 초안을 담는다. [기계 검토 JSON](../research/validation/reports/context-rule-audit.json)에는 기둥 위치·후보 상태·근거 쪽·미판정 필드를 보존했다.

두 사람 간에는 기존 합충 표의 **기호 비교 사실**만 연결했다. 한 사람 안의 연·월·일·시 순서를 두 사람의 여덟 기둥에 임의로 부여하지 않으며, 개인 차트의 합화 조건을 궁합 공식으로 확장하지 않는다. ‘충이 있으니 자주 싸운다’, ‘합이 있으니 좋은 배우자다’ 같은 성격·관계 단정은 만들지 않는다.

관계 유형이 바뀌어도 계산 근거는 같다. 친구는 연락 빈도, 가족은 도움과 개인의 결정 범위, 연인은 함께하는 시간과 혼자 쉬는 시간을 이야기하도록 제안한다. 이 문장은 `editorial-conversation-prompt-not-chart-derived`로 표시하고 생일에서 나온 조언으로 제시하지 않는다. 근거가 승인되지 않은 강점·차이 해석은 빈 목록이다.

점수·정규화 궁합값·지도 반경은 null이다. [점수·지도 감수 판정](relationship-scoring-review.md)에 확인된 기준과 남은 산식 조건을 기록했다. 웹에 이 연구 초안을 자동 연결하지 않았고 기존 결과 스냅샷도 유지한다.

## 검증과 다음 범위

새 자동 검사는 원전 PDF·쪽 이미지·전사 무결성, 중간 극·거리·본신 합·떨어진 추가 합 상대, 같은 기둥 후보 상관관계, 일부 후보 전용 방해 조건 제외, 16개 주변 조합의 전수 고정 차트 대조, 동시 합충 보존, 관계 유형 불변성·시간 모름·개인정보 제외를 확인한다. 과거 보고서도 그대로 재현한다. 원문 의미나 관계 예측의 타당성을 해시·단위 검사로 증명하는 것은 아니다.

```sh
node research/validation/audit-context-rules.mjs --check
pnpm --dir research/validation test
# 운영 미승인: 종료 코드 2
node research/validation/audit-context-rules.mjs --release-check
```

남은 해석 과제는 **사령·뿌리 등급을 선택한 강약 정책, 합화 충분조건과 상충 시 우선순위, 관계별 해석의 근거와 승인**이다. 이번에 끝낸 조건 관찰 구현과 이 종합 판단을 구분한다. 역사적 시계 최종 판정·독립 음양력 범위·사용자 관찰과 외부 로그인/결제 검증도 앞선 미완료 상태를 유지한다.
