# 달력·풀이 후속 감수와 출시 준비

2026-10-20. 외부 연동은 준비 후 진행하라는 사용자 지시에 따라, 공개 자료의 달력 대조·기존 풀이의 일관성·저장 계산의 표시·출시 조건 재현을 보강했다. 계산 엔진 v5와 풀이 `source-observations-copy-v2`는 유지하며, 기존 결과를 재계산하거나 문구를 바꾸지 않았다.

## 새로 확보한 달력 근거

[KASI 월별음양력](https://astro.kasi.re.kr/kor/life/pageView/5)의 공개 입력 폼에 양력 연·월과 그레고리력 구분을 전달해 24개월을 조회했다. 별도 서비스 계정·API 키를 사용하지 않았다. 자료 범위는 1908·1912·1920·1930·1940·1948·1954·1961·1972·1987·1988·2000·2012·2020·2025·2026년의 선택된 월이다. [요청 파라미터·원문 해시](../research/validation/fixtures/kasi-months/sources.json)와 원문 HTML의 gzip 파일을 보존했다.

파서는 응답의 요청 연·월, 그레고리력 표, 그 달의 모든 날짜의 순서·개수, 음력 윤달 표시와 일진을 검사한다. 잘못된 기본 월로 돌아온 응답·중복 날짜·변경된 표는 자료로 채택하지 않는다. 기대값은 후보 엔진에서 만들지 않고 [원문 행에서 전사](../research/validation/fixtures/kasi-months-derived.json)한다. 검증은 네트워크 없이 재현된다.

새 자료는 **730일**, 그중 음력 윤달에 해당하는 날짜 **78일**이다. 기존 2023~2024년의 738일 자료와 중복되지 않으므로, 두 묶음의 날짜 기대값은 합계 1,468일이다. 그렇다고 1908~2026 전 기간이 검증되거나 1,468개의 독립 천문 관측을 확보한 것은 아니다. 두 묶음 모두 KASI 자료이며, 후보 엔진도 KASI 기반 음력표를 사용한다고 명시한다. 이번 검사는 엔진 내장표와 별도로 확보한 공개 출력의 재대조다.

## 대조 결과와 구분한 예외

| 검사 | 통과 | 의미 |
|---|---|---|
| 양력→음력 | 730 | 윤달 구분 포함 |
| 음력→양력 원시 변환 | 730 | 공개 행의 역변환 |
| 시간 모름의 일진·시주 없음 | 각 730 | 날짜 일진 일치, 시간 보충 없음 |
| 알려진 시각의 일진 | 5,100 | 같은 730일의 자정·야간 등 7개 분 표본. 5,100개 독립 사료가 아님 |
| 양·음력 입력 프로필 일치 | 699 | 현재 연구 입력 범위 안의 동치 |
| 달력→기호 풀이 근거·점수 미도입 | 각 730 | 저장 규칙 v2와 비교 범위 일치 |

알려진 시각 표본 5,110개 중 10개는 기존 보호에 따라 거절됐다. 존재하지 않는 시각 6개, IANA 중복 시각 2개, 1954년 출처 차이 2개다. 이를 ‘음양력 변환 실패’로 세지 않았다. 이 검사는 고정 IANA/v5의 보호 동작 재현이며 추가 역사 사료가 아니다.

양력 1908년 1월의 31일은 음력 1907년에 속한다. 원시 변환 왕복은 모두 확인했지만, 현재 앱의 음력 입력 연도는 1908년부터이므로 그 31일의 음력 입력 동치를 통과했다고 쓰지 않는다. 지원 범위·이전 계산을 이번 작업에서 바꾸지 않았다.

KASI 표의 **음력 연·월 간지와 사주의 입춘·절입 연·월주는 서로 다른 기준**이다. 비교 가능한 표기에서 차이가 139건 나왔지만 계산 실패로 처리하지 않는다. 윤달 행에는 월 간지가 없는 경우도 있어 파서가 세 간지의 존재를 강제하지 않는다. 일진만 일주 날짜 라벨의 근거로 쓰고 연·월 간지를 절입 사주의 정답으로 가져오지 않는다. 예를 들어 1908-04-01의 음력 월 표기는 병진이며, 현재 사주 절입 기준의 월주는 을묘다.

현재 KASI 서비스의 역사 날짜 출력은 과거 당시 발행된 역서나 실제 출생 기록을 직접 확인한 자료가 아니다. 출생지의 시계 관행, 1954년 전환 전/후 시각 해석, 시주 정확도와 자정/23시 관습의 최종 승인은 별도로 남아 있다. 2026년 자료 중 검토일 이후 날짜는 달력 연산 자료이며 앱의 미래 생일 거절을 해제하지 않는다.

## 풀이와 화면 수정

기존 원문 22명조·편집 초안 17사례는 보존했다. 추가로 오행 대표 5개를 양쪽에 조합하고 관계 4종을 적용한 **100개 합성 조합**에서 근거·A/B 순서 교환·시주 제외의 일관성을 검사했다. 후보를 늘려 불확실성이 커질 때 새 확정 사실이 생기지 않는지도 검사했다. 이것은 구조·문장 검증이며 관계 예측이나 명리 전문가의 승인이 아니다. [달력·풀이 보고서](../research/validation/reports/calendar-reading-drafts.md).

‘생년월일 연구 계산 확인’은 저장된 프로필에서 다음을 보여준다.

- 음력 입력을 포함한 저장 당시 양력 환산 날짜.
- 명시된 자정 일 경계, 절입/시간대 적용, 태양시 보정 제외 기준. 알 수 없는 버전에는 최신 기준을 덧씌우지 않는다.
- 저장된 연·월주 후보의 실제 값. 후보 중 하나를 고르거나 확률·중요도 순서로 표시하지 않는다.
- ‘시간 모름’과 기둥의 ‘미확정’을 구분한다.
- 1908년 4월 이전 서울 지역 평균시, 1972년 이전 시간 기준, 1954년 출처 차이 및 절입 경계의 검토 상태.

표시는 저장 결과의 진단 설명이며 풀이 스냅샷·버전·구매 상태를 바꾸지 않는다. 이 정보는 개인 결과 화면에만 있고 공개 공유 카드에는 추가하지 않는다. 좁은 화면에서 후보값이 읽히도록 계산표를 두 열로 배치했다.

## 출시 준비 종합 검사

[종합 보고서](../research/validation/reports/release-readiness.md)는 새 달력 보고서·기존 베타 품질 보고서를 다시 계산해 저장본과 비교하고 원문 압축/비압축 해시를 확인한다. 자료 재현 성공과 다음 **8개 미완료 조건**을 구분한다.

1. 계산 정책·지원 범위 운영 승인.
2. 명리 전문가 감수.
3. 실제 사용자 이해도 관찰(현재 0명).
4. 외부 비공개 환경의 접근 제어 확인.
5. Supabase·카카오 실제 왕복 — 준비 후 진행.
6. NICEPAY 실제 테스트 왕복 — 준비 후 진행.
7. 유료 상품 범위·가치·수치 도입 여부 승인.
8. 운영 환경의 백업·복원·감시·문의·동의/보존/환불 정책과 배포 복귀 검증.

이 명령은 단위·브라우저·DB·빌드 테스트를 대신 실행하지 않는다. 테스트는 별도 CI 단계다. CI 성공, 환경 변수의 승인 플래그 또는 달력 자료 추가만으로 실제 승인 상태가 바뀌지 않는다. 외부 설정을 읽거나 키 준비를 다시 요청하지 않았다.

## 재현과 검증

```sh
python3 research/validation/collect-kasi-months.py --check
node research/validation/audit-calendar-reading.mjs --check
node research/validation/audit-release-readiness.mjs --check
node research/validation/audit-release-readiness.mjs --release-check
pnpm --dir research/validation test
npm test --prefix web
npm run build --prefix web
npm run typecheck --prefix web
npm run test:journey --prefix web
python3 tools/check_docs.py
```

종합 검사의 `--check`는 자료 재현 시 0, `--release-check`는 현재 **2(출시 차단)**가 정상 기대값이다. 기술 오류·자료 변경은 1로 실패한다. 네트워크 재수집은 명시적으로 `collect-kasi-months.py --download`를 실행할 때만 하며, 수집 후 diff와 출처를 다시 검토해야 한다.

이번 검증: 연구 **207개**, 웹 **80개**, HTTP 및 모바일 **12사례**, 타입·빌드·문서 연결 검사 통과. 새 모바일 사례는 1908년 역사 시각 주의와 2024년 입춘 후보를 320px·390px에서 표시하고, 화면 열람 전후 스냅샷·주문이 바뀌지 않음을 확인한다. [QA와 화면](../web/qa.md). 실제 전문가·사용자 검토와 외부·운영 환경 검증은 미완료다.
