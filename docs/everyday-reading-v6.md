# 일상 언어로 읽는 장단점 v6

2026-10-21 사용자가 v5도 어렵고 어색하다고 지적하고 짧은 장단점 제목과 생활 속 행동 설명 예시를 제공했다. 신규 버전은 `chunbae-everyday-copy-v6`다.

- 한 줄 성격 → 장점/단점 각각 최대 4개 → 관계에서 나타나는 모습으로 정리한다. 온화한 훈장 말투를 유지하고 ‘떠올려 보게’와 기둥별 방법 설명의 반복을 줄인다.
- 확인된 각 기둥의 분류를 차례로 읽고 중복을 제외한 최대 4개의 설명 예를 고른다. 이 편집 순서는 강약·우세·확률 판정이 아니다. 원래의 모든 근거와 후보·시간 미상 정보는 보존한다.
- 같은 성향의 장점과 어려움을 연결한다. 친구/연인/가족/동료의 본문·대화·마무리는 별도이며 연인은 애정·연락·데이트·서운함을 다룬다.
- 예시 문장을 계산 사실이나 새 명리 판정으로 채택하지 않는다. 일주만으로 전체 성격을 확정하지 않고 기존 전체 사주 분류를 유지한다.
- v5 결과를 독립 복사한 새 원고다. 과거 버전/저장 결과/공유를 덮어쓰지 않는다. 공개 카드의 비식별 조언도 유지한다.

검증 결과와 공개 체험 주소는 temporary-preview-deployment.md에 기록한다. 외부 로그인·실결제·운영 승인 상태는 바꾸지 않는다.

로컬 검증: 웹 121개, HTTP 여정, 모바일 320/390px 26개, Next 빌드, 타입 검사, 정적 체험판 빌드 통과. 문단 분할에 맞춰 여정 검사를 각 문단과 장점 목록으로 갱신했다. 기존 v5 검사는 명시적 v5 조회로 유지한다.
