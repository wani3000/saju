# 개인·궁합 일관성 v8 — 2026-10-22

버전: chunbae-coherent-whole-chart-v8. 신규 생성에만 적용한다. v7 이하 저장 결과와 공개 카드 정책은 유지한다.

## 해설 구성

- 확인된 연·월·일·시의 천간/지장간 십성을 열 가지로 유지한다. 개인의 상황·행동·주의점·필요한 배려와 궁합에서 같은 사전을 사용한다.
- 확인된 모든 분류와 근거 ID를 연결한다. 월간 대표 하나, 최초 공통 대분류, 최대 네 항목 제한을 사용하지 않는다. 같은 분류가 반복된다고 강하다고 세지 않는다.
- 장점과 주의점에 같은 상황을 붙인다. 신중한 모습과 먼저 나서는 모습이 어떤 때의 이야기인지 구분한다.
- 양방향 도움은 받는 사람의 배려 요구와 주는 사람의 행동을 연결한다. 도움 방법은 편집된 예시이며 실제 부족함이나 도움이 되는 정도를 측정한 값이 아니다. 본인에게 없는 분류를 결핍으로 해석하지 않는다.
- 연인: 데이트·연락·여행·서운함. 친구: 취향·취미·부탁·고민. 가족: 선택·방문·돌봄. 동료: 업무 방법·일정·마감·의견. 가족의 세부 관계나 동거, 직무를 추정하지 않는다.
- 총평은 읽을 방향, 상세는 상황과 행동, 마지막은 실제 경험을 확인하는 질문으로 나눈다. 개인 도움과 궁합 도움, 마지막 실천의 완전 중복을 제거한다.
- 근거 펼침도 이전 성격 문구를 재사용하지 않고 동일 분류에 연결한다. 계절·합충·같은 오행은 사실로 보존하며 새 강약/합화/성격 가중치를 만들지 않는다.

## 한계

확인된 전체 기둥의 분류를 반영하지만, 미승인 종합 강약·합화·궁합 점수 모델은 아니다. 같은 분류 조합의 글은 일부 같을 수 있다. 시간만 달라도 무조건 다른 성격을 만들지는 않는다. 모든 상황을 담아 총 분량은 v7보다 길어질 수 있으며 반복 제거와 길이 단축은 구분한다.
