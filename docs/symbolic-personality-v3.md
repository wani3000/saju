# 사주 성향·궁합 이야기 v3

2026-10-20 사용자가 임시 체험판의 4단계 결과가 기호 설명뿐이라며, 한자→풀이→각자의 성격과 두 사람의 궁합을 MBTI처럼 읽을 수 있는 결과를 요청했다. 새 결과부터 symbolic-personality-copy-v3을 사용한다. 기존 source-observations-copy-v1/v2와 저장·구매·공개 공유 스냅샷은 재작성하지 않는다.

## 결과 흐름

1. 한자 사주표와 한글 독음. 일간 강조, 목·화·토·금·수의 쉬운 뜻과 기둥 설명. 시간 모름과 계산 후보는 그대로 유지.
2. 일간별 열 가지 성향 유형. 별명·자연 비유·세 키워드·성향 소개·장점·주의점. 가까운 관계와 업무 방식은 펼쳐 읽을 수 있다.
3. 두 일간 오행의 방향 관계 5종(동일·내가 생함·상대가 생함·내가 극함·상대가 극함)과 두 유형별 대화 문장. 닮은 점, 엇갈릴 때, 역할을 바꿔 해 볼 연습을 설명한다. 합·충 개수로 좋음/나쁨을 판정하거나 궁합 점수를 만들지 않는다.
4. 친구·연인·가족·동료의 일상 장면·행동·대화 질문, 훈장의 마무리.

갑/을/병/정/무/기/경/신/임/계는 각각 개척가·조율가·표현가·세심가·버팀목·살림가·해결사·감식가·탐험가·사색가라는 창작 유형명으로 소개한다. MBTI 문항/유형/점수를 복제하거나 실제 성격 검사로 표시하지 않는다. 같은 일간은 같은 유형이다. 월령·용신·강약·합화의 종합 판정과 사주 전체의 성격 진단을 구현했다는 뜻은 아니다.

## 출처와 해석의 구분

천간의 오행 배속은 기존 [원전 대조](reading-rules-review.md) 및 고정 카탈로그를 재사용한다. 음양과 천간을 자연에 빗대는 전통 문맥은 [『삼명통회』 권2 원문](https://zh.wikisource.org/zh-hant/三命通會/卷二)의 「論天干陰陽生死」「十干分配天文」을 참고했다. 온라인 전사본의 모든 글자를 판본 대조하거나 실제 성격에 대한 타당성을 검증한 것은 아니다. 열 가지 유형명과 한국어 성향/관계 문장은 원전 번역이나 전문가 승인문이 아닌 독립적인 편집 해설이다. 일간을 자연에 빗대어 이야기를 읽는다는 안내를 결과에 표시한다.

사용자의 최신 요청에 따라 이전의 ‘기호 정의만 설명’하던 앱 범위를 상징적 성향 이야기까지 확장했다. 정식 운영 승인, 실제 전문가 서명, 검증된 관계 예측/성격 측정을 뜻하지 않는다. 기존 계산 정책·출시 감수 묶음과 research-policy.json의 v2 근거는 동결된 정의 설명의 기준선으로 남으며 v3을 인증하는 근거로 쓰지 않는다. 새 입력 안내는 v3의 성향 풀이와 한계를 명시한다.

## 구현과 보존

- [유형 원고](../web/src/domain/saju-types.ts), [규칙·조합](../web/src/domain/symbolic-reading.ts), [화면](../web/src/components/PersonalityReading.tsx).
- 엄격한 v5 차트 검증 후 저장 차트에서 일간을 읽는다. 생일 계산·성향·문구를 LLM/API에 맡기지 않는다. 일간이 미확정이면 유형·궁합 조합을 보류하고 시주를 임의로 채우지 않는다.
- 신규 생성 때 해설 전체를 결과와 함께 저장한다. 과거 결과 화면에서 현재 카탈로그로 성향을 다시 계산하지 않는다. 공개 카드는 기존처럼 별명·일반 대화만 남기고 성향·한자·출생 정보·궁합 해설을 제거한다.
- 임시 배포의 브라우저 저장/외부 전송 차단·실결제 제외는 유지한다. 다른 출생 정보라 해도 같은 일간이면 같은 유형이며, 실제 성격의 차이는 이용자가 직접 확인할 영역이다.
