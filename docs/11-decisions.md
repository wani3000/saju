## 2026-10-14 사용자 지정 결제사·운영 후속

삭제·보존 개발 정책: 직접 삭제는 개인 입력/결과/공유를 제거하고 최소 거래·동의·무료 이력/삭제 로그인 식별자를 남긴다. 만료 정리는 30일 이상 비활성·비회원·주문 없는 계정만 처리한다. 로그인 갱신·입력 저장과 동일한 계정 잠금에서 조건을 재검사한다. 보존 기간/근거는 출시 전 별도 감수가 필요하다.

## 2026-10-17 작업 복구 상한

자동 작업은 3회까지만 실행하며 worker 프로세스 중단도 소모한 시도로 취급한다. 3회 만료 시 무료 예약을 반환하고 유료 권한은 보존한다. 수동 재시도는 기존 비교 ID를 사용한다. 계정 삭제·환불·병합과 작업 획득의 잠금 순서를 계정→job으로 맞춘다. 수신 본문은 16KiB·10초 제한을 공통으로 적용하고 과대 요청 전체를 메모리에 받은 뒤 검사하지 않는다.

운영 점검은 실패 작업·만료 lease·미확정 결제의 존재를 조치 필요로 판정한다. 임의의 지연 SLA를 운영 기준으로 확정하지 않는다. 점검 정상은 DB 내 해당 이상이 없다는 의미이며 외부 로그인/PG 검증·콘텐츠 승인·출시 허가를 뜻하지 않는다. 상태 집계만 CLI로 출력하고 실제 알림 발송이나 예약 실행은 만들지 않는다.

지장간 12목록·28항목, 일간 기준 십성 분류, 월지 후보와 감수 초안을 `natal-definitions-research-v1`으로 추가한다. 기존 합충 v1은 보존한다. 판본의 敗財/劫財 차이와 한국어 10분류 명칭을 구분해 용어 승인은 pending으로 둔다. 지장간 구절의 순서는 본기 순위나 가중치가 아니다. 일주 후보 안의 일간·지장간 결합을 유지하고, 다른 기둥의 일부 후보 교차 결과는 성립 가능한 전체 사주로 단정하지 않는다. 일부 후보 전용 문장을 제외하고 시간 모름·역사 시계/절기 검토를 전달한다. [후속 감수](natal-rules-review.md).

월령 강약·합화·성격·궁합 점수는 산출하지 않는다. 원전 용어의 정의와 실제 예측의 타당성을 구분하며 웹 연결·기존 구매 결과 변경은 없다. 1954년 IANA 제안 패치까지 추적했으나 전환 시계의 독립 실무 증거는 확보하지 못했으므로 v5 보호를 유지한다.

## 2026-10-19 월령·합화 맥락과 관계 초안 결정

『子平真詮』 1926년 판본을 추가 대조했다. 월령 하나로 강약을 고정하지 않고 투출·뿌리 연결을 기록한다. 합은 위치·중간 천간·추가 합 상대·일간 참여를 조건부로 기록하며, 일부 후보의 방해 조건을 공통 사실로 승격하지 않는다. 같은 기둥 후보의 천간·지지는 결합을 보존한다. 합이 충을 자동 상쇄하거나, 추가 상대가 있으면 자동으로 쟁합이 된다는 정책은 채택하지 않는다. [조건 감수](month-combination-review.md).

새 연구 버전은 `month-combination-context-research-v1`이다. 『子平真詮』의 맥락 설명으로 기존 『淵海子平』 지장간 목록을 조용히 바꾸지 않는다. 강약·합화의 최종 결정과 점수는 미판정이다. 관계 초안은 기호 비교 사실과 생일에서 도출하지 않은 대화 제안을 분리한다. 관계 유형에 따라 근거·점수·지도 척도를 바꾸지 않는다. 기존 앱·구매 결과는 보존하고, 외부 연동은 준비 후 진행한다. [점수·지도 판정](relationship-scoring-review.md).

## 2026-10-19 원문 사례에 한정한 통근·합 방해 판단

『子平真詮』의 명시적 통근 11사례에 정성적 분류를 적용하고, 갑기 사이 경/을의 방해 사례를 부분 판정한다. `ziping-explicit-judgments-research-v1`은 기존 관찰 모듈과 별개다. 음간 장생의 뿌리 인정과 지장간의 같은 오행 관찰을 합치지 않으며, 미수록 조합을 무근으로 간주하지 않는다. 후보 전체에서 확인되지 않은 판단은 확정 문장에 쓰지 않는다. 방해 사례 부재로 합화 성공을 선언하거나 정성 등급을 숫자로 바꾸지 않는다. [후속 감수](source-judgments-review.md)에 근거·정규화 정책·검증을 남긴다. 앱·기존 구매 결과는 유지한다.

## 2026-10-19 사령과 강약·합화 조건의 통합 검토

『淵海子平』 又論節氣歌의 월별 배분을 사령 연구표로 추가한다. 실제 절입에서 86,400초를 하루로 세며 ±120초 검토 폭을 사령 경계에도 적용한다. 오월의 29일 합계는 임의로 고치지 않고 해당 월 사령을 미확정 처리한다. 실제 30일 초과 구간을 늘이거나 마지막 천간으로 채우지 않는다. 정적인 지장간·사령·판본별 통근은 별도 근거로 유지한다.

종합 감수는 사령·투출·통근·생극을 함께 제공하되 임의 점수나 다수결로 신강·신약을 정하지 않는다. 갑기 합의 월령·상대 유일성·추가 갑/을·중간 방해를 필요조건으로 검사한다. 필요조건 충족은 합화 충분조건의 승인이 아니다. 원문의 `甲乙` 표기를 보존하고 갑기 범위·기일 대칭 적용 정책을 명시한다. [감수 기록](seasonal-strength-review.md)에 근거와 검증을 남긴다. 기존 앱·구매 결과·연구 버전은 유지한다.
