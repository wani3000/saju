## 외부 준비물

- Supabase를 채택할 경우 dev/staging/prod 프로젝트, URL, 공개키, 서버 전용 키 및 DB 접속 경로.
- 간편 로그인 공급자 앱 등록, redirect URL, 비밀키. 첫 제안은 카카오를 검토하되 연동 가능 여부를 확인한다.
- Toss Payments 테스트/운영 계약과 키, 사업자·정산 정보, 웹훅 주소.
- 운영 도메인과 DNS 권한, 배포 대상, 백업/모니터링 예산.
- 콘텐츠 감수와 운영 문의 담당자, 서비스 정책.

키는 비밀 저장소와 로컬 비추적 환경 파일로만 전달·보관한다. 문서에는 변수 이름과 용도만 기록한다. 지금은 어떤 키도 요구하거나 저장하지 않았다.
