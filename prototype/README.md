# 가까운 사이 · 호랑이 클릭 시안

선택 원본: [호랑이 2번](../design/characters/tigers/02-tiger.png). 2026-10-14 사용자 선택.

## 실행

Node 22.17.0에서 확인했다. 이 폴더에서 실행한다.

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
```

브라우저에서 http://127.0.0.1:4173 을 연다. 현재 제공 화면은 휴대폰 미리보기이며 iPhone/Pixel을 전환할 수 있다.

## 제공하는 흐름

- 시작 → 내 정보 → 상대 정보 → 입력 확인 → 예시 결과.
- 가상 정보 채우기, 양력 날짜·시간 기본 검증, 입력 오류, 뒤로 가기, 수정 후 복귀.
- 지도/목록, 네 명 단위 지도 페이지, 기존 결과 재열람.
- 추가 상대 2,900원 안내 및 **결제 없이** 예시 추가.
- 공개 별명 편집, 생일 없는 예시 공유 문구 복사. 외부로 자동 전송하지 않는다.

## 운영 설계와의 차이

별도 React/Vite/TypeScript 클릭 시안이다. Next.js 운영 앱을 완성한 것이 아니다. 결과는 모든 입력에 동일한 고정 예시이며 점수·궁합 거리·사주 계산을 만들지 않는다. 음력·윤달은 입력 흐름만 제공하고 실재하는 날짜 여부는 확인하지 않는다. 실제 엔진·서버·DB·인증·공유 링크·결제 연결이 없다. 새로고침하면 메모리의 입력·결과가 사라진다. 브라우저 저장소·URL·로그에 생일을 보관하지 않는다.

메모리 상태는 보안 경계나 무료권/주문 장부가 아니다. 실제 구현에서는 서버의 초안·소유권·멱등성·영속 스냅샷·공유 철회를 별도로 구현해야 한다. 진짜 개인정보 대신 ‘가상 정보로 채우기’를 사용한다.

## 검증

```sh
npm test
npm run check:runtime
npm run build
npm run test:sites
```

모델 테스트 6개와 빌드 검증, 모바일 템플릿 무결성 검사를 추가했다. `test:sites`는 번들 제공 경로 검사이며 배포를 수행하지 않는다. 브라우저 상호작용과 화면 근거는 [design-qa.md](design-qa.md). 200% 글자 확대, 실제 모바일 키보드·보조기기, 고령 사용자 관찰은 별도 검증이 필요하다.

## 자산

[생성 프롬프트](public/assets/tigers/prompts.json). 내장 image_gen으로 제작했으며 참조는 선택한 자체 시안이다. `pair-v1.png`는 시작/결과/공유, `orange-v1.png`와 `cream-v1.png`는 이름을 동반하는 표시 아바타다. 배경 투명 PNG를 보존했다. 캐릭터는 사주 계산·가격에 영향을 주지 않는다.

폰트는 [Jua](https://github.com/google/fonts/tree/main/ofl/jua)와 Noto Sans KR, 아이콘은 [Phosphor React](https://github.com/phosphor-icons/react)를 사용한다. 관련 원문 라이선스는 [licenses](licenses/README.md)에 보관한다. 휴대폰 프레임과 키보드는 Product Design 템플릿 자산이다.
