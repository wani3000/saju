# 김춘배 훈장 · 서버 없는 임시 체험판

현재 web 앱의 App·글꼴·한지·그림과 같은 연구 계산 v5/전체 사주·개인/궁합 일관성 풀이 v8를 재사용한다. 기본 App의 요청 전송 함수를 프리뷰 안에서만 브라우저 컨트롤러로 교체한다. 일반 Next.js 앱은 카카오 로그인 후 서버 저장·공유·인증·결제 흐름을 별도로 제공한다.

프리뷰: 우측 프로필의 조회/모의 결제 내역과 입력→수정/확인→기호 계산/결과→지도→추가 상대/모의 결제→공유 미리보기→초기화. 입력/결과는 해당 탭의 sessionStorage에 보관하고 서버로 보내지 않는다. 저장 공간이 막히면 메모리에서만 체험한다. 같은 탭의 새로고침 복원은 지원하지만 다른 기기·계정 복구와 동기화하지 않는다. 브라우저의 탭 복원 기능은 세션을 복구할 수 있으므로 민감한 정보 대신 가상 정보만 사용한다.

로그인·복구 코드·공개 링크·실결제·운영 DB 연결은 제공하지 않는다. 외부 호출/공개 공유용 경로는 컨트롤러에서 거절하고, 호스팅 CSP의 connect-src none으로 fetch/WebSocket 전송도 막는다. 모의 결제는 금액 확인 뒤 브라우저 안에서만 상태를 바꾼다. 실제 결제/서버 동시성의 검증물이 아니다. 테스트용 샘플만 사용한다.

```sh
cd web
npm run build:preview
python3 -m http.server 64927 --bind 127.0.0.1 --directory .preview-dist
```

`.preview-dist`는 Git 제외된 정적 출력이다. 서버/환경변수/DB 파일을 복사하지 않고 생성 JS/CSS·폰트·창작 그림·라이선스·정적 헤더만 포함한다. 빌드 그래프에서 engine/readings 이외의 서버 모듈과 비공개 파일 유입을 거절한다. Vercel 배포는 이 출력 폴더만 업로드하고 기존 앱 프로젝트/도메인과 연결하지 않는다.

빌드를 다시 하면 출력 폴더와 내부 Vercel 링크가 초기화된다. 배포 전 올바른 전용 프로젝트/팀으로 명시적으로 link하고 inspect한 뒤 preview 환경에 배포한다. 생산 환경으로 promote하지 않는다. 프로젝트명 chunbae-preview, 팀 oxaz1234-gmailcoms-projects. 실제 URL/배포 상태는 검증 후 프로젝트 작업 기록에 남긴다.
