## 제품 기준

내 생년월일 입력 → 상대 생년월일 입력 → 결과 → 공유 → 결과 아래 관계 지도 → 한 명 더 추가하기.

- 첫 상대 1명 무료. 이후 상대 1명마다 2,900원이라는 현재 기획 기준을 사용한다.
- 기존 구매 결과 재열람, 결과 공유, 지도 확인은 무료다.
- 사주 계산은 검증한 공개 엔진을 우리 서버에서 실행한다. 궁합 규칙과 쉬운 풀이 문구는 직접 관리한다.
- 초기 버전은 AI 없이 구현한다. 점수·지도 거리를 생성형 AI에 맡기지 않는다.
- 내부 DB는 우리 서비스가 관리하는 PostgreSQL이다. 물리적으로 개인 PC 안에만 두는 DB라는 의미가 아니다.
- 본문 18~20px, 큰 버튼, 화면마다 주 행동 하나를 기본으로 한다.

## 프로젝트 확인

현재 작업 경로는 위의 복원 위치를 사용한다. 과거 PC 배치 기록은 docs/11-decisions.md에 보존한다.

프로젝트 루트에서 `python3 tools/check_docs.py`로 문서 연결을 확인한다. 이 검사는 문서만 확인하며 앱·DB·결제 테스트가 아니다.

오월 29일의 추가 판본 대조와 중화·다섯 합의 출처별 조건은 [후속 감수](docs/extended-source-review.md)에 정리했다. [21사례 보고서](research/validation/reports/extended-source-drafts.md)는 원문 사례 및 조건 검토이며 운영 강약·합화 엔진의 승인이 아니다.

시상 왕기의 선호 시주, 토 합화의 조건부 파상·자조, 일반 중화 관계 관찰은 [후속 감수](docs/hour-balance-review.md)와 [19사례 보고서](research/validation/reports/hour-balance-drafts.md)에 추가했다. 원문 예시 일치와 최종 강약·합화 판정은 구분한다.

신규 결과에는 [출시 후보 v1 기호 풀이](docs/selected-reading-release.md)를 연결했다. 일간 오행·연월일의 공통 합충 기호에 따라 설명이 달라지며, 대화 제안과 공개 공유 범위를 구분한다. 기존 예시 결과는 보존한다. 궁합 점수·강약·합화 판정과 운영 출시는 계속 미승인이다.

[강약·합화·점수 기준 후속](docs/adjudication-score-review.md)은 원문 강약 20명조 판어, 다섯 합의 방해 조건과 점수안 3종을 검사한다. 단순 생조 개수 기준은 반례로 배제했고, 개인 판어를 궁합 가중치로 전용하지 않는다. 일반 최종 판정·수치화의 운영 승인은 계속 보류다.

첫 베타 범위는 [점수 없는 기호 설명판](docs/beta-scope-and-quality.md)으로 고정했다. 신규 문구는 `source-observations-copy-v2`이며 기존 결과는 보존한다. 문장·조건 17사례와 원문 22명조를 검토했고 연구 198개·웹 74개 검사 및 모바일 입력→결과→공유를 확인했다. 로컬 비공개 후보이며 실제 전문가 감수·사용자 이해도 관찰·외부 체험·유료 전환은 미완료다.

사용 흐름·보안·출시 전 검사는 [로컬 자동 점검](docs/local-release-checks.md)으로 재현한다. 새로고침 시 소유권 확인 후 화면을 복원하고 수정 후 확인 화면으로 복귀한다. 정확한 API 경로·주문 소유권을 보강했으며 웹 77개 및 모바일 8사례 검사를 CI에 연결했다.
