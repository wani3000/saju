# 화면안 선택 기록

2026-10-09 built-in image_gen으로 세 가지 독립 결과 화면안을 생성했다. 실제 동작 앱이 아닌 디자인 비교용 이미지다. 대화에서 표시된 순서가 아래 번호의 기준이다.

2. [두 번째 화면안](02-warm.png)

프롬프트 원문과 생성 방식은 [prompts.json](prompts.json)에 있다. 사용자의 선택 전까지 확정 디자인이나 구현 완료로 표시하지 않는다.

모든 안은 큰 글씨, 결과 다음 공유와 지도, 2,900원 사람 추가를 다룬다. 이미지의 인물은 생성된 예시이며 사진 업로드 기능이나 실제 인물 자료 수집을 요구하지 않는다. 초기 기획의 기본 정보는 별명과 생년월일이다. 화면의 서비스명도 가칭이다.

시각 검토: 세 결과 모두 핵심 글씨·공유·지도·추가 버튼을 표현했다. 생성 이미지에서 임의로 추가된 인물 사진, 중복 브랜드 문구, 설명 길이, 지도 노드 거리는 최종 구현 전에 정리한다. 수치상 글꼴 크기·명암비·터치 크기·동작·접근성은 이미지로 검증한 상태가 아니다. 실제 구현에서 확인한다.

선택 뒤 입력·로딩·오류·빈 지도·결제 화면까지 같은 디자인 기준으로 이어 설계한다. 계산 엔진의 남은 운영 검증과 외부 계정 준비는 별도 과제다.
