# 호랑이 시작 화면 시안

2026-10-14 사용자 요청: “더 귀여운 동물로 가자 호랑이로 가자”. 캐릭터 종은 호랑이로 확정했다. 사용자가 아래 2번을 선택했으며 이전 새·구름·수달 시안을 대체하는 최신 선택 묶음이다.

대화에 실제 표시된 순서:

1. [호랑이 시안 1](01-tiger.png)
2. [호랑이 시안 2](02-tiger.png)
3. [호랑이 시안 3](03-tiger.png)

built-in image_gen 사용. [전체 생성 프롬프트](prompts.json)에 참고 이미지와 목표 390×844 화면을 기록했다. 원본 생성 파일은 보존하고 프로젝트에 복사했다.

검수: 세 이미지에서 호랑이 두 마리, 한국어 제목, 주 행동, 2,900원 안내를 확인했다. 시안 2는 요청한 매트한 점토보다 봉제 인형 질감으로 생성됐다. 이는 실제 출력 기준 선택 대상이며 결과를 점토 스타일로 단정하지 않는다. 생성 이미지의 세부 문구는 최종 문안이 아니며 구현 시 본문 18~20px·가격 안내 대비·200% 확대를 검증한다. 후속 구현: 2번 기준 클릭 시안과 hero·아바타 자산을 [prototype](../../../prototype/README.md)에 추가했다. 실제 계산·결제는 미연결이다.
