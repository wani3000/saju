# 캐릭터 화면 시안 · 2026-10-13

미선택. built-in image_gen으로 독립된 이미지 3개를 생성했다. 생성 프롬프트와 참고 이미지 경로는 [prompts.json](prompts.json)에 기록했다. 논리적 목표 viewport는 390×844다. PNG는 고해상도 시안이며 실제 CSS 접근성 검증은 아직 하지 않았다.

표시 순서가 선택 번호다. 이전 design/concepts 3안과 구분한다.

1. [인연 우체부](01-birds.png): 새 두 마리, 아이보리·청록, 제목에서 시작하는 구성.
2. [마음 날씨 안내자](02-cloud.png): 구름 캐릭터, 연보라·파랑, 캐릭터와 입력 순서 중심.
3. [관계 정원사](03-otter.png): 수달 캐릭터, 크림·테라코타, 관계 지도와 함께 모으는 경험 강조.

검수: 각 이미지의 제목·주 행동·추가 가격이 보이며 화면 잘림은 발견하지 않았다. 이미지에 생성된 세부 문구는 최종 카피가 아니다. 선택 후 보조 문구는 18~20px, 버튼 높이는 56px 이상, 대비와 200% 확대를 실제 브라우저에서 검증한다. 2안의 관계 지도 설명은 실제 마음이나 친밀도를 측정한다는 인상을 주지 않도록 구현 시 정리한다. 사주햄찌 스크린샷은 친근한 안내 방식의 참고로만 첨부했다.
