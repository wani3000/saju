# 김춘배 훈장 · 조선 2안

2026-10-20 사용자가 최신 [기록 사진풍 UI 2안](../documentary-ui-v2/02-paper-greeting.png)을 선택하고 충청북도·서당·김춘배 같은 지역/인물 설정을 요청했다. 선택한 안을 다른 스타일로 바꾸지 않고 [이름 반영 기준 화면](selected-reference.png)으로 보정한 뒤 실제 web 앱에 적용했다.

## 인물

- 이름/표시명: 김춘배 / **김춘배 훈장**. 풀 설정: **충청북도 괴산의 서당 훈장, 김춘배 할아버지**.
- 지역: 충청북도는 사용자 요청, 괴산은 구현 시 보충한 창작 배경이다. 조선의 행정구역 표기를 고증했다는 뜻이 아니다.
- 역할: 작은 서당에서 글을 가르치며 찾아온 사람의 이야기를 듣는 가상 안내 인물. 실제 인물·생몰년·경력·역사적 사진 출처를 만들지 않는다.
- 시선/장면: 카메라를 보지 않고 창가 책상에서 책을 내려다본다. 옛 방문자가 남긴 기록 사진 같은 창작 장면이며 실제 선교사 촬영물이라고 주장하지 않는다.
- 말투: 담담하고 따뜻한 훈장의 초대말. 시작 문구는 “누구와의 이야기가 궁금한가?”, “생일로 두 사람의 사주 기호를 살펴보세.” 과장된 사투리·예언·보증·챗봇 기능은 추가하지 않는다.
- 한계 안내: “인물과 사진은 창작이며 실제 역사 기록이 아니에요.” 현재 점수 없는 로컬 설명형 베타이며 실제 결제 없음.

## 제작 자산

기본 image_gen으로 선택 보정 이미지와 독립 자산 4개를 생성했다. 모든 호출의 전체 프롬프트·참조 파일·출력 경로·크기·바이트·SHA-256은 [prompts.json](prompts.json)에 고정했다. 생성 출력은 별도 리사이즈/재인코딩 없이 복사했다. 원본 시안 전체를 잘라 UI로 사용하지 않는다.

사진과 인장의 alpha 0–255를 확인했다. 인장 출력의 투명 여백은 CSS 표시 창에서 처리하며 사진·문자 픽셀을 새로 그리지 않았다. 서체는 자체 호스팅 Noto Serif KR/Noto Sans KR이며 [라이선스](../../../../web/licenses/README.md)를 따른다. 제3자 앱의 사진·캐릭터·이름·브랜드를 런타임 자산으로 쓰지 않는다.

## 적용/보존

[character.json](../../../../web/content/character.json)의 kim-chunbae-v1/chunbae-v1은 표시용이다. 시작·입력·결과·지도·공유의 안내 역할만 바뀐다. 계산 엔진 v5·문구 v2·점수 null·가격·저장 풀이/구매는 유지한다. 개별 사람은 이름과 나/상대 표기로 구분한다. 신규 기호 설명 공유는 새 카탈로그를 고정하고 기존 tigers-v1 공유는 기존 호랑이 그림을 보존한다. 미지원 카탈로그는 최신 인물로 덮어쓰지 않는다. prototype은 그대로 보존한다.

[실제 UI와 선택 화면 비교](../../../../design-qa.md), [기능 QA](../../../../web/qa.md): 웹 88개·HTTP·모바일 18사례·빌드/타입·로컬 PostgreSQL 복원 검증 통과. 실제 사용자 관찰·외부 연동·출시 승인은 별도다.
