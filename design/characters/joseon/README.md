# 조선 콘셉트 남자 할아버지 시안

2026-10-20 사용자 요청: “이런 컨셉으로 하자 조선 컨셉으로. 우리도 남자 할아버지 느낌으로 하자.” 기존 호랑이 방향을 대체하는 최신 디자인 방향이다. **조선풍·남자 할아버지는 확정, 아래 세부 시안 선택은 대기**다. 현재 앱과 기존 결과/공유 자산은 아직 변경하지 않았다.

대화에 실제 생성 이미지가 표시된 순서가 선택 번호다.

1. [시안 1](01-hanji-study.png): 한지 서재의 노선생.
2. [시안 2](02-sarangbang.png): 사랑방의 다정한 어르신.
3. [시안 3](03-monochrome-study.png): 흑백 서재의 조선 어르신.

built-in image_gen으로 각각 독립 생성했다. [전체 프롬프트·참고 경로·체크섬·실제 크기](prompts.json)를 보존했다. 원본 생성 파일은 유지하고 세 결과를 이 폴더에 복사했다. 화면 설계 기준은 390×844이며 생성 파일의 실제 픽셀 크기와 구분한다.

사용자가 보낸 흑백 실내 장면과 여성 노인 캐릭터 서비스 캡처, 기존 호랑이 시작 화면을 직접 보고 생성 호출에 첨부했다. 흑백/한옥 실내/친근한 노인의 분위기를 참고하며 여성 인물의 얼굴·이름·브랜드·문구를 복사하지 않는다. 생성 인물은 가상 남성이다. 역사 인물 재현이나 고증 완료로 표시하지 않는다.

세 이미지 모두 남성 노인, 조선풍 의상·서재, 한국어 안내, 생일 입력 주 행동을 육안 확인했다. ‘사주 할아버지’는 화면의 가칭이며 최종 서비스 이름이 아니다. 사주 기호 설명·두 사람 입력·보관함 흐름은 유지한다. 참고 서비스의 캐릭터채팅을 새 기능으로 채택한 것이 아니다. 이미지 속 문구·가독성은 방향 검토용이며 실제 앱의 18~20px 본문·대비·확대/키보드 검증을 대신하지 않는다.

선택 후 필요한 작업: 선택한 얼굴의 일관된 안내/결과 자산 제작 → 현재 Next.js 화면의 색·서체·문구/이미지 적용 → 사람 구분용 표시와 공유 자산의 버전 정책 검토 → 모바일·복원·공유·가격/결과 불변 검증. 기존 호랑이 자산과 저장된 공유의 카탈로그는 보존한다. 계산·풀이의 운영 승인과 외부 연동은 별도다.
