# 기록 사진과 실제 앱 참고를 반영한 최신 시안

2026-10-20. 사용자 피드백: 카메라를 보지 않고, 미국 선교사가 찍은 오래된 조선 사진 같은 장면. 이어서 예시 앱을 실제 확인해 비슷한 디자인 분위기를 반영하도록 요청했다.

**최신 선택 묶음은 이 폴더의 세 화면**이다. 이전 폴더의 정면 초상 3안과 별도다. 이번 대화에서 새 화면이 실제 표시된 순서:

1. [화면 1](01-ink-record.png)
2. [화면 2](02-paper-greeting.png)
3. [화면 3](03-study-letter.png)

번호는 새 UI 이미지 3장의 표시 순서다. 그 앞에 별도로 보여 준 [기록 사진풍 인물 장면](../documentary/reading-by-window.png)은 선택 번호에 포함하지 않는다. 시안 선택·실제 앱 반영은 대기다.

built-in image_gen을 사용해 원본 장면 1개와 UI 3개를 독립 제작했다. [전체 프롬프트·체크섬·크기](prompts.json)에 기록했다. 기준 뷰포트는 390×844이며 실제 출력 픽셀 크기는 메타데이터에 별도 보존했다. 출력에서 남성 인물이 책을 내려다보고 카메라와 눈을 맞추지 않는지, 기존 인물의 작은 썸네일도 같은지 육안 확인했다.

[실제 공개 화면 검토 기록](../../../../docs/guija-design-reference-review.md)에 공식 앱 미리보기 5장과 실제 웹 소개/입력 진입을 구분했다. 각 생성 호출에 해당 원본 이미지와 새 가상 인물 장면을 첨부했다. 앱 내부 대화/기억/결제는 실행하지 않았다.

세 안 모두 점수 없는 기호 설명판과 생일 입력 주 행동을 유지한다. 참고 앱의 인물·이름·전기·문구를 복제하지 않으며 챗봇·기억·알림·구독을 추가하지 않는다. ‘사주 할아버지’는 가칭이다. 새 인물은 AI로 만든 가상 장면이며 실제 역사 사진이나 선교사 촬영 기록이 아니다. 선택 후 자산/문구/토큰 적용과 모바일·저장/공유 불변 회귀 검증을 수행한다.

## 선택 결과

사용자가 이 묶음의 **2안**을 선택했다. 충청북도·서당·김춘배 설정을 더한 [김춘배 훈장 v1](../chunbae-v1/README.md)을 실제 web 앱에 적용했다. 위 3안은 선택 당시 이력으로 보존한다. [구현 비교 검수](../../../../design-qa.md)를 따른다.
